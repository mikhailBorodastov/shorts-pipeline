# 3D-сцены (stage3d.js), сторож и линтер

> Перенесено дословно из `_studio/CLAUDE.md` (16.10.2026). Пути роликов — от папки видео канала (`Доедать будешь/videos/<Имя>/`), инструкции `studio.py` — из рабочей папки.

## 3D-сцены (stage3d.js): Paper Mario + Octopath
В шаблоне есть 3D-слой `src/stage3d.js` (three.js r186 + postprocessing 6.39 + Reflector в `src/vendor`, грузит `vendor/boot3d.js`). Мир `world3d({ fx, build(w), update(w, lt, D, T) })` рендерится в общий WebGL-холст и вклеивается в 2D-кадр: `SCENES[k].draw = (ctx, lt, D, T) => { WORLD.draw(ctx, lt, D, T); /* 2D поверх */ }`. Субтитры, плашки, переходы, sfx не меняются. API и грабли описаны в шапке `stage3d.js`, образец целого ролика — `Коты сыщики 3D/src/yard3d.js` (двор-диорама, время суток, catCard) и `shots.js` (сцены, склейки мини-локаций внутри секции, THUMBNAILS с 3D-кадрами).
- **Анимации копим, а не планируем:** движения ёжика и эффекты придумываем под конкретный ролик, а удачное сразу обобщаем в `engine/moves3d.js` (или `hogCard`/`drawHog`) и записываем строкой в `_studio/ANIMATIONS.md` (что делает, где впервые, как вызвать). Перед тем как писать новое движение — загляни в каталог.
- **План доработок и история правок** — `_studio/HANDOFF_3d.md`. Пиксельный ёжик (`pixelHogCard`) пользователю не зашёл — не использовать, пока сам не попросит.
- **Когда брать:** если пользователь просит 3D, «как Paper Mario / Octopath», диораму. По умолчанию стиль по-прежнему 2D-аппликация.
- **Герои:** `hogCard` (бумажный ёжик: `c.hog = { walk: gait3(...), fedora, mouth, look, arm… }`, лапки уже есть; нужен тулкит с `drawHog` — копируй файл `Не жми эту кнопку в лифте детской поликлиники/src/paper.js` (подключается перед stage3d.js; `drawHog` умеет `walk` и `backView` — спина из иголок для `turnHog3`), `pixelHogCard` (HD-2D), `spriteCard` (фото/спрайт с кромкой, `c.pt(fx, fy)` для прицепа шапок и глоу). Движения: `popUp3`, `flip3` (бумажный переворот — поворот спиной, смена карточки), `hop3`, `gait3`.
- **Фидбек пользователя:** каждой смене мысли — своя локация, а не один сет на весь ролик. Перечисления («в кусты, в подвал, под машину») — отдельными мини-сценами с жёсткими склейками. В 9:16 всё должно влезать по ширине (группы — сеткой, камера сверху). Монстров/существ старыми гравюрами не делать — просить референсы или искать цветные игровые спрайты. Нравится: pop-up телефон, окна с котами, отражение в 3D-зеркале.
- **Кадр подольше:** `[пауза 1.5]` прямо в строке VO (tts.py вставит тишину после слова, интонация не рвётся), а не отдельная секция.
- **Имена и расстановка автора:** у объектов мира (`card`, `box`, `lamp`, `model`, `hogCard`, `spriteCard`, `w.add(группа, pos, 'Имя')`) есть `name` → `w.items`; `мир.layout = { 'Имя': { p: [dx, dy, dz], r, s, hide } }` двигает их поверх кода после `update()`. Группы (`мир.groups = { 'Ели слева': ['карточка 3', …] }`, собираются в `regroup()` после build) двигаются, крутятся вокруг своего центра и масштабируются целиком; безымянные объекты, созданные подряд на одном месте (ель из двух карточек, опора с перекладиной), группируются сами — «spruce 12» по `key` карточки или «группа 3». Такой блок приходит из препродакшена («✋ Расставить» в Штурме) в конце `element.js` — переноси его вместе с миром и не меняй `name` объектов.

- **glTF-модели:** `ASSETS.models = { key: '../assets/models/x.glb' }` грузит `stage3dInit` (загрузчик — `vendor/GLTFLoader.js`, three r186, MIT), в мире — `w.model(key, { h, pos, rotY, name, matte: true, anim })`: модель встаёт на пол по центру, `matte` делает её матовой, «бумажной». Берутся из препродакшена (📦 ассеты) — лицензии в README элемента.
- **Сторож монтажа (S21, `docs/studio/stage21-guard.md`):** `python _studio/server/studio.py montage guard <видео> [--scenes 3,5]` (кнопка «🛡 Сторож» на таймлайне) — без картинок прогоняет 3D и ловит: герои и предметы вошли друг в друга или в декорации, объект пропал / возник / перескочил за кадр вне склейки, мерцание — z-fighting в 3D (подтверждается картинкой), моргающие объекты и мерцание по готовому mp4 (`stands/flicker.py`, видит и 2D). Вызов — шаг «Сторож» в пайплайне, «🛡 Сторож» на таймлайне, `act <видео> guard` из чата. Отчёт текстом + лист кадров `build/guard.png`, засечки «Сторож» на таймлайне; находки — это правки (`guard.issues[].id`, вкладка «Правки», «✨ Исправить правки» над полем чата; «задумано» — `guard.issues.<id>.status ok`); сцены из данных раздвигает сам. Вход и уход — `life3` / `enter3` / `exit3` (`engine/kit3d.js`), а не `visible`; `hide` в сценах редактора анимируется сам (`o.life`). Задуманное — `w.touch('A','B')`, `w.guard('Имя', {pop:false})`. После 3D-правок прогоняй его, каждое ❌ чини.

- **Линтер сцены (S29, `docs/studio/stage29-lint.md`):** `python _studio/server/studio.py scene lint <видео> <EL>` / `montage lint <видео>` (сторож и поворотный стол `render_prop.js` зовут его сами) — вывернутые модели (`P3.lathe` — профиль снизу вверх!), нормали внутрь, карты нормалей `_dx` / `_gl`, незагруженные текстуры, несобранные шейдеры, NaN, белый / чёрный / пустой кадр, камера в объекте или под полом. Вид: `scene frame … --mode backfaces | normals | wireframe` (изнанка красным), у автора — «вид:» в редакторе и 🧊 3D-просмотре. Движок — `engine/lint3d.js`; объект без проверки — `userData.lint = false`. После правки 3D-геометрии прогоняй, ❌ чини.
- **Проверка:** `render.js snap` как обычно. `RENDER_PAGE=demo.html` рендерит другую страницу проекта. Ошибки WebGL видны в консоли snap (`[pageerror]`).
- **Грабли:** в шейдерах не использовать `pow(0.0, y)` (NaN на D3D → bloom заливает кадр чёрным); спрайты прятать `visible = false`, а не масштабом 0. `WT(i, 'кот')` находит первое слово с подстрокой («котов»!) — бери уникальные куски. Кадры клипов в `assets/*/f%03d.jpg` бывают 480×360, а не 320×240 — считай кроп по реальному размеру.
