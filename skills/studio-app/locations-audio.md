# Локации и сцены-плейбек (S13), быстрый монтаж, интервью (S27), Studio с телефона (S24), звуковой редактор (S23)

> Перенесено дословно из `_studio/CLAUDE.md` (16.10.2026). Пути роликов — от папки видео канала (`Доедать будешь/videos/<Имя>/`), инструкции `studio.py` — из рабочей папки.

- **Локации и сцены-плейбек (S13, `docs/studio/stage13-locations.md`):** в видео с `locations: true` (все новые 3D) сцена препродакшена — **локация**: место без действия
  (окружение, свет, фоновая жизнь петлёй, именованные ракурсы `shots[]`, без времени). Сцены создаются на монтаже оверлеем поверх локации:
  `python _studio/server/studio.py mscene locations <видео>` (локации, ракурсы, персонажи, сцены) → `mscene new <видео> <локация> "имя" '<оверлей>' --sec "<секция>"`
  (камера ключами от ракурсов `{t, shot, dolly}`, персонажи с клипами, звуки, маркеры, `patch` — отличие места только в этой сцене); правки — `scene ops <видео> <ms…>`.
  Место меняет только локация (`scene ops <видео> <локация>` — все её сцены пересоберутся и перерендерятся); если неясно — спроси автора «во всех сценах / только в этой».
  Таймлайн играет клипы (`server/clips_api.py`, `build/clips/`), экспорт — их склейка. Старое видео перевести: `mscene convert <видео>` (сцены и монтаж — в `_archive/s13/`).
  **⚡ Быстрый монтаж** (НЕ по умолчанию — S22: автор работает «препродакшен → согласование → монтаж на локациях», быстрый ему не нравится; «Сделать» без нарисованных локаций открывает препродакшен, быстрый — только у видео, уже сделанных так): видео с `fast: true` — ролик кодом, генератор его не трогает. Задача `fastmontage` (`server/fast_api.py`): Opus — план и общее в `src/scenes.js`,
  проверка, что общий код открывается, Sonnet-писатели параллельно — сцены `src/scenes/sNN.js` (кадры проверяют обязательно), Opus в панели — сводка и черновая сборка (30 к/с), препродакшен — задним числом.
  «Сделать заново» у готового быстрого ролика — `POST /api/montage/redo` (`fast_redo`: код ролика и out/*.mp4 -> `_archive/fast/`, монтаж обнуляется, быстрый монтаж с нуля).
  Препродакшен — в коде: `ppWorld` (места редактора), `ppAdd` (3D-пропсы, персонажи), `PP2D[el]` (2D-черновики), `IMG.own_<el>_<n>` (свой ассет автора по состояниям — как есть); есть — бери, нет — рисуй сам.
  Шпаргалка движка — `prompts/fastkit.md` (читай её, а не движок); набор готовых деталей — `engine/kit2d.js`, `engine/kit3d.js` + каталог `KIT.md`: удачное переиспользуемое переноси туда.
  Монтаж без препродакшена на локациях — задача `automontage`; нет персонажа / предмета — `add-elements` + объект `src: {pending: <id>, h}` (заглушка, подменится готовым черновиком сама).

- **Интервью вместо анкеты (S27, `docs/studio/stage27-interview.md`):** вопросы Claude к видео — интервью: план `ivplan` (Sonnet), по одному вопросу, после ответа `ivnext` правит план (drop / edit / add / clarify при противоречии / requeue после смены ответа), итог `interview.summary` идёт в промпты рядом с ответами (`ideas_claude.qa_text`). Данные — те же `qa[]` + `st` (plan | cur | done | skip | drop), `video.json → interview`; сервер `server/interview_api.py`, UI — `web/ui/interview.js` (поп-ап «Новое видео», бриф, телефон). Агент интервью не проходит за автора: `studio.py interview show <видео>` — ход и итог; запустить — `act <видео> interview`.
- **Studio с телефона (S24, бета, `docs/studio/stage24-mobile.md`):** мобильный режим `web/m/` (`mobile.js` на общем `core.js`; адреса как у десктопа `#/v/<id>[/pre/<el>|/notes|/chat]`, `#/bell`) — плеер с правками на кадре (`notes[]`, `from: 'phone'`, рисунок пальцем → `/api/videos/sketch`), «✨ Исправить правки», препродакшен по одному (пины, ✓, «Поправить»), чат видео. Доступ — Tailscale: `tailscale serve --bg <порт>`, сервер слушает только 127.0.0.1; удалённый запрос (Host не localhost / заголовки прокси) пускается только с куки привязанного устройства (`server/remote_api.py`, код из ⚙ «📱 Телефон», `studio.py remote [devices|off]`). Меняешь API, которым пользуется `mobile.js`, — проверь и мобильный режим (вид 375×812).
- **Звуковой редактор монтажа (S23, `docs/studio/stage23-audio.md`):** `montage.tracks` (дорожки: громкость dB, mute — и в экспорт, solo — только в окне), `montage.duck` (музыка приглушается по словам голоса, −6 dB), плашка звука — `track, at, src, gain (множитель), in, out, dur, loop {a, xf}, fadeIn, fadeOut (null у звука — авто-затухание), align, by`; звуки сцен — те же поля в `scene.json → sounds` (правка с таймлайна идёт в сцену). Расчёт плашки — `clip_pieces` / `render_clip` в `template/audio.py` = `MSnd.pieces` в `web/audio_tl.js` (генератор сам обновляет `audio.py` проектов, сохраняя `TALK` / `MUSIC`). Панель «🔊 Звуки» — `server/audio_api.py` (`/api/audio/list|search|similar|upload|fetch|import`; поиск в сети — Mixkit первым; «＋ Пак» — папка или zip в общую библиотеку, `sfx_library.py import … --auto`; свои файлы — `<видео>/files/sfx/own|net|edit/`). CLI: `montage tracks <видео>`, `montage clip <видео> add|set|del …`, `montage soundsin <видео>` (звуки ⚡ быстрого ролика из кода сцен — в редактор, с привязкой к словам). **🔒 `by: author` — плашку поставил автор: не меняй и не удаляй без его «да»** (`set montage` и `montage clip` откажут без `--force`).
  **Всё, что звучит, — плашкой на таймлайне (15.10.2026, автор: «как в нормальных программах монтажа»):** вжух перехода — плашка на дорожке «Переходы» (`trans: <юнит>`, движок свой не ставит — `noWhoosh`), многослойный звук препродакшена — плашка на слой `el:<id>#<i>`, связанные `grp`; правила — `montage_api.norm_sfx` = `Montage.normSfx`, их применяет сама сборка. Скрытых звуков (в коде сцен, в `audio.py`, слоями внутри плашки) не добавляй. Готовый mp4 старее монтажа — «⚠ старее монтажа» (`out/.exports.json`, `export_stale`), такой ролик автору не показывай как готовый — экспорт заново (§8.3 `stage23-audio.md`).
