## Claude Studio — приложение (бывший «Штурм идей»)
План и устройство — `_studio/docs/studio/` (README, architecture, roadmap, ТЗ этапов: `stage1-editor.md`, `stage2-studio.md`), препродакшен — `docs/preproduction.md`, прошлое устройство Штурма — `docs/shturm.md`. Меняешь приложение — обнови их.
Локальная страница `http://localhost:8790/` (запуск — `Claude Studio.bat` в рабочей папке; порт запущенного — `python _studio/server/studio.py port`). Окно-приложение — `_studio/app` (Tauri 2, ярлык «Claude Studio»; сборка и устройство — `docs/studio/stage2-studio.md` §5), `.bat` — запасной вход в браузере. Установщик для друзей — `app/build_setup.bat` → `Claude Studio Setup.exe` (программа + демо-канал `_studio/demo/`, мастер зависимостей; §5.1).

Есть сценарий — страница предлагает переписать его агентом.
  Старые адреса `#/p/<id>/<этап>` только переадресуют в окно видео (`App.oldRoute`); вкладки «Штурма» (идеи, биты, название, образы, структура, итоги), лист персонажа, мастерские и редактор скелета убраны в S12.11 — данные в `video.json` остались. «Начать» в шаге «Сценарий» кладёт проект ролика прямо в папку видео.
- **Видео** (`video.json`, architecture §3.2): `idea`, `topic` (контекст), `refs[]`, `qa[]` (вопросы Claude и ответы автора), `titles[]` (углы атаки, ★ финалисты), `elements[]` (препродакшен), `thumbs[]` (обложка), `stage` (последний открытый этап), `status`, `project`. Биты, смыслы, 7 вопросов, жанр, итоги — убраны (жанр Claude выводит сам). id видео = id бывшего штурма; пути в документе — `files/<id>/…` и `render/<id>/…`, сервер разрешает их в `<видео>/files` и `<видео>/preprod` (`server/paths.py`).
- **Библиотека канала** (`<канал>/library/`, architecture §3.7, `server/studio_api.py`): утверждённые ✓ персонажи, пропсы, 3D-модели, звуки, видео для экранов — версиями (`lib:<kind>/<slug>@<N>`), с превью и `license.json`; вкладка **«На проверку»** (`#/lib/review`, `Pages.review` в `web/pages.js`): ✓ элементы видео карточками по видео (превью, 3D покрутить, звук послушать), «＋ В библиотеку» / «Обновить» одной кнопкой без перезагрузки (до 3 параллельно, сервер пишет по одной — `_PUB`), «Не брать» — `e.libSkip` (`/api/lib/skip`); `lib/candidates` отдаёт `state` new | newer | same (`e.lib.render` — какой черновик опубликован); или CLI `lib publish <video> <element>`. На странице предмета — «Поправить с Claude» (`libfix`, пины на 3D-модели + заметки → новая версия), «Дублировать», «Умеет» у персонажа; 2D-предмет правится в препродакшене видео и публикуется новой версией. Мастерских («🛠», «✏️ Править» рабочей копией) нет с S12.11.
  Удаление: 🗑 на плитке или «☐ Выбрать» пачкой (`Pages.libDelete`) → `/api/lib/archive` уносит предмет в `_archive/library/<канал>/<id>/whole-…` (+ `_lib_entry.json`); плашка «↩ Восстановить» (`/api/lib/restore`, `studio_api.restore_item`) — пока автор на странице; стоит в сценах — сначала подтверждение со списком видео.
- **Препродакшен** — модель и экспорт в `_studio/server/preprod.py` (шапка файла — полная схема элемента). `elements[]`: `kind` char | prop | scene | sound — в таком порядке, `name`, `desc`, `why`, `status` '' | ok | drop, `refs[]` картинки автора; у сцены `uses[]` — id её персонажей и пропсов; `final[]` — «🎬 Для финала» {text, x?, y?}: что автор хочет от ассета в готовом ролике (у утверждённого клик по черновику ставит зелёный пин); у звука `mix[]` — слои ролика {sid, at, gain, note} + `mixNote` (`sound` = первый слой, для совместимости). **@-ссылки:** в любом поле страницы «@» открывает список элементов (↑↓, Tab/Enter — вставить), в текст пишется `@[Название]`; переименование элемента переписывает ссылки; упомянутые у сцены персонажи и пропсы входят в её состав; промпты (`preprod.element_brief`) и экспорт их раскрывают. **Сцены — после персонажей и пропсов:** «Что в сцене» связывает их со сценой, при рисовании сцены Claude получает их черновики и код `element.js` и ставит их в неё (в 3D — картонными карточками `w.card({draw: drawX…})`, ёжик — `hogCard`); «✨ Накидать» сам заполняет `uses` у новых сцен. **📦 Бесплатные ассеты** (карточка под референсами элемента, `assets.py`): поиск 3D (Poly Pizza, Poly Haven, Sketchfab, OpenGameArt), 2D (Openverse, Commons, OpenGameArt) и текстур (ambientCG, Poly Haven) без ключей; «✨ Подобрать» (`assets`, `ideas_claude.assets_spec`: Claude ищет через `assets.py search "q1" "q2" --kind …` с учётом «Что нужно» — `aask`) кладёт 3–6 предложений с объяснением в `picks[]` (строки поиска + `why`, `use` work|ref), ничего не скачивая — берёт автор; «📌 В реф.» кладёт превью в `refs[]`, «⬇ В работу» качает сам ассет в `files/<plan>/assets/<id>/` → `assets[]` (glTF, картинка, карты текстуры; лицензия и автор записаны), 🧊 — покрутить модель (`/tpl/stand3d.html?model=…&view=1`). Скачать со Sketchfab можно только с токеном пользователя в `.studio/sketchfab_token.txt`. Claude при рисовании получает ассеты элемента и его состава (`preprod.assets_brief`): модели — через `MODELS` + `w.model`. «✨ Накидать» (`elements`, можно по типу и с подсказкой «чего не хватает») → у визуального элемента «🎨 Нарисовать черновик» (`element`, `ideas_claude.element_spec`): Claude пишет `<канал>/videos/<видео>/preprod/<el>/vN/element.js` по контракту стенда (`PICS`, функция элемента, `ELEMENT.draw(ctx, T)`), рендерит `render_shot.js …&parts=element`, смотрит и правит; сцены при `engine: '3d'` — на 3D-стенде `/tpl/stand3d.html` (`world3d` шаблона). Правки — пины и «в целом» (`fx.main`: `notes[]` — по пункту на Enter, Backspace в пустом удаляет; старое одно поле `text` тоже читается), «Поправить» делает vN+1 от прошлого кода, отправленные пункты снимаются. 3D-черновик (`renders[].three`) смотрится живьём: «🧊 Смотреть в 3D» открывает `/tpl/stand3d.html?…&view=1` — сцена играет петлёй `ELEMENT.len` (по умолчанию 6 с), камера крутится мышью (свободная камера подменяет сценарную после `update` мира). «✋ Расставить» (там же «✋ Двигать», `&edit=1`): автор выбирает объект (клик или список `w.items`, объекты без `name` — «карточка 3» по порядку создания) и двигает его мышью по полу, Shift — по высоте, стрелки / PageUp / Q E / + − / H — сдвиг, поворот, размер, скрыть; в пределах ±12 м, ×0.25…4. Ctrl+клик — выбрать несколько (двигаются вместе), «🔗 Сгруппировать» / «⛓ Разгруппировать» (Ctrl+G / Ctrl+Shift+G), клик по части группы берёт группу, Alt+клик — часть; автогруппы можно разобрать. «💾 Сохранить» → `POST /api/layout3d` (задача `layout3d`, без Claude): новая версия черновика = тот же `element.js` + блок `// ==== расстановка автора` (`w.groups` + `w.layout`) в конце, кадры переснимаются, `renders[].layout`. «Поправить» от такой версии сохраняет блок (Claude закрепляет автоматические имена через `name`). Звук: «✨ Подобрать» (`sound`: Claude ищет в первую очередь на YouTube — `sounds.py search --src youtube`, кусок длинного ролика по `sounds.py peek` (главы, таймкоды, самые пересматриваемые места), плюс 1–2 из открытых баз; сервер скачивает 3–5 кандидатов в `files/<plan>/sfx/`), «🔎 Искать» (YouTube, библиотека пайплайна, Freesound, Commons — без Claude), «⬇ по ссылке» (любая страница со звуком, прямой файл, YouTube через yt-dlp, «с/по» — кусок). ✓ у кандидата — выбранный звук. Нарисованные элементы Claude берёт в «🎨 Отрисовать» обложки.

- **Очередь переживает перезапуск (S22):** живые задачи Claude (ждут / идут, с pid claude.exe) пишутся в `.studio/.jobs/live.json` (только процессом сервера — `ideas_api.SERVER`); при старте сервера `restore_jobs` останавливает осиротевшие claude.exe со всеми детьми и возвращает задачи в очередь тем же порядком, в 🔔 — «в очереди снова N». Отмена, таймаут, стоп агента и клипов — `P.kill_tree` (taskkill /T), а не `proc.kill()`.
- **Качество по правкам автора (S22, после аудита):** правка на превью с таблеткой «🌐 На весь ролик» (`notes[].global`, ставится и сама по словам «по всему видео / глобально») — правило ролика: в системном промпте каждой сессии видео (`agent.video_rules`), агент применяет её ко всем сценам. **✏️ Рисунок в правке:** пока открыта карточка правки, автор рисует прямо по кадру (кисть / стрелка / рамка, 4 цвета; `notes[].draw` — штрихи в долях кадра) — при сохранении `/api/videos/sketch` (`videos_api.sketch`) склеивает кадр с рисунком в `notes[].sketch` (`files/<видео>/N.png`), «Исправить правки» отдаёт его Claude картинкой: стрелка — куда двигается / идёт, рамка — о какой области речь. `montage needs` — чек-лист «🎬 Для финала» по сценам монтажа (и «элемент нигде не стоит»), `montage continuity` — таблица преемственности по сценарию и правкам автора (где, когда, кто и в каком состоянии; `video.json → continuity`, Sonnet), `montage verify` — проверка кадров по обоим (Sonnet, `build/needs.json`); всё это — в `mscene locations` и правилах агента («перед „монтаж готов“ — needs → verify»). Правила кадра (`agent.FRAME_RULES`: плашки — только по делу, один герой в фокусе, без «отсылок ради отсылок», живой кадр, свет с тенями, не из воздуха) — в промпте агента, кроме сценария. Модуль — `server/needs_api.py`.
- **Сдвиг по времени одной командой (S22):** `montage shift <видео> <с> <Δ> [--only units,sfx,music,overlays]` — всё в монтаже с секунды `с` на Δ (юниты, звуки, музыка, надписи, длина; отмена — «↺» в чате); `scene shift <видео> <EL> <с> <Δ>` — всё в сцене (ключи, клипы, позы, камера, звуки, маркеры, длина) одной пачкой `scene ops`, ручные ключи автора тоже (значения не меняет). Было: агент двигал 17 звуков по одному.
- **Скорость и экономия (S26, `docs/studio/stage26-speed.md`):** агенту — точечные команды вместо чтения файлов и полных перезаписей: `notes <видео>` (правки автора, вместо `show`), `show --brief`, `scene get|montage get|voice get <путь>`, `help schema <тема>`, `scene prefab <видео> EL <имя>`, `montage brief --sec i`, `montage ops|undo` (🔒 автора — `--force`), `scene ops` пачкой на несколько сцен `'{"EL1":[…]}' --frames`, `scene probe` / `montage probe <t> [x,y]` — что в кадре текстом, `scene frame` / `montage snap` листом и `--compare` (тёплый Chrome `stands/shotd.js`, ~1 с), `voice redo <секции> [--ripple]` и `voice gap` — переозвучка одной секции вместо `montage tts`. Ошибки CLI — одной строкой (трейсбек — `.studio/cli_errors.log`), JS проверяется до снимка. «Исправить правки» — пачками по 4–6 в свежей сессии, модель на пачку (`FixBatch` в `web/core.js`: Opus — рисунок, «на весь ролик», новый объект; иначе Sonnet); контекст запуска > 150k — продолжение в новой сессии со сводкой; системный промпт по режиму (`agent.new_cmds`, `NEW_RULES`); чат по умолчанию Sonnet; «Поправить» черновиков — effort medium (`IDEAS_FIX_EFFORT`).
- **Простой (S28, `docs/studio/stage28-idle.md`):** Studio открыт сутками и не должен держать видеокарту (диктовка OpenWhispr на CUDA тормозила). `StudioIdle` (`web/core.js`): окно свёрнуто или без фокуса > 20 с — `on`; новые опросы страницы — через `StudioIdle.every(fn, ms, idleMs)`, а не голый `setInterval`. Петли кадров — только по флагам (`ED.dirty/playing`, `V.dirty/playing` — сеттеры будят rAF), не `requestAnimationFrame` без конца; стенды в iframe читают `top.StudioIdle` и `IntersectionObserver` (объект `Live`). 3D-превью (`view=1`) само играет 2 круга, ▶ автора — без ограничений; превью — `X3_MSAA_MAX = 2`, ~30 к/с. `review_server.py` гаснет после 30 мин без запросов (`REVIEW_IDLE`, `render.js` пингует его во время рендера; копируется в ролики `sync_engine`), ComfyUI Studio — после 10 мин без задач и без замка видеокарты (`comfy3d.idle_tick` из `auto_tick`, `STUDIO_COMFY_IDLE_MIN`).
