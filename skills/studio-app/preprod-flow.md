- **«Уже было» (S15, `docs/studio/stage15-reuse.md`):** после «✨ Накидать» и CLI `add-elements` новые персонажи, пропсы и звуки сами сверяются (задача `reuse`, Sonnet, `server/reuse_api.py`)
  с библиотекой канала и ✓ элементами прошлых видео (включая свои ассеты автора `own[]`) -> `e.libMatch`; автор решает в поп-апе «Нашлось в библиотеке» (`web/ui/reuse.js`):
  Как есть / За основу / Новый. Пока решения нет, черновик не рисуется (`reuse_api.holds`). Добавляешь элементы сам — не обходи это: `add-elements` без `--no-reuse`,
  решение — `python _studio/server/studio.py lib reuse <видео> <эл> as-is|base|new [ref]` только по слову автора; что видит поиск — `lib reuse-catalog <видео>`.
  Локации, сцены и эффекты прошлых видео берутся только «за основу»: копия черновика плюс правка под ролик.
- **Вариации (S18, `docs/studio/stage18-variants.md`):** тот же персонаж или пропс в другом образе («Стив в скафандре») — отдельный элемент с `variantOf: <id основного>`.
  В препродакшене это одна карточка с образами внутри, черновик вариации рисуется от кода основного. Сам добавляешь образ — `add-elements … --variant-of <id>`, не новым персонажем.
- **Накидать (S19):** Claude сам предполагает 2D / 3D у персонажа и пропса (`dim` / `form: 'rig'` + `dimBy {by, why}` — 🤖 на переключателе; клик автора снимает `dimBy`).

- **«📐 По референсу» (S16, `docs/studio/stage16-refbase.md`):** автор может дать шорт / TikTok как **референс подачи** (`refs[].role = 'base'`: поле в попапе «Новое видео» или «📐 За основу» в брифе) —
  наша тема рассказывается в его подаче: те же биты, порядок и доли времени, приёмы, длина фраз, связки, текст на экране; картинку и монтаж не переносим; при споре со стайл-гайдом главнее референс (CTA и мораль тоже).
  Разбор подачи — `refvideo.base_extras` (whisper по словам → `phrases.txt`, кадры с таймкодом `beat_sheet*.jpg`, склейки). Карта «их бит → наш бит» — задача `beatmap` (Opus, `server/refbase_api.py`) → `video.json → beatmap`;
  автор правит «наш бит» (🔒) и 📌 в окне «Сценарий» → «📐 Карта подачи», утверждает — агент пишет сценарий ПО КАРТЕ (сцена на бит, шапка `по референсу: <ссылка>`), `check_script.py` сверяет с `refs/beatmap.json` вместо норм гайда.
  Режимы карты (`beatmapMode`, сами по длинам): один в один (длинное — с главами), длинное → шортс (формула всего ролика), шортс → длинное (бит шортса = глава).
  «💡 Похожие темы» — отдельный путь попапа «Новое видео» (вкладка «🔎 Ресерч по референсу»: ссылка + «что ищем» → темы → клик по теме → бриф пути «Есть идея»; задача `reftopics`) — по ссылке Claude предлагает темы для канала в той же механике (не копию). CLI: `ref base <видео> <rid> [--off]`, `beatmap show|run|ok|topics <видео>`.
  Пишешь сценарий сам, а у видео есть утверждённая карта — `beatmap show` и те же правила.
- **«⇄ Другой формат» (S25, `docs/studio/stage25-reformat.md`):** из шортса — длинное, из длинного — шортсы; всегда НОВОЕ видео-двойник (`from` / `forks`), исходник не трогаем.
  `python _studio/server/studio.py fork <видео> long [--len 600] [--wish …] [--refs …] [--base <ссылка>]` — бриф, ответы, ✓ препродакшен (жёсткими ссылками), сцены редактора — локациями с ракурсами по области кадра (`shot.frame`, `camFit` в движке);
  исходник — `refs[] {kind: 'studio', role: 'source'}`, текстом — `reformat source <видео>`. Длинное: «💡 Что добавить» (`deepen`, Opus 🌐, автор ✓) → «📐 Карта глав» (S16 expand по нашему шортсу) → сценарий (♻ — строки шортса, озвучка вся заново) → монтаж на локациях.
  Из длинного: `moments <видео> run|make <id…>` — куски с новым холодным хуком (удержание YouTube), каждый — шортс-двойник с черновиком `script.md`; `--squeeze` — пересказ одним шортсом. Ракурсы под формат — `reframe <видео>`.
- **«📝 Сценарии» (S33, `docs/studio/stage33-scripts.md`):** сценарий — раздел канала (`#/scripts`, доска 💡 идеи · ✏️ черновики · ✓ готовы · 🎬 в видео), видео начинается с готового сценария: «Новое видео» = выбрать сценарий + основа (визуал, своя запись).
  Сценарий — документ видео с `kind: 'script'` (та же папка `videos/<Имя>/`, `script.md`, `research.md`, ссылки, интервью, карта подачи, сценарист); привязка (`script bind`) делает его видео (`kind: 'video'`) — текст один и тот же.
  Страница `#/s/<id>` — документ по сценам (правки — `server/scripts_api.py` поверх `template/script_api.py`, без проекта), выделение → 🔎 / ✍ / 💬 (`review/script_notes.json`), вкладки «Тема и источники», «Интервью», «📐 Карта подачи», «Правки», «Версии»; агент — сессия этого документа.
  **Длины и таймкодов нет** (автор: «по таймингу будь что будет»): сцена — `### Название`, сцена-пауза — `**Пауза:** 2`; `check_script.py` длину не проверяет. Сценарий без видео: проекта не создавай, `montage check` работает и без него, голоса нет.
  CLI: `script list | new "Имя" [--long] [--idea …] [--text файл] | show | ok | bind | dup | untimecode | notes | reply`.
