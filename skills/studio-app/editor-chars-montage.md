# Сцены редактора (S1), 3D-пропсы (S3), персонажи со скелетом и анимации (S4/S5), монтаж (S6), агент (S7), ревью и упаковка (S8), make3d, локальные обложки и 3D, новый канал (S9)

> Перенесено дословно из `_studio/CLAUDE.md` (16.10.2026). Пути роликов — от папки видео канала (`Доедать будешь/videos/<Имя>/`), инструкции `studio.py` — из рабочей папки.

- **Сцены в редакторе (Claude Studio, S1):** у 3D-сцены препродакшена может быть `e.stage` — тогда она не `element.js`, а данные: `<канал>/videos/<видео>/preprod/<el>/work/scene.json` (где что стоит, ключи, камера с планами, свет, звуки, маркеры) + `prefabs.js` (как выглядят предметы). Движок — `engine/scene.js` (`sceneWorld(SCENE, PREFABS)`, `applyScene`), формат — `docs/studio/architecture.md` §3.3. Правь такие сцены только операциями: `python _studio/server/studio.py scene show|ops|undo|version|clip <plan> <el>` (ручные правки автора — `authored`, их не трогать). Редактор — «🎬 Оформить сцену» в карточке; план Studio — `docs/studio/`.
- **3D-пропсы (Claude Studio, S3):** у пропса препродакшена `dim: '3d'` — это не карточка, а объёмный предмет `preprod/<el>/vN/prefab.js` (`prop3d({ name, h, params, build(w, o) })`
  на `engine/props3d.js`: фигуры `P3.box / cyl / lathe / extrude`, наклейки `P3.sticker` из 2D-рисунков; или Blender: `model.py` → `python _studio/stands/blender_run.py model.py` → `model.glb`).
  Стиль 3D канала — `channel.json → style3d` (у «Доедать будешь» — бумажный макет). Кадры — `node _studio/stands/render_prop.js <url prefab.js> <папка>` (4 ракурса + лист);
  в сцене редактора — `src.prefab = 'lib:props/<slug>@N'` или `'el:<элемент>@vN'`. Образец — `_studio/stands/samples/crt3d/prefab.js`, ТЗ — `docs/studio/stage3-props.md`.
  Живые части (S10.3): `channels` в prop3d + ключи `keys["ch.<имя>"]` (экран — программа или видео кадрами `lib:media/<slug>@N`, индикатор, курсор); видео — `studio.py media add "<ссылка>" --from --to`;
  предметы в руках (S10.2) — `keys["hold.handR"]` + хват персонажа `grips.json` (мастерских в интерфейсе нет с S12.11 — хват правит Claude). Образец — `lib:props/elt-monitor-bol-soi@3`, ТЗ — `docs/studio/stage10-workshop.md`.
- **Персонажи со скелетом (Claude Studio, S4):** персонаж библиотеки — `lib:characters/<slug>@N` = `prefab.js` (`character({...})`, `engine/rig.js`) + костюмы / `rig.json`.
  Ёжик — риг `param` поверх `drawHog` (скелет `hog`: тело, голова, лапы, ноги; лицо — look, lid, mouth, brows), пижама и кепка — костюмы (`wear`). Остальные — риг `parts` (части на костях).
  Поза — `{ bones: { armL: { rot, len } }, face: { mouth, brows, look }, wear: { kepka: true }, sit }`; нарисовать — `rigDraw(ctx, char, pose, x, yНог, рост, T)`, в 3D — `charCard(w, char)`.
  Посмотреть персонажа в позе — `python _studio/server/studio.py char pose <slug> '<поза JSON>' out.png`. ТЗ — `docs/studio/stage4-characters.md`.
  Анимации (S5): клипы типа скелета `library/anims/<type>/<slug>.json` (дорожки `armR.rot`, `face.mouth`, `ik.armL`, `card.y`…); в сцене у персонажа `clips[]`, `pose[]` (ключи позы, `ik`, `null` — отпустить),
  `walk: auto` (ходьба сама по ключам позиции), `lipsync: {sound}`. **С S12.11 анимации ставит Claude, а не автор:** в редакторе сцены нет дорожек клипов, Tab и ручек IK (клипы только проигрываются);
  что умеет персонаж — `scene brief` («Персонажи и что умеют»: клипы его скелета с подсказкой `when`/`prompt`) и «Умеет» на странице персонажа в библиотеке. Нужного движения нет — скажи автору, какое добавить. ТЗ — `docs/studio/stage5-animations.md`.
  Монтаж (S6): `video.json → montage` (юниты сцен редактора с картой времени `map`, голос, субтитры, `sfx`, `music`, `overlays`) → генератор `server/montage_api.py` пишет проект (`assets/studio/…`, `src/montage.js`, СГЕНЕРИРОВАННЫЙ `src/scenes.js` — руками не править) → `build.sh`. CLI: `python _studio/server/studio.py montage show|gen|build <видео>`. ТЗ — `docs/studio/stage6-montage.md`.
  Агент (S7): панель справа на всех этапах (`web/agent.js`) — живая сессия `claude -p` stream-json на видео (`server/agent.py`), инструменты — только `studio.py …` (для агента: `scene brief|frame`, `montage brief|tts|check|snap|drift` — `drift`: сцены на старом тексте голоса и промахи `WT()`, S22); препродакшен из чата — `el <видео> fix|draw|make3d|ok <эл>`, `sound <видео> pick|fetch|use|list <эл>`, `job wait <id> [id…]` (до 9 мин за вызов: агенту `BASH_DEFAULT_TIMEOUT_MS=600000`, S22) (`server/agent_tools.py`, задачи как кнопки карточки); справочник команд в промпте агента — только ядро под режим, группы — `studio.py help <тема> <видео>` (`agent.cmd_groups`, S22: −47 % промпта у быстрых роликов), правки закрываются пачкой `studio.py done <видео> '[{id, reply}, …]'` (notes / fixes / guard.issues): правку автора агент делает сам, ТЗ не просит; запуск отменяется целиком (пачки с `run`); «📌 пометки» на объектах — `scene.comments`; «✨ Собрать». ТЗ — `docs/studio/stage7-agent.md`.
  Ревью и упаковка (S8, в S12 — окно видео): пины на кадре → `video.json → fixes[]` с «почему», «Исправить все» — агент вносит их `scene ops --by author`; шаг «Упаковка» (панель `#/v/<id>/pack`) — обложка с доски «Обложки» (S12.9) и «✨ Тексты» (`packtext` → `pack`, `out/packaging.md`), «Права» из лицензий (`server/pack_api.py`). ТЗ — `docs/studio/stage8-review-pack.md`.
  3D персонажа и пропса (S12.11) — одна кнопка **«✨ Сделать 3D ▾»** в карточке препродакшена (`server/make3d_api.py`, задача `make3d`): Claude (Sonnet) выбирает способ из доступных — фигурами кодом, из модели в «📦 ассетах», бумажная карточка из частей, Blender, TRELLIS, Meshy / Tripo (только при ключе) — и в той же задаче запускает `element` / `charparts` / `charmodel`; «▾» — выбрать самому (`GET /api/make3d/ways`), почему — в `e.make3d`.
  «⋯» у 3D-пропса: «Разделить на отдельные модели» (`split3d`) и «Сделать вариации…» (`vary3d`, 2–8) — Claude (Sonnet) разбирает модель, новые 3D-пропсы с `from3d` встают в препродакшен, их черновики — в очередь; черновик начинается с `prefab.js` исходной модели.
  Локальные обложки (вне плана): FLUX.2 [klein] 4B (Apache 2.0; 9B — некоммерческая, выключена по умолчанию) в том же ComfyUI Studio — модель `flux:4b` в «Обложках», адаптер `server/flux2.py` (`generate_thumbnail`, CLI `status|gen|bench`), веса — `tools/comfy_setup.py --flux 4b`, настройки — ⚙ «🖼 Локальные обложки». Кириллицу пишет с опечатками — заголовок давай полем «Надпись» (накладывается шрифтом). Описание и замеры — `docs/studio/local-thumbs.md`.
  Локальная 3D (вне плана): TRELLIS (пропс — без скелета, `prop3d` из model.glb; рамка «выдели предмет» на листе) — TRELLIS.2 / Pixal3D в отдельном ComfyUI Studio (`server/comfy3d.py`, ставит `tools/comfy_setup.py` или ⚙ Настройки): черновик → «⬆ Довести» → «🎨 Перекрасить» → «Поправить» (Claude подбирает сиды и настройки, `trellisfix`), по 2–4 ракурсам. Описание — `docs/studio/local3d.md`.
  Новый канал (S9, с S31 — мастер): «+ новый канал…» → интервью по стилю (`#/style/interview`, вкладки нет) → «✨ Собрать стиль» (`server/channel_api.py`) раскладывает ответы: первый лук (`looks/from-interview`, `interview.visualNote`), гайд (только текст, монтаж, звук, упаковка), голос, субтитры (`style/captions.json` → `CAPTION_STYLE` роликов), правила — предложениями в Память; повторное интервью ничего не перезаписывает (`style-guide.proposed.md` + `interview.proposal` → «✓ Принять» в «Гайде», `/api/channel/proposal`). 3D-герой — Blender (`rig: 'model'`, `modelChar` в `engine/rig.js`). ТЗ — `docs/studio/stage9-channel.md`.
