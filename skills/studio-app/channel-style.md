# Стиль канала в 4 вкладки (S31), сценаристы (S32), визуалы и луки (S14), учиться по видео (S30)

> Перенесено дословно из `_studio/CLAUDE.md` (16.10.2026). Пути роликов — от папки видео канала (`Доедать будешь/videos/<Имя>/`), инструкции `studio.py` — из рабочей папки.

- **Стиль канала — 4 вкладки (S31, `docs/studio/stage31-style-tabs.md`):** Канал (название, иконка, язык, «О канале», сводка) · Визуалы · Голос и субтитры · Гайд. **Подачи канала нет** — подача пишется в брифе видео (`brief.delivery` — текст автора; у старых видео — ключ старого списка, `Styles.deliveryText`) или берётся из «📐 Референса подачи». **Правил канала нет:** текстовые — в Памяти (scope channel), технические — ручки лука (`cards.facing`, `cards.facingMaxDeg` → `PAPER_RULES` в `rig.js`). Полки «Референсы канала» нет — референсы у луков. Разделы гайда про картинку — кнопкой «→ в лук» в «Библию» лука (`looks[].picRules` → бриф; `looks[].bible` — путь к библии S30). **Лук из другого канала** — «+ Лук ▾ → Из других каналов» и выбор плитками в «Новом канале»: `looks_api.take_from` (`POST /api/looks/take {from, look}`, CLI `looks others|take`) — копия с новым key, файлы `style/looks/<key>/` жёсткими ссылками (текстовые — копией с переписанными путями `style/looks/…`, `/api/lib/file/<канал>/`), предметы библиотеки, на которые ссылаются сцена и герои, техника, если её нет; ёжик-герой не переносится. Новый канал — `interview.fresh` (луки взяты, интервью всё равно ждёт); старый канал без интервью, но с луками — настроен (`Styles.setUp`). Переезд — `migrate_s31` (сам при открытии ⚙ Стиль, CLI `channel s31 [ID]`, копия — `_archive/s31/`); старые поля `rules`, `ruleDefs`, `deliveries`, `refs`, `hero` не пишутся, только читаются.

- **«✍️ Сценаристы» (S32, `docs/studio/stage32-writers.md`):** ⚙ Стиль → Сценаристы — персона сценариста по чужому YouTube-каналу: ссылка → список роликов (📖 изучить / 🙈 спрятать для теста / не брать) → расшифровки и ритм без Claude → Sonnet читает пачками → Opus — библия (`style/writers/<key>/bible.md`: кто говорит, схемы, хук, связки, концовка, юмор, словарь, стоп-лист, учебные образцы) → **слепой тест** на спрятанном ролике (Sonnet — факты и оригинал с пунктуацией, Opus — наш текст тем же блоком, что в работе, Sonnet — разбор; автор угадывает А/Б и ставит пины «✓ это он / ✗ не он») → «Следующий раунд» (Opus, библия vN+1, тест на новом ролике) → «✓ Годится». Пробник — тема нашего канала на его языке с гуманайзером. Персона чужого языка — у теста ещё «EN / RU» (`writerru`: оригинал переводом, наш — сразу на языке канала; пины RU — `lang: 'ru'`).
  Выбор: ★ у канала (`channel.json → writer`), у видео — «Основа видео» (`brief.writer`: '' — канала, 'none' — без персоны). В работе `writers_api.agent_block` идёт в «📝 Сценарий» и «✨ Собрать», карта подачи S16 — скелет (и `our.vo` карты пишется голосом персоны), персона — слова; гуманайзер приём персоны не трогает; `montage check` кладёт `refs/writer.json` → `check_script.py` ⚠ на его фразы (стоп-лист, 5 слов подряд как в расшифровках). Учимся МАНЕРЕ, а не текстам.
  CLI: `writers list | learn <канал> [--fmt shorts|long|both] | go | show | bible [--v N] | test | probe <п> "тема" | refine | ok | default <п> | use <видео> <п|none|channel>`; чат — `act channel writerlearn | writertest | writerrefine`. Сервер — `server/writers_api.py`, страница — `web/ui/writers.js`.
- **Визуалы (S14, `docs/studio/stage14-looks.md`; вид S31 — галерея луков по техникам, страница лука: Превью и ручки / Палитра / Герои / Библия / Референсы, «⇄ Сравнить», «+ Лук ▾»: по видео, по картинкам, из интервью, из шаблонов, копия):** ⚙ Стиль → Визуалы: **техника** (чем рисуется кадр: в интерфейсе просто «2D» и «3D» — ключи `paper` / `diorama`, автор: «делить на 2D и 3D, без „аппликаций“»; своя от Claude) → **луки** с ручками.
  Ручки лука реально применяются к ролику: `window.LOOK` в `src/format.js` проекта (пишут монтаж, `produce`, `set_brief`), движок читает `LOOKV('путь', умолчание)` (`paper.*`, `post.*`, `fx.*`, `cards.facing`, `style3d`);
  свои ручки лука (`custom.*`) читает код сцен — их список и значения есть в брифе видео («Настройки лука»). Герои — у лука, не у канала (может не быть ни одного; `kind: 'hog'` — бумажный ёжик тулкита).
  Бриф видео может перекрыть ручки и героев (`brief.lookOver`), у вышедших — заморозка `lookSnap`. CLI: `python _studio/server/studio.py looks show|migrate|format <видео>`.

- **«🎞 Учиться по видео» (S30, `docs/studio/stage30-stylelearn.md`):** ⚙ Стиль → Визуалы → «🎞 Учиться по видео»: видео 8–12 мин (до 15; длиннее — кусок «с–по»), ссылка или файл → `server/stylelearn.py`:
  `stylecut` (без Claude: планы по `ffmpeg scene` + гистограммам, 4 кадра на план, повторы, метрики, листы) → `stylewatch` (Sonnet пачками по 5 листов) → `stylesynth` (Opus: `learn/bible.md`, правила с кадрами-доказательствами, «Чего не хватает» с находками бесплатных ассетов, тест-кадры) →
  доска ✓ / ✗ / ✏️ у автора → `styletest` (Opus: лук как `lookbuild` + тестовые кадры; пины → «Поправить») → «✓ Принять». Сжатая библия идёт в бриф каждого видео на этом луке (`brief_lines`).
  «✨ Да, делаем всё» (`styleall`): доска → ✓, лучшие находки → скачать, недостающее → `styleengine` (Opus дописывает ОБЩИЙ движок: новое выключено по умолчанию, ручки → `web/ref.json`; резервная копия + снимок демо-сцен до и после, сломалось → откат), затем `styletest`.
  Учимся стилю, а не содержанию: кадры видео-образца в ролики не кладём, его персонажей не рисуем. CLI: `looks learn start|show`, `looks bible [лук]`; чат — `act channel stylelearn` / `styleall`.
