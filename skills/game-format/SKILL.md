# Игровой формат (пародия на хоррор-игру)

> Перенесено дословно из `_studio/CLAUDE.md` (16.10.2026). Пути роликов — от папки видео канала (`Доедать будешь/videos/<Имя>/`), инструкции `studio.py` — из рабочей папки.

## Игровой формат (пародия на хоррор-игру) — впервые в «Не жми эту кнопку»
Нарратор только в хуке (секция с VO), дальше сцены-паузы из script.md (таймкод + «Картинка» + «Текст» без VO). Образец — `Не жми эту кнопку в лифте детской поликлиники/src/scenes.js`:
- `DIALOG` — субтитры в стиле Silent Hill: шрифт пользователя `PostironicHillSilentHill1Font` (`assets/fonts/SilentHill1.ttf`, без «ё»; кегль ~88 — у шрифта мелкие буквы), жёсткая тень, между репликами паузы «как в игре», мигающий треугольник «дальше», если следом реплика или меню; `talk: 'mom'|'hog'` = реплика вслух «звериной речью», без `talk` — мысль. `MENUS` — игровые меню с курсором и выбором. `dialogSfx(add, ta, tb)` ставит звуки речи и меню, `drawDialog(ctx, T)` рисует.
- **«Звериная речь» как в Animal Crossing:** `_studio/animalese.py` — по слогам «согласная + её гласная» («ка-же-ца»), не по буквам: буквенная версия («ка-а-жа-е…») звучала как «не то говорит». Слоги озвучены edge-tts один раз, кэш `_studio/animalese_cache/` (`python _studio/animalese.py --cache` — все ~240 слогов на голос). Звук `talk:<who>:<текст>` рендерит отдельная дорожка в `audio.py` (`TALK` — пресеты голосов), музыка приглушается под неё как под голос. Для голоса текст переписывается как слышится (`PHON`: «кажется» → «кажеца»), субтитры остаются обычными.
- **В Claude Studio** — этап «🎙 Голос» → «🐾 Звериная речь» (`server/talk_api.py`, тот же `animalese.py`): голоса канала (`<канал>/style/animalese.json`), ползунки, «▶ Послушать» (переозвучивается сразу), «➕ В препродакшен звуком» (звук «🐾 …» → сцены и монтаж), CLI `talk voices|keep`. Старый конструктор шаблона — по буквам, не по слогам.
- **Конструктор голоса** для пользователя: `src/animalese.html` (в шаблоне; буквы — скопируй `_studio/animalese_cache/*` в `assets/animalese/`). Тот же алгоритм и RNG, что в `animalese.py`; «Скопировать настройки» даёт JSON — вставь его в `TALK` в `audio.py`.
- Свои звуки из файлов: `add(t, 'file:assets/<файл>.wav', gain)`.
