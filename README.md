# Пайплайн анимационных шортов

Вертикальные шорты 1080×1920, 60 fps, в стиле Kurzgesagt: плоская векторная графика, неоновые акценты и плашки-«таблетки», субтитры по слову. Герои — круглые ёжики в духе Смешариков.

Анимация рисуется кодом (Canvas), поэтому любую правку можно сразу посмотреть в браузере, не пересобирая видео.

Работает в паре с [Claude Code](https://claude.com/claude-code): ты пишешь сценарий и оставляешь правки, Claude рисует сцены. Инструкция для Claude — [CLAUDE.md](CLAUDE.md).

---

## Установка

1. Создай рабочую папку для шортов (например `D:\work\Animations`) и склонируй пайплайн внутрь **под именем `_pipeline`**:
   ```bash
   cd D:/work/Animations
   git clone https://github.com/mikhailBorodastov/shorts-pipeline _pipeline
   ```
2. Поставь зависимости:
   - [Python 3.10+](https://www.python.org/): `pip install edge-tts numpy pillow` (для своей озвучки ещё `pip install faster-whisper`);
   - [Node.js 18+](https://nodejs.org/);
   - [ffmpeg](https://ffmpeg.org/) в PATH (Windows: `winget install Gyan.FFmpeg`);
   - Google Chrome или Microsoft Edge — путь находится сам, свой можно задать переменной `CHROME`;
   - на Windows — Git Bash, для `build.sh`.
3. Создай первый проект (шаг 1 ниже). Файл `CLAUDE.md` в корне рабочей папки появится сам.

---

## Как работаем — 5 шагов

### 1. Создать проект
Дважды кликни `_pipeline\new.bat` и введи название. Или из терминала в рабочей папке:
```bash
python _pipeline/new_project.py "Зачем ежу иголки"
```
Рядом с `_pipeline` появится папка `Зачем ежу иголки\` с уже установленными зависимостями.

### 2. Вставить сценарий
Открой `script.md` в папке проекта и замени пример своим сценарием (формат ниже). Видео, картинки и ссылки-референсы клади в `refs\`.

### 3. Попросить Claude собрать шорт
Открой Claude Code в рабочей папке и напиши:
> сделай шорт по сценарию в папке «Зачем ежу иголки»

Claude сгенерирует черновой робоголос, нарисует сцены, сам проверит кадры и пришлёт первую версию видео.

### 4. Править в интерфейсе ревью
Запусти `review.bat` в папке проекта. Он сам откроет в браузере ревью именно этого проекта (название видно в заголовке). Можно держать открытыми несколько проектов сразу: каждый получает свой порт (8765, 8766, …), а если сервер проекта уже запущен, `review.bat` просто откроет его страницу.

- **Кликни по кадру** — поставишь пин и откроешь заметку с таймкодом. Напиши, что не так, и нажми `Ctrl+Enter`.
- **Отрезок «от–до»:** протяни мышкой по таймлайну с зажатым `Shift`, или нажми `I` на начале и `O` на конце.
- **Звуки:** под словами на таймлайне идут звуковые дорожки: каждый цветной блок — отдельный звук с подписью, пересекающиеся звуки лежат на разных строках. Кликни по блоку, и откроется карточка: послушать отдельно или в контексте, **заменить** на звук из библиотеки (поиск и папки всегда под рукой), **громче/тише** (±дБ), **удалить**, оставить комментарий. Кнопка «+ 🔊» добавляет новый звук в текущий момент. Всё сохраняется правкой, как обычная заметка.
- **Зум таймлайна:** `Ctrl` + колесо мыши над таймлайном или кнопки −/+. В плотных местах так проще попасть по нужному звуку.
- Когда всё отметил, напиши Claude: **«глянь правки»**.

Claude читает `review/notes.md` и скриншоты кадров с пинами, вносит правки, отвечает под каждой заметкой и отмечает её ✓. Пока он работает, страница сама перезагружается на том же таймкоде.

Повторяй, пока не понравится.

### 5. Финальный рендер
Скажи «собери финал» или запусти `./build.sh` в папке проекта. В `out\` появятся:
- `<название>.mp4` — видео с голосом;
- `<название>_NO_VO.mp4` — только музыка и звуки;
- `music_sfx_no_vo.wav` — дорожка без голоса, под свою озвучку.

## Формат `script.md`

```markdown
# Название ролика

voice: ru-RU-DmitryNeural        ← или ru-RU-SvetlanaNeural (женский)
rate: +25%                       ← скорость чернового голоса
произношение: Chrono Trigger = Кроно Триггер

## 1. Колючий вопрос (00:00–00:05)
Визуал: Ёжик сидит на полянке и чешет затылок, вокруг всплывают «?».
Голос: Вы когда-нибудь задумывались, зачем ежу пять тысяч иголок?
Заметки: хочется тёплый ночной свет, как в референсе refs/night.jpg

## 2. Броня
Визуал: …
Голос: …
```

- **Одна секция `## ` — одна сцена.** Поле `Голос:` обязательно: из него делается озвучка и субтитры.
- Таймкоды в заголовке — ориентир для тебя. Реальную длину сцены задаёт длина фразы.
- `Визуал:` и `Заметки:` пишутся свободным текстом: что показать, настроение, ссылки, «как в референсе».
- `произношение:` — как TTS должен читать слово. Субтитры при этом покажут оригинальное написание.

## Интерфейс ревью: горячие клавиши

| Клавиша | Действие |
|---|---|
| `Пробел` | плей / пауза |
| `←` `→` | кадр назад / вперёд |
| `Shift` + `←` `→` | ±1 секунда |
| клик по кадру | новая правка с пином |
| `N` | правка без пина |
| `Shift` + протянуть по таймлайну | выделить отрезок |
| `I` / `O` | начало / конец отрезка |
| `L` или 🔁 | повторять отрезок по кругу |
| `[` `]` | к предыдущей / следующей правке |
| `Ctrl` + `Enter` | сохранить заметку |
| клик по блоку на дорожке звуков | правка звука: заменить / громкость / удалить / коммент |
| «+ 🔊» | добавить звук из библиотеки в текущий момент |
| `Ctrl` + колесо над таймлайном, −/+ | зум таймлайна |
| повторный клик по ■, `Esc`, пауза | остановить прослушку звука |

- Звук переключается между «с голосом», «без голоса» и «без звука». Скорость — 1×, 0.5× или 0.25×.
- Правки сохраняются в `review/notes.json` и `review/notes.md`, скриншоты — в `review/shots/`.
- Сохранение безопасно. Если Claude отвечает на правки, пока ты пишешь новую, ничего не затрётся: у каждой заметки побеждает более свежая версия.

## Своя озвучка

1. Запиши по одному файлу на секцию: `sec0.mp3`, `sec1.mp3`, … (порядок как в `script.md`).
2. Положи их в `build\vo\` проекта вместо черновых.
3. Скажи Claude: **«подставь мою озвучку»**. Он заново разметит тайминги слов, и субтитры с анимацией сядут на твой темп.

## Звуки

Звуковые эффекты берутся из **общей библиотеки** `_pipeline/sfx_library/` (для всех проектов), музыка синтезируется.

- **Добавить пак звуков** (любая папка с wav/mp3/m4a/mp4, подпапки = категории):
  ```bash
  python _pipeline/sfx_library.py import "C:/Users/<ты>/Downloads/Мой пак"
  ```
  Звуки перегоняются в единый WAV с короткими id вроде `whoosh/15-quick-a` и `hit/05-impact`. У каждого замеряется длина и момент пика, чтобы удар попадал точно в кадр.
- **Послушать и выбрать:** открой `_pipeline/sfx_library/browser.html` двойным кликом. Там поиск, плеер и кнопка «копировать» для id. Id можно вписать прямо в правку, например «здесь `lib:hit/01-boom`».
- **Искать из терминала:** `python _pipeline/sfx_library.py find удар` (ищет по id и исходным именам).
- Claude выбирает звуки сам по каталогу `sfx_library/index.md`. Стандартные звуки (`pop`, `whoosh`, `impact`, `click`, …) тоже берутся из библиотеки, а если её нет — синтезируются.
- Категория `meme` — узнаваемые куски из игр, фильмов и видео, то есть чужие записи. В публичных роликах используй её осторожно. Библиотека в git не попадает (размер и лицензии паков), её нужно импортировать на каждой машине.

## Персонажи: ёжики

Функция `drawHog(ctx, x, y, размер, {…})` в `src/chars.js`. Что можно задать:

- **Расцветка** `skin`: `main` (рыжий), `blue`, `pink`, `green`, `violet`, `grey`.
- **Эмоции:** `eye` (размер глаз), `mouth` (открытый рот, 0–1), `sad`, `brows` (брови: −1 злой, +1 удивлён), `blink`, `look` (куда смотрит).
- **Движения:** `armF` и `armB` (углы лапок), `walk` (походка), `sq` (сплющивание при прыжке), `rot`, `dir: -1` (смотрит влево).
- **Аксессуары:**
  - шапки `hat`: `cap`, `crown`, `cowboy`, `party`;
  - `glasses`, `scarf`;
  - предмет в лапе `prop`: `mic`, `flag`, `sword`, `gavel`, `scythe`.

Новые расцветки, аксессуары и персонажей просто проси у Claude.

## Устройство проекта

```
<проект>/
  script.md          сценарий (ты)
  refs/              референсы (ты)
  review/            правки: notes.md, shots/
  out/               готовые видео
  src/scenes.js      сцены этого ролика (Claude)
  src/chars.js       персонажи
  src/lib.js         хелперы рисования
  src/main.js        движок: таймлайн, переходы, субтитры
  src/review.*       интерфейс ревью
  tts.py             черновой голос из script.md (edge-tts, бесплатно)
  audio.py           синтез музыки и звуков, сведение
  render.js          рендер кадров (headless Chrome)
  build.sh           полная сборка → out/
  review_server.py   сервер ревью; также `python review_server.py list`
  review.bat         запуск ревью двойным кликом
```

## Заметки

- Черновой голос берётся из бесплатного edge-tts, ему нужен интернет.
- Шрифты в `template/assets/fonts` (Rubik, Nunito, Press Start 2P) взяты из Google Fonts, лицензия SIL Open Font License.
- Сторонние материалы, которые попадают в конкретные ролики (кадры игр, логотипы, спрайты), в репозиторий не входят; права на них у их владельцев.

## Если что-то не так

- **Вверху панели плашка «Сервер ревью старой версии».** Закрой окно сервера и запусти `review.bat` заново. Нужно один раз: дальше сервер подхватывает обновления сам.
- **Страница ревью не открывается или показывает не тот проект.** Проверь название в заголовке страницы. Закрой старые окна сервера и запусти `review.bat` заново: он сам найдёт свободный порт и откроет нужный адрес (его же выводит в окне).
- **Голос не сгенерировался (`No audio received`).** Это временный сбой edge-tts, скрипт сам повторяет попытки. Если не помогло, запусти ещё раз.
- **Правка висит открытой, хотя сделана.** Нажми на заметке «✓ Сделано» или напиши Claude.
