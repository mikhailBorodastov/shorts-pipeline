# S20 — Claude везде: чат видит вкладку, умеет её кнопки, спрашивает и оставляет уведомления

Статус: ✅ сделано 5 окт 2026. Код: `server/actions.py`, `server/notify_api.py`, `server/agent.py` (сессия канала `ch-<id>`, `ctx_text`, `ASK_RULES`), `server/make3d_api.py` (`VOLUME`, `author_words`), `web/agent.js`, `web/ui/notify.js`.
Отличия от плана: смена раздела гайда (`changuide`) и «⬇ взять ассет» в реестр не вошли — первое принимает только автор на странице, второму нужна строка поиска; в чате канала гайд правится Edit-ом по прямой просьбе.

Макет — `stage20-agent-everywhere-mockup.html`.

## Зачем
Автор хочет говорить с чатом справа на любой вкладке: «ты сделал персонажей плоскими — сделай их по-настоящему 3D», и Claude сам
разбирает просьбу, ставит нужные задачи (те же, что кнопки ✨ этой вкладки), задаёт уточняющие вопросы и отчитывается.
Всё, что Claude сделал, копится в ленте уведомлений 🔔: клик → та вкладка и тот элемент, где это лежит.

Решения автора (5 окт 2026):
- чат **везде**: в окне видео — сессия видео (как сейчас), на страницах канала (Библиотека, Стиль, Обложки, Рендеры, Память, YouTube) — сессия канала;
- «по-настоящему 3D» — способ выбирает Claude, но **слова автора главнее стиля канала**: объёмный = Blender / TRELLIS / модель из ассетов, бумажную карточку (`parts`) брать нельзя;
- тяжёлое (Opus, 3D, пачка элементов) — сначала план кнопками [Делай / Изменить], мелочь — сразу;
- в ленте: готово / ошибка задач, вопросы Claude, рендеры и экспорт, итоги YouTube.

## Что есть сейчас (до S20)
- Панель агента — только в окне видео (`web/agent.js` `follow()`), одна сессия на видео (`server/agent.py SESS`).
- Контекст: этап и курсор монтажа; **открытый элемент препродакшена не передаётся** (`route.sub` не читается в `ctx()`).
- Задачи препродакшена агенту — через `agent_tools.py`: `el fix|draw|make3d|ok`, `sound …`, `add-elements`. Нет: «Накидать», split3d, vary3d, ассеты, обложки, тексты упаковки, B-roll, правка в библиотеке, правка стайл-гайда.
- `make3d._decide` не видит правок автора (`fx`, `ask`) и прямо советует `parts` для анимируемого персонажа — отсюда «объёмный» Стив выходит бумажной карточкой.
- Уведомлений нет: тост, точка на вкладке, звук; готовые задачи сервер забывает через 30 мин (в `log.txt` — строка без ссылки).

## 20.1 Чат на всех страницах + контекст вкладки
- `AgentPanel.follow()` показывает панель на всех страницах оболочки. Сессия: `video:<id>` в окне видео, `channel:<id>` — на остальных
  (лог `<канал>/agent.jsonl`, системный промпт — канал + «Память» + команды канала, без правил монтажа).
- Над полем ввода — **чип контекста** «📍 Препродакшен · Стив из Майнкрафта» (× — не привязывать к элементу в этой реплике).
- `ctx` дополняется: `page`, `tab`, `el` + имя и вид элемента (`route.sub`), открытая модалка (3D-просмотр, поп-ап), в библиотеке — предмет и версия,
  в «Стиле» — раздел. `ctx_text` пишет это строкой `[контекст: …; открыт элемент EL=… «Стив из Майнкрафта» (персонаж, 3D: parts v1)]`.
- В каждую реплику — **«что умеет эта вкладка»**: короткий список действий только текущей вкладки (из реестра 20.2), а не все сразу — экономим токены.

## 20.2 Реестр действий: всё, что умеют кнопки ✨
- `server/actions.py`: одно место, где описаны действия Claude по вкладкам — `id` задачи, вкладка, что делает (1 строка), параметры, «вес» (`light` / `heavy`), модель.
- Одна CLI-команда для агента: `studio.py act <видео|channel> <action> [--el ЭЛ] [--p '{json}']` → та же очередь `/api/claude`, `job wait` — дождаться.
  Старые `el fix|draw|make3d` остаются как короткие формы.
- Покрываем: препродакшен (`elements` «Накидать», `element`, `make3d` со всеми способами вкл. `asset`, `split3d`, `vary3d`, `assets` подобрать, `assetfetch`,
  `sound`, `charmodel`, `trellisfix`, B-roll), упаковка (`render` обложки, `packtext`), сценарий/голос — как сейчас, библиотека (`libfix`, дубль),
  стиль (`changuide` — раздел гайда, принять — только автор).
- Не даём: удаление и архив, «✓ утвердить» за автора (только по прямой просьбе), ручную расстановку `layout3d`.
- Страница сама подхватывает результат (как после кнопки): опрос `/api/revs` уже это делает.

## 20.3 Слова автора главнее стиля (make3d и черновики)
- `make3d._decide` получает: правки `fx` элемента (notes, «в целом»), `ask`, и `wish` — просьбу из чата (агент передаёт `--p '{"wish":"по-настоящему объёмный"}'`).
- Промпт: «Стиль канала — по умолчанию, если автор не сказал иначе. Просьба автора важнее». Если в просьбе «объёмный / по-настоящему 3D / не плоский» — `parts` и `shapes`-карточки запрещены,
  выбор из Blender / TRELLIS / модели из ассетов / Meshy·Tripo (при ключе); почему — в `e.make3d.why`.
- `wish` уходит и в сам черновик (`charparts`/`charblender`/`charmodel`/`element`) — раздел «Автор просит».
- Агент перед пачкой (несколько персонажей) показывает план: «Стив, Стив в скафандре, Крипер → Blender, ~15–25 мин каждый» [Делай / Изменить].

## 20.4 План и вопросы в чате
- Вопрос с вариантами `[[выбор: A | B | C]]` — во всех режимах (сейчас только в локациях); свободный вопрос — `[[вопрос]]` в конце реплики (поле ответа подсвечено).
- План тяжёлой работы — `[[план: Делай | Изменить]]` после списка шагов; «Делай» отправляется репликой, агент ставит задачи.
- Пока Claude ждёт ответа — уведомление «Claude спрашивает» (20.5) не гаснет; ответ в чате его закрывает.
- Правило промпта: heavy-действия (по реестру) — только после «Делай»; light — сразу. Неясно, к чему относится просьба, — один вопрос с вариантами, без ТЗ-анкет.

## 20.5 Лента уведомлений 🔔
- Хранилище канала: `.studio/notify/<канал>.jsonl` — `{id, ts, kind: job|ask|render|yt|error, title, text, video, videoName, el, route, job, read}`; 500 последних / 60 дней.
- Источники: завершение задачи (`ideas_api` Job → done/error, с `summary`), агент (вопрос / план / «готово» с итогом), `render_api` (ролик собран, обложки), `youtube_api` (разбор 3 / 28 дней, всплеск комментариев).
  Маршрут собирается из задачи: `kind→вкладка` (карта `TAB` уже есть в `core.js`) + `el` → `#/v/<id>/pre/<el>`.
- API: `GET /api/notify?since=` (вместе с `/api/revs`, без лишнего опроса), `POST /api/notify/read {ids|all}`, `POST /api/notify/clear {ids|video|—}` — убрать из ленты насовсем.
- UI: 🔔 в сайдбаре с числом непрочитанных; панель-лента: «Сегодня / Раньше», фильтр «это видео / все», иконка вида, имя видео и элемента, время.
  Клик → переход по `route` + подсветка элемента на 2 с; «Прочитать все», «Очистить» (всё или, с фильтром «Это видео», только его) и × на пункте. Тост и звук остаются; точки на вкладках окна видео читают ту же ленту.
