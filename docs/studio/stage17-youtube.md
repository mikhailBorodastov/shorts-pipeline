# S17. «📊 YouTube» — аналитика канала и уроки для Claude

**Статус: ✅ сделано 5 окт 2026** (макет — [stage17-youtube-mockup.html](stage17-youtube-mockup.html)). Код: `server/youtube_api.py`, `web/ui/yt.js`, `web/ui/yt.css`.

**Как сделано — отличия от ТЗ ниже:**
- **Комментарии — через yt-dlp, а не API.** `commentThreads.list` требует скоуп `youtube.force-ssl` (это право на запись) — с `youtube.readonly` Google отвечает 403. Поэтому комменты качает yt-dlp (топ-40, 2–3 с на ролик), при синке — только у роликов, где изменился счётчик, не больше 6 за раз.
- **Подключение — прямо в разделе** (пустое состояние: вставить JSON клиента → «Войти через Google» → выбрать канал; «⋯» — сменить канал, войти заново, отвязать, выйти), отдельной вкладки в ⚙ Настройках нет. Старый токен Штурма переехал сам.
- **«Типичное удержание» пунктиром не рисуется** — API не отдаёт такую кривую; вместо неё подпись по `relativeRetentionPerformance` («выше / ниже обычного для такой длины»).
- **Вехи (3 и 28 дней) разбираются сами, только если веха наступила после подключения канала** — у старых роликов «✨ Разобрать» вручную (не тратим лимит на всю историю разом); не больше трёх разборов за синк. Синк сам — раз в 6 ч, пока Studio открыта (`auto_tick`).
- Ролики моложе 4 дней Claude видит с пометкой «цифры неполные» (Analytics досчитывает удержание 2–3 дня).
- Замер: `ytlearn` — 15 с, $0,03; `ytvideo` — порядка того же.

**Зачем.** Сейчас цифры вышедших роликов автор приносит в чат руками («Итоги» и «Просмотры» убраны в S12, данные — `_archive/ideas/stats.json`).
Нужен раздел, где YouTube-канал подключён напрямую: просмотры, время, подписки, удержание по секундам, «смотрели / пролистали», источники, комментарии —
а Claude читает эти цифры и превращает их в уроки, которые дальше учитывают сценарий и все кнопки ✨.

Решения автора (5 окт 2026):
- **связь** — 1 канал Studio = 1 YouTube-канал (плашка «привязан к @…» в шапке); вход в Google один, разные каналы Studio могут смотреть разные YouTube-каналы;
- **уроки** — в «Память» как правила канала (status `new`, помечены «из статистики» и с цифрами-доказательствами); принятые уходят в промпты, как и сейчас;
- **метрики ролика** — удержание по секундам, «смотрели / пролистали» (engaged views), откуда пришли зрители, комментарии. **Не только шорты** — длинные 16:9 тоже, раздел делит «Всё / Шорты / Длинные»;
- **Claude** — кнопка «Что работает» по каналу, разбор одного ролика, идеи из комментариев, и **сам после обновления — по вехам ролика** (3 и 28 дней), а не на каждое обновление;
- **привязка роликов** — Studio подбирает пару сама и показывает с «?», автор подтверждает или выбирает другое видео; подтверждённое видео само становится «✅ вышло»;
- **где видно** — только в разделе YouTube (окно видео и плитки не трогаем).

## 1. Поток

```
⚙ / пустой раздел: «Войти через Google» ─► OAuth PKCE на 127.0.0.1 (только чтение) ─► .studio/youtube/<google>.json
        │                                     выбрать YouTube-канал ─► channel.json → youtube {id, handle, title, thumb, account}
        ▼
Раздел YouTube (#/yt) открыт и данные старше 6 ч  или  «⟳ Обновить» ─► задача ytsync (без Claude)
        │   Data API: канал, все ролики (uploads), лайки/комменты · Analytics API: ряды по дням, по роликам, удержание, источники
        │   ─► <канал>/analytics/ (кэш, вне git)
        ├─► автопривязка: ролик ↔ видео Studio (название / дата / длина) ─► «?» на чипе, автор ✓ ─► video.json → yt, status out
        └─► вехи: ролику исполнилось 3 или 28 дней и разбора этой вехи нет ─► задача ytvideo (Sonnet, 1 проход)
                 ─► разбор ролика + 0–2 урока в «Память» (new) + идеи из комментариев
«✨ Что работает» ─► задача ytlearn (Sonnet, 1 проход) ─► 3–5 уроков в «Память» (new), с цифрами
«✨ Разобрать» в карточке ролика ─► ytvideo вручную
```

Данные Analytics приходят с задержкой 2–3 дня — в шапке «по 2 окт., сравнение с 28 днями до этого», как у него. Первые сутки ролика — только счётчики Data API.

## 2. Вход в Google

- Основа — архивный `tools/archived/youtube.py` (PKCE на свободном порту 127.0.0.1, только `urllib`, без библиотек). Переезжает в `server/youtube_api.py`.
- Скоупы те же: `youtube.readonly` + `yt-analytics.readonly`. **Комментарии читаются тем же входом** (`commentThreads.list` с OAuth) — отдельный API-ключ, как у него, не нужен.
- OAuth-клиент «Desktop app»: `.studio/youtube_client.json` (переносим из `_archive/ideas/youtube_client.json`; в установщике для друзей — инструкция «создай клиента в Google Cloud», ссылка и поле «вставить JSON» в ⚙ Настройки → YouTube).
- Токены — `.studio/youtube/<email>.json` (один Google-аккаунт может владеть несколькими YouTube-каналами — после входа список каналов `channels.list?mine=true` + бренд-аккаунты; выбор в поп-апе).
- Старый токен из архива пробуем первым: если refresh жив — вход не нужен.
- Если скоуп урезан (автор снял галочку) — плашка «Не всё удалось прочитать: … Войди ещё раз и отметь обе галочки» (как на его скрине).
- «⋯» в шапке: «Сменить канал», «Выйти из Google», «Отвязать от канала Studio».

## 3. Данные

`channel.json → youtube = { id: 'UC…', handle: '@doedat', title, thumb, account: 'mail@…', linkedAt }`

Кэш `<канал>/analytics/` (в `.gitignore` канала — это кэш, всё перекачивается):
- `channel.json` — `{ at, subs, views, videos, lag: '2026-10-02', periods: { '7'|'28'|'90': { cur: {views, minutes, subsNet, avgDur, avgPct, engaged}, prev: {…}, byType: {short: {…}, long: {…}} } }, days: [{d, views, minutes, subsG, subsL, short, long}] }` — 180 дней по дням (90 + 90 для сравнения);
- `videos.json` — `[{ yt, title, published, dur, type: short|long, thumb, views, likes, comments, minutes, avgDur, avgPct, engaged, subs, shares, studio: '<id видео>'|null, guess: {video, score, why}|null, ms: {d3, d28} }]`;
- `v/<ytid>.json` — подробности ролика, качаются при открытии карточки и на вехах: `retention: [{x, watch, rel}]` (100 точек `elapsedVideoTimeRatio` → `audienceWatchRatio`, `relativeRetentionPerformance`), `traffic: [{src, views}]` (`insightTrafficSourceType`), `days: [{d, views}]`, `comments: [{id, author, text, likes, at, replies}]` (последние 50 + топ-10), `review: { d3|d28|manual: {at, text, drops: [{t, scene, why}], ideas: [...], rules: [ruleId]} }`, `snaps: {d1, d3, d7, d28}` — цифры на вехе (для сравнения роликов «на равных»).

`video.json → yt = { id, url, linkedAt, by: 'author'|'auto' }` — привязка, видна и из видео.

**Шорт или длинное** — `creatorContentType` (SHORTS / VIDEO_ON_DEMAND) из Analytics; запасной путь — длина ≤ 180 с и 9:16.
**«Смотрели / пролистали»** — только у шортов: `engagedViews / views` («остались смотреть» против «пролистали»). У длинных вместо неё — CTR показов, если API отдаст (`проверить` — в Analytics API его исторически нет, тогда колонка «—»).

Квота Data API — 10 000 единиц в сутки; полное обновление канала на 100 роликов ≈ 10–15 единиц. Analytics — без ощутимой квоты.

## 4. Автопривязка

Для каждого ролика без `studio` считается лучший кандидат среди видео канала без `yt`:
- название: совпадение с `pack.titles`, `titles[]` ★, `out/packaging.md`, именем видео (нормализовать: регистр, эмодзи, хэштеги, «?!»);
- дата: публикация не раньше последнего экспорта `out/*.mp4` и не позже чем через 14 дней;
- длина: длительность ролика ±2 с от `out/<видео>.mp4`.

`score ≥ 0.6` → чип «🔗 Имя видео ?» (жёлтый): клик — меню «✓ Да, это оно / Выбрать другое… / Не из Studio». Подтверждено → `yt` в `video.json`, `status: out` (если был другой — не трогаем `out`, только ставим).
Ниже порога — чип «—», по клику то же меню со списком видео. «Не из Studio» запоминается (`studio: false`), больше не предлагается.

## 5. Экран «YouTube» (`#/yt`, `web/ui/yt.js`, `yt.css`)

Сайдбар: новая группа **«Аналитика» → «YouTube»** под «Рендерами»; точка-индикатор, если идёт обновление, «N new», если Claude предложил уроки из статистики.

1. **Шапка:** аватар, название, `@handle · 2 290 подписчиков`, «Открыть в YouTube Studio ↗», чип канала Studio («🔗 Доедать будешь»), «⟳ Обновить» (с «обновлено 2 ч назад»), «⋯».
   Плашка ошибок/урезанного доступа — под шапкой.
2. **Фильтры:** `7 дней | 28 дней | 90 дней` · `Всё | Шорты | Длинные` · «по 2 окт., сравнение с 28 днями до этого».
3. **Четыре карточки:** Просмотры · Часы просмотра · Подписчики (`+N`, «пришло минус ушло») · Средний просмотр (`0:31`, «45 % ролика»). У каждой — дельта к прошлому периоду (зелёная/красная) и спарклайн.
   В режиме «Шорты» четвёртая — **«Смотрели»** (доля engaged views), средний просмотр — подписью.
4. **График по дням:** сплошная линия — период, пунктир — прошлый период того же размера; переключатель «Просмотры / Часы / Подписчики»; точки выхода роликов — засечки по низу (наведение — название).
5. **«Что работает» (слева)** — уроки канала из «Памяти» с источником «статистика» (принятые — белые, новые — с кнопками ✓ / ✕ / ✏ прямо тут); «✨ Спросить Claude» (= ytlearn); поле «Свой урок» + «Добавить» (в «Память», `by: author`).
6. **«Свежие комментарии» (справа)** — по всем роликам, новые сверху: автор, когда, ♥, текст, «к ролику …». Ниже свёрнуто — **«💡 Идеи из комментариев»** (от ytvideo): карточка «+ видео» создаёт видео с идеей и контекстом (вопрос зрителя + ссылка на коммент).
7. **Таблица роликов:** превью с длительностью, название, тип (шорт/длинное), дата, просмотры, часы, средний % (полоска), «Смотрели» (шорты), лайки, комменты, видео Studio (чип).
   Сортировка по любому столбцу, фильтр «Всё / Шорты / Длинные», поиск. Клик по строке — карточка ролика.
   Режим **«на равных»** (переключатель над таблицей): цифры на одной вехе — «за первые 3 дня» / «за 28 дней», чтобы старые ролики не выигрывали возрастом.

## 6. Карточка ролика (поп-ап поверх раздела)

- Превью, название, «Вышел 26 сент · обновлено 11 мин назад», «▶ На YouTube», «YouTube Studio ↗», «⟳ Обновить».
- Ряд цифр: Просмотры · Часы · Средний просмотр · Средний % · **Смотрели** (шорты) · Лайки · Комменты · Подписчики.
- **Видео Studio:** выпадающий список (с подсказкой «?»), «Открыть видео →».
- **Удержание:** кривая 0–100 % по секундам ролика, подпись «через 3 с — 78 % · середина — 52 % · конец — 31 %».
  Если ролик привязан к видео Studio — **под кривой полосы сцен** из таймингов видео (`build/vo_timing.js` / монтаж, у длинных — главы), и три самых резких спада отмечены «−18 % · сцена „Бюджет“ · 0:07».
  Пунктиром — «типичное удержание YouTube для такой длины» (`relativeRetentionPerformance`: выше/ниже нормы).
- **Откуда пришли:** горизонтальные полосы (Лента Shorts, Главная и подписки, Поиск, Страница канала, Внешние, Прочее) с числом и %.
- **Комментарии:** список с ♥; у ролика без комментариев — «Комментариев пока нет».
- **🧠 Разбор Claude:** последний разбор (3 дня / 28 дней / ручной) — 3–6 строк: что сработало, где ушли и почему (по сцене и тексту VO), сравнение со средним по каналу;
  «уроки в Память: 2 → посмотреть»; «✨ Разобрать ещё раз» (ручной, с полем «о чём спросить»).

## 7. Задачи Claude (Sonnet, без инструментов, 1 проход — бережём лимит)

Все промпты получают уже посчитанные компактные данные (таблица, ~1–3 тыс. токенов), без чтения файлов.

| задача | когда | на входе | на выходе |
|---|---|---|---|
| `ytvideo` | веха 3 д и 28 д (сама), «✨ Разобрать» | цифры ролика + среднее канала, удержание (20 точек), спады × сцены и VO (если привязан), источники, ≤ 40 комментов | `review` (текст + `drops[]`), 0–2 правила → «Память» `new`, 0–3 идеи из комментариев |
| `ytlearn` | «✨ Спросить Claude» в «Что работает» | таблица всех роликов на вехе 3 д/28 д (просмотры, %, смотрели, источники), у привязанных — хук (первая фраза VO), длина, схема; текущие правила «Памяти» (чтобы не повторять) | 3–5 правил → «Память» `new` |

Правило из статистики: `{ text, why: 'цифры: …', scope: 'channel', status: 'new', by: 'claude', from: { kind: 'yt', videos: [ytid…] } }`.
Карточка правила в «Памяти» показывает «📊 из статистики» и ссылки на ролики. Сценарист получает их как все правила (`memory_api.prompt_text`).
Веха срабатывает один раз на ролик (флаг в `ms`); если Studio была закрыта на вехе — догоняет при следующем обновлении (не старше 60 дней).
Оценка: ytvideo ≈ 4–6 тыс. токенов, ytlearn ≈ 8–12 тыс. — порядка двух-трёх кнопок ✨ «Названия».

## 8. Сервер и CLI

- `server/youtube_api.py` — вход, синк, привязка, вехи; `GET /api/yt` (сводка раздела по `period`, `type`), `GET /api/yt/video?id=` (карточка, докачка), `POST /api/yt/login|select|logout|sync|link|learn|review|lesson`.
- Задачи: `ytsync` (без Claude, в общей очереди не ждёт), `ytvideo`, `ytlearn` (через `ideas_claude`, `TEXT_MODEL`).
- `channel_api` — поле `youtube` канала; `memory_api.add(..., source)` — источник `yt`.
- CLI (для сессии Claude Code): `python _studio/server/studio.py yt status | login | channels | select <UC…> | sync | show [ytid] | link <ytid> <видео> | unlink <ytid> | learn | review <ytid>`.
  `yt show` печатает компактную таблицу — так Claude в чате отвечает на «как зашёл ролик про Росомаху?» без ручных цифр.
- Перенос: `_archive/ideas/stats.json` → первичное заполнение `snaps` у восьми старых шортов (если Analytics сейчас не отдаёт историю).

## 9. Этапы

1. **Вход и синк:** `youtube_api.py` из архивного модуля, ⚙ Настройки → YouTube, выбор канала, `ytsync`, кэш, CLI `yt status|login|sync|show`.
2. **Экран канала:** сайдбар, шапка, фильтры, карточки, график, таблица, комментарии.
3. **Карточка ролика:** цифры, удержание с полосами сцен, источники, комментарии.
4. **Привязка:** автоподбор, «?», меню, `video.json → yt`, статус «вышло».
5. **Claude:** `ytvideo` (вехи + кнопка), `ytlearn`, уроки в «Памяти» с «📊», идеи из комментариев → «+ видео».
