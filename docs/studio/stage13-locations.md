# S13. Локации и сцены-плейбек

Смена парадигмы (решения автора 3 окт 2026). Сейчас «сцена» препродакшена — всё сразу: место, расстановка, свет, камера с планами, анимации, звуки,
а таймлайн открывает её в редакторе. Теперь — разделяем **место** и **то, что в нём происходит**.

## 1. Что меняется

| | было | стало |
|---|---|---|
| Препродакшен | персонажи, пропсы, **сцены** (с камерой и движением), звуки, эффекты, B-roll | персонажи, пропсы, **локации**, звуки, эффекты, B-roll |
| Локация | — | место: окружение, расстановка пропсов, свет, **фоновая жизнь** (мерцание, дым, экран, птицы — петлёй), **именованные ракурсы** («общий план двора», «у щитовой»). Без времени: ни проходов, ни камерных проездов, ни действий. Утверждает автор |
| Сцена | элемент препродакшена | **появляется на монтаже**: локация + что в ней происходит по голосу — камера (проезды и склейки от ракурсов локации), персонажи и их действия, звуки, маркеры к словам. На одной локации — сколько угодно сцен |
| Таймлайн | живой предпросмотр, двойной клик → редактор сцены | **плейбек отрендеренных клипов сцен** (полное качество). Внутрь не зайти; правки — пинами и в чат, вносит Claude |
| Правка локации | — | меняет все сцены на ней: их клипы перерендериваются сами |

Решения автора: сцена хранит **только свои отличия поверх локации** (добавить / скрыть / сдвинуть предмет — для себя; остальное приходит из локации);
локация = окружение + пропсы + свет + фоновая жизнь, **персонажи и их действия — только в сценах**; пин на таймлайне, задевающий локацию, —
Claude **спрашивает** «во всех N сценах или только в этой»; плейбек — **сразу полное качество** (экспорт = склейка готовых клипов + звук);
редактор локации — **нынешний без таймлайна**; **только 3D** (2D — потом по тому же принципу); старые видео — как есть,
«Про металические штуки» переделываем по-новому (старые сцены и монтаж — в `_archive`).

## 2. Данные

### 2.1 Локация — элемент препродакшена `kind: "location"`
Папка как у сцены редактора: `preprod/<el>/work/scene.json` + `prefabs.js` (тот же движок `engine/scene.js`), но:
- в `scene.json` нет времени: у объектов и света нет `keys`, `clips`, `pose`, `face`, у камеры нет `keys`/`cuts`; `len` — длина петли фоновой жизни (по умолчанию 6 с);
- **фоновая жизнь** — каналы префабов (`channels`, как экран ЭЛТ) и «петлевые» параметры света (`flicker`), частицы мира (`motes`), фоновый звук локации `ambient: [{src, gain}]`;
- **ракурсы** `shots: [{ id, name, pos, target, fov, note }]` — статичные точки съёмки, утверждаются вместе с локацией;
- `rev` растёт с каждой правкой (по нему сцены знают, что надо перерендерить).

### 2.2 Сцена монтажа — оверлей поверх локации
`video.json → montage.scenes[]` (метаданные) + файл `montage/scenes/<sid>/scene.json` (оверлей):
```json
{ "schema": 1, "id": "s3", "name": "Ёжик у щитовой", "location": "e1a2b3", "locRev": 12, "len": 7.5,
  "camera": { "keys": [ { "t": 0, "shot": "u-shitovoy", "dolly": 0.4 }, … ], "cuts": [ … ] },     // ключи — от ракурсов локации (shot) или свои pos/target
  "patch":   { "o12": { "pos": [1.2, 0, -0.4] }, "o15": { "hide": true } },                      // свои отличия от объектов локации (только для этой сцены)
  "objects": [ { "id": "c1", "src": { "character": "lib:characters/hog@4" }, "keys": {…}, "clips": […], … } ],   // персонажи и добавленные предметы
  "sounds": [ … ], "markers": [ … ], "comments": [ … ] }
```
Собранная сцена = `composeScene(location, overlay)` (`engine/scene.js`): объекты и свет локации → `patch` → объекты сцены → камера сцены (ракурсы раскрываются в pos/target).
Монтаж (`montage.units`) ссылается на сцены монтажа (`scene: "m:s3"`), карта времени `map` и маркеры к словам — как сейчас.

### 2.3 Клипы
`montage/clips/<sid>.mp4` (кадр проекта, 30/60 fps, H.264 из браузера — тот же путь, что рендер ролика) + `<sid>.json` `{key, len, at}`,
где `key = hash(оверлей + rev локации + prefabs + префабы библиотеки)`. Клип устарел, если ключ не совпал → в очередь перерендера.

## 3. Этапы

### Препродакшен
- «Накидать по сценарию» предлагает **локации** (одна локация — на все куски сценария, что в ней происходят) + персонажей, пропсы, звуки.
- Черновик локации — Claude (Opus) собирает место сразу в формат редактора (как `sceneconvert`, но без времени): объекты, свет, фоновая жизнь, 3–6 ракурсов;
  кадры по ракурсам — лист черновика. Правки — пины и «в целом», как у сцен сейчас.
- «🎬 Оформить локацию» — нынешний редактор в **режиме локации**: без таймлайна и ключей; расстановка, свет, добавить предмет, свободная камера;
  панель «Ракурсы» (сохранить вид как ракурс, переименовать, удалить); фоновая жизнь играет петлёй; Claude справа.
- Утверждение ✓ — как у элементов. Монтаж разрешён, когда локации сцен утверждены (предупреждение, а не запрет).

### Монтаж
- «Сделать» (живой монтаж): Claude делит сценарий на сцены по локациям, для каждой — оверлей: камера от ракурсов (проезды, наезды, склейки), персонажи и действия
  (клипы «Умеет»), звуки, маркеры к словам. Сцены сразу уходят в рендер клипов, таймлайн заполняется по мере готовности.
- Таймлайн — плейбек клипов: сцены подряд, голос, музыка, звуки; переходы между сценами — склейкой при сборке. Двойной клик **ничего не открывает**.
- Правки: пин на кадре / сцена на таймлайне / чат → Claude правит **оверлей** сцены (`studio.py montage scene ops`).
  Правка про место (переставить, убрать, добавить в окружение) → Claude спрашивает кнопками: «во всех N сценах на «Двор» (правка локации)» / «только в этой сцене».
- Правка локации (в препродакшене руками или через Claude) → `rev` растёт → клипы всех сцен на ней перерендериваются сами; пока рендерятся — на таймлайне старый клип с плашкой «обновляется».

### Экспорт
- Склейка готовых клипов (без перерендера) + звук → `out/`. Почти мгновенно, если все клипы свежие.

## 5. Риски и решения по ходу
- **Время рендера.** Полное качество: 3D 1080×1920 ≈ 100–330 кадров/с на этой машине → 7-секундная сцена 60 fps ≈ 2–5 с. Перерендер локации с 6 сценами — до полуминуты, в очереди.
- **Персонажи в локации.** Решено: только в сценах. Фоновые «жители» (бабки на лавочке) — если понадобятся, это пропс-карточка с фоновой жизнью в локации.
- **Старые видео** работают по-старому: элементы `kind: scene` и редактор сцены остаются для них; новые видео (3D) — только локации.
- **Ручные правки сцены** невозможны из интерфейса (так задумано); аварийный путь — CLI `montage scene ops` / Claude.

## 6. Как сделано (13.1–13.6)
Отличия от плана: отдельного `kind: location` нет — локация = элемент `kind: scene` в видео с флагом `video.json → locations: true` (новые 3D-видео ставят его сами;
`mscene convert <видео>` переводит старое). CLI — `studio.py mscene …`, а не `location …` / `montage scene …`; правки сцен — обычные `scene ops` (по id сцены монтажа).
- **Данные.** Локация — `preprod/<el>/work/scene.json` без времени: `shots[]` (именованные ракурсы {id, name, pos, target, fov}), фоновая жизнь — петли объектов.
  Сцена монтажа `ms<hex>` — `video.json → mscenes[]` {id, name, location, sec} + файл `preprod/<ms>/overlay.json` (источник правды: `len`, `camera.keys`
  {t, shot, dolly, dpos, dtarget}, `objects` (персонажи с клипами), `lights`, `sounds`, `markers`, `patch` {id объекта локации: pos|rot|scale|hide}).
  `locations_api.compose(loc, ov)` собирает `preprod/<ms>/work/scene.json` + `prefabs.js` — их читает движок как обычную сцену.
- **Код.** `server/locations_api.py` (compose, recompose, new_scene, on_location_change, convert_video, бриф `locations_brief`, CLI `mscene list|new|show|compose|rm|locations|convert|to-location`);
  `scene_api.py` — `ms…` в `work_dir`, `save_scene` пересобирает сцену или (для локации) все её сцены; черновик локации после перевода в редактор теряет время (`strip_time`, ключи камеры → ракурсы).
- **Клипы.** `server/clips_api.py`: сегменты по началам юнитов, ключ = sha1(сцена + prefabs + глобальное монтажа + слова на отрезке (+ прошлая сцена при переходе)),
  `RENDER_RANGE=a:b RENDER_OUT=… node render.js frames 30 4` → `build/clips/<ключ>.mp4`, склейка `playback.mp4`; `/api/clips/state|playback|render`, задача `clips` (локальная, без очереди Claude).
  Окно видео играет `playback.mp4` (`MontagePreview.openClips`), устаревшее перерендеривает само; экспорт (`render_api`) — склейка клипов + `mix.wav`, без рендера кадров.
- **Правки.** Двойной клик по сцене на локациях не открывает редактор; агент в режимах montage/chat/build получает блок S13 и спрашивает «во всех сценах на локации / только в этой» кнопками `[[выбор: …]]`.
- **Ограничения.** Клипы — 30 fps; кадры перехода между сценами входят в клип входящей сцены (её ключ зависит от прошлой); старые видео (без флага) работают по-старому.
- **Скорость клипов (после первого прогона).** Сборка видео на локациях (`montage build`, «🔨», экспорт) всегда идёт через клипы — после монтажа агентом кэш окна готов.
  Все устаревшие клипы рендерятся одним запуском браузеров (`render.js` + `RENDER_SEGS=<json [{a,b,out}]>`), без ~15 с старта на клип.
  Тяжёлые локации упираются в видеокарту: 1 окно 27 к/с, 2 — 22, 4 — 12 («Металлические штуки»), поэтому `render.js` меряет кадр 3D-сцены и при > 12 мс рендерит в одно окно.
- **Монтаж без препродакшена (2026-10-03).** «Сделать» в шаге «Монтаж» у 3D-видео без сцен препродакшена (или на локациях) — задача `automontage`
  (`locations_api.auto_montage`, POST `/api/automontage {video, wish}`): нет локаций — Claude накидывает их по сценарию; черновики локаций — в очередь, задача ждёт
  (настоящие локации, не болванки — решение автора); потом агент монтирует (режим montage). Нужного персонажа / предмета нет — агент заводит элемент
  (`add-elements` печатает id) и ставит объект `src: {pending: <id>, h}`; `resolve_pending` при сборке сцены подставляет выбранную версию 3D элемента
  (`el:<id>@vN`) или бумажную карточку «?» с названием (`_ph:<id>` в prefabs.js сцены). После агента — `make3d` для всех элементов-заглушек в очередь;
  готовый черновик (`element`, `make3d`, `charparts`, `charmodel`, `trellisfix`) -> `on_element_ready` пересобирает сцены с ним, клипы перерендериваются сами.
- **⚡ Быстрый монтаж (2026-10-03, по умолчанию для «Сделать»).** Автор: «раньше ты собирал без препродакшена — почему так долго?» Поэтому «Сделать» в шаге
  «Монтаж» у видео без готовых сцен редактора (2D и 3D) — `POST /api/montage/fast` (`montage_api.fast_start`): флаг `video.fast`, `stands/paper.js` -> `src/paper.js`,
  агент в режиме `fast` пишет ролик кодом в `src/scenes.js`, как до Studio (CLAUDE.md, шаг A), проверяет `montage snap`, собирает `montage build`,
  а в конце заносит в препродакшен то, что вышло (`add-elements`). Генератор монтажа такой scenes.js не трогает (`generate` при `fast` — пропуск).
  Окно видео играет собранный `out/*.mp4` со звуком (`clips_api.fast_state`); код новее ролика — пересборка сама (если ролик уже был); правки — чат и пины
  (режим chat у fast-видео получает те же правила). Путь с локациями (`automontage`) остаётся для видео, где места живут долго.
- **⚡ Быстрый монтаж v2 — параллельно (2026-10-03).** Автор: «у другого автора 3D-ролик собирается за 20–30 минут, почему у нас долго?» Замер старого пути: один Opus
  5–8 мин читает движок, 10–20 мин пишет весь ролик, 5–10 мин снимает кадры, рендер 3D 60 к/с. Теперь «Сделать» = задача `fastmontage` (`server/fast_api.py`):
  prep (флаг fast, paper.js + kit2d/kit3d в проект, tts) → план и ОБЩИЙ код `src/scenes.js` (Opus, читает только `prompts/fastkit.md` — шпаргалку движка)
  → писатели сцен параллельно (Sonnet, 3–5 сразу, `src/scenes/sNN.js`, `SCENES[k] = {…}`, свои кадры `montage snap`; недописанная сцена — заполнитель
  в index.html, не падение) → сводка Opus-агентом в панели (стыки, ошибки, перенос удачного в набор деталей) → `montage build` черновиком 30 к/с
  → препродакшен задним числом из плана. Набор деталей канала — `engine/kit2d.js`, `engine/kit3d.js`, каталог `_studio/KIT.md` (растёт от ролика к ролику).
- **Быстрый монтаж берёт препродакшен (2026-10-04).** Автор: «есть в препродакшене — берём его, нет — делаем сами, как раньше». `fast_api.pack_preprod` перед планом:
  сцены / локации редактора — `montage_api._pack_scene` (вынесен из генератора) → `ppWorld(el, {build, update})`, ракурсы `ppShot`; 3D-пропсы и персонажи видео и библиотеки —
  `ppAdd(w, ref, {pos, rotY, scale})`; 2D-черновики `element.js` — в своей области видимости `PP2D[el].<функция>`; звуки — строки `add(...)`; **свой ассет автора**
  (`e.own[]` — картинка + состояние, блок «Свой ассет — в ролик как есть» в карточке элемента; «Сделать всё» такие не рисует) — `IMG.own_<el>_<n>`, вклеивать как есть.
  Всё это — в `src/montage.js` (его загрузка препродакшена всегда первая: свой `window.STUDIO_READY` сцен выполняется после неё) и списком «ПРЕПРОДАКШЕН ВИДЕО» в задании плана и писателей.
