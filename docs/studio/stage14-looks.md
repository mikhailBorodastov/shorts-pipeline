# S14. Визуалы: техники и луки, настройки, герои визуала, интервью с референсами

> Статус: **✅ сделано (3 окт 2026), 14.1–14.6** — решения автора в §1, макет — [stage14-looks-mockup.html](stage14-looks-mockup.html), устройство — §10.

---

## 0. Зачем

Сейчас «Визуалы» — список с названием, описанием, переключателем 2D/3D и референсами. Описание уходит Claude в бриф, но
**ни одна ручка не меняет картинку**, посмотреть, как выглядит визуал, негде, а герой (ёжик) прибит к каналу целиком.

Хотим, как в референсе автора (экран «Styles» чужого приложения): **техника → её луки**. У лука есть ползунки и тумблеры, которые
**реально применяются к ролику**, своё живое превью, свои герои (или ни одного). Новый лук можно собрать по референсам
и короткому интервью: Claude подберёт технику, выставит ручки, придумает свои и отрендерит пример сцены.

Плюс мелочь, которая мешает уже сейчас: во вкладках стиля **не видно, какая выбрана** (`a.btn.sel` без стиля; `button.sel` есть, а вкладки — ссылки).

## 1. Решения автора

| вопрос | решение |
|---|---|
| Иерархия | **два уровня: техника → луки**. Техника — чем рисуется кадр (2D-аппликация, 3D-диорама, своя по референсам). Лук — набор настроек этой техники + герои + палитра + превью |
| Встроенные | **править можно**, у изменённого — «↺ к заводским» |
| Ползунки | **реально применяются к ролику** (`window.LOOK` в проекте, движок читает) |
| ✨ по референсам | Claude выбирает технику, выставляет ручки и **придумывает свои** (пишет код примера сцены под них); новую технику или новый лук в имеющейся — **решает сам** и объясняет почему |
| Герои | у лука: **без героя**, **персонажи из библиотеки**, **описать нового → сделать**; **несколько героев** (главный + остальные) |
| Превью | **сцена под лук, живой просмотр** в панели, пока крутишь ручки; mp4 для наведения переснимается **сам в фоне** после правок |
| Вкладки | **сократить**: Обзор · Подачи · Визуалы · Голос и субтитры · Стайл-гайд · Правила · Интервью. «Герой» и «Палитра» → в лук (шрифты — к субтитрам), «История» → кнопка в гайде |
| Старые видео | ссылаются на лук и **подхватывают правки при пересборке**; у вышедших (`status: out`) настройки замораживаются |
| В видео | **в брифе видео** можно подкрутить лук и героев только для этого видео (перекрытия поверх лука) |
| Переезд «Доедать будешь» | луки переезжают **без героев** — автор настроит сам |
| Интервью | **своё короткое интервью у каждого нового лука** (5–8 вопросов по референсам); интервью канала остаётся для гайда, подачи, голоса |
| Референсы в интервью | общая полка в начале, вложения к ответу, **видео с таймкодом** (кусок «с–по»), **🔎 поиск картинок** (Яндекс / свободные, `imgsearch.py`) |

## 2. Данные

### 2.1 Канал (`channel.json`)

```js
techniques: [{
  id, key: 'paper' | 'diorama' | <свой>, label, icon, desc,
  engine: '2d' | '3d',
  builtin: true,                    // из ref.json (стартовые), иначе — собран Claude
  controls: [Control],              // ручки техники (у встроенных — из ref.json, у своих — от Claude)
  scene: 'style/tech/<key>/scene.js' | null,   // демо-сцена техники; null — встроенная stands/looks/<key>.js
}],
looks: [{
  id, key, tech: '<key техники>', label, desc,
  builtin: true, factory: { params, desc, palette } | null,   // заводские значения — для «↺ к заводским» и пометки «изменён»
  params: { 'fx.bloom.intensity': 1.2, 'paper.edge': 1.4, 'custom.outline': 3, … },
  extra: [Control],                 // свои ручки лука (Claude придумал под референсы), поверх ручек техники
  scene: 'style/looks/<key>/scene.js' | null,  // свой код примера (если extra требует), иначе — сцена техники
  palette: { colors: [{name, hex, use}] },
  heroes: [{ id, kind: 'lib' | 'desc', ref: 'lib:characters/<slug>@N', name, desc, character, role: 'main' | '' , video?: <id видео героя> }],
  refs: [Ref],                      // как сейчас: {id, img | url, note, from?, to?}
  interview: { qa: [{id, q, why, a, refs: [Ref]}], done },
  preview: { video: 'style/looks/<key>/preview.mp4', poster: '…/poster.jpg', sig, ts, status: '' | 'queued' | 'running' | 'error' },
  build: { why, note, ts },          // что решил Claude в ✨ (техника / лук, почему)
}]
```

`Control` = `{ key: 'fx.bloom.intensity', label, hint, type: 'toggle' | 'slider' | 'select' | 'color', min, max, step, options: [[v, label]], default, group }`.
Ключ — путь с точкой в `window.LOOK`. Включатель эффекта — `<эффект>.on`, его ползунки — рядом (`fx.dof.on` + `fx.dof.range`):
в интерфейсе ползунки выключенного эффекта бледнеют.

### 2.2 Видео (`video.json`)

```js
brief: { …, look: '<key лука>', lookOver: { params: {…}, heroes: null | [Hero] } }   // перекрытия только для этого видео
lookSnap: { params, heroes, palette, ts }   // заморозка при статусе «✅ вышло»
```

`brief.look` старых видео — ключ старого визуала; после переезда ключи луков те же (`paper`, `diorama`, `noir`), видео не ломаются.

## 3. Экраны

### 3.1 Вкладки стиля

`Обзор · Подачи · Визуалы · Голос и субтитры · Стайл-гайд · Правила · Интервью` — сегментированная полоса (как «Built-in / Custom» на скрине):
выбранная — светлая плашка с тёмным текстом, остальные — приглушённый текст. Старые адреса `#/style/hero|look|history` переадресуют
(`hero` и `look` → `#/style/looks`, `history` → `#/style/guide`, там «🕘 История» кнопкой).

### 3.2 «Визуалы»

Сверху: заголовок «Визуалы», строка-пояснение, переключатель **Все · Встроенные · Свои**, кнопка **«+ Новый визуал»**.

1. **Карточки техник** в ряд (иконка, название, «N луков», описание одной строкой). Выбранная — с рамкой акцентного цвета.
   Под рядом — описание выбранной техники полностью (что за движок, где сильна).
2. **«Луки в технике»** — слева колонка плиток лука: превью-постер 16:9 / 9:16 (по формату канала по умолчанию), название, 🔒-значок нет — вместо него
   метка «встроенный» / «изменён», описание в две строки, «N видео». **Наведение — превью играет** (`<video muted loop>` поверх постера, `play()` на mouseenter, `pause()` + в начало на mouseleave).
   Нет mp4 — постер; идёт пересъёмка — тонкая полоска прогресса по низу плитки.
3. **Панель лука** справа:
   - шапка: название (правится), метки «встроенный · изменён», «↺ к заводским», «⧉ Дублировать», «🗑», «N видео» (клик — список);
   - **Описание** (одно поле — уходит Claude в бриф);
   - **Живое превью**: стенд в iframe (2D `stands/page.html`, 3D `/tpl/stand3d.html`) с демо-сценой; ручки шлют `postMessage({look})`,
     стенд пересобирает `window.LOOK` без перезагрузки (2D — сразу; 3D — `w._post()` заново, это дёшево). ▶/⏸, таймлайн 0…len;
   - **Настройки** — сетка в две колонки, как на скрине: подпись + подсказка слева, контрол справа (тумблер / ползунок со значением / выпадашка / цвет).
     Группы: «Свет и эффекты», «Цвет», «Бумага», «Своё (от Claude)». Изменённые относительно заводских — точка у подписи;
   - **Герои**: чипы героев (превью из библиотеки, имя, ★ главный), «+ из библиотеки» (выпадашка персонажей канала с картинками),
     «+ описать нового» (имя, внешность, характер, референсы → «🦸 Сделать» = нынешний `hero_setup`, но от лука), «без героя» — когда список пуст, так и написано;
   - **Палитра** лука (как нынешняя вкладка, только у лука);
   - **Референсы** лука (как сейчас) и ссылка «интервью лука (N ответов)».
4. Правки сохраняются операциями в `channel.json` (как всё на странице). Через ~2 с после последней правки — в очередь фоновая задача
   `lookprev` (без Claude): mp4 для плиток и поп-апа «Новое видео».

### 3.3 «+ Новый визуал» — мастер с интервью

Шаг 1 **Референсы** — полка: картинки (перетащить / Ctrl+V / файл), ссылки на видео с полями «с» и «по» (`02:10`–`02:25`; без — весь ролик),
**🔎 Найти картинки** (панель `ImgSearch` из `core.js`: Яндекс Картинки / свободные; выбранные ложатся на полку). Подпись «что взять» у каждого.
Видео разбираются в фоне `refvideo.py` (кадры куска сеткой, речь не нужна) в `style/looks/<key>/refs/<id>/`.

Шаг 2 **Интервью** — «✨ Вопросы»: Claude смотрит полку и задаёт 5–8 вопросов про этот вид («контур толстый, как на рефе 2, или тоньше?»,
«нужен постоянный герой? кто?», «2D или объём?»). К ответу можно приложить картинку, ссылку на видео с таймкодом или найти картинку поиском.
«+ ещё вопросы», «+ свой вопрос», пропуск — как в интервью канала.

Шаг 3 **«✨ Собрать визуал»** (Opus): техника (имеющаяся или новая) и почему, лук: название, описание, значения ручек, свои ручки
и код примера сцены под них, палитра, предложение по героям (из библиотеки или описанием). Claude сам снимает кадры (`render_shot.js`),
смотрит и правит 2–3 прохода, сервер снимает mp4. Результат открывается в панели лука — дальше крутишь руками.

### 3.4 Поп-ап «Новое видео» и бриф

Выбор визуала — плитки луков (с наведением-превью), сгруппированные по техникам; под выбранным — его герои.
В «Основе видео» (`Panels.base`) — «Настроить для этого видео»: те же ручки и герои, правки пишутся в `brief.lookOver`, рядом «↺ как в луке».
Смена лука меняет движок, как сейчас (`set_brief`), и бриф-строки `Визуал:` / `Герои:`.

## 4. Как настройки попадают в ролик

- `window.LOOK` = вложенный объект из `params` лука + `brief.lookOver.params` (+ заморозка `lookSnap` у вышедших).
  Пишется в `src/format.js` проекта рядом с `FRAME_SIZE` — его уже подключают все `index.html` проектов.
  Пишут: `montage_api` (генерация), `ideas_api.produce`, `videos_api.set_brief`; общий помощник `looks_api.format_js(plan)`.
- Читают:
  - 2D-тулкит (`paper.js`): `paper.grain`, `paper.edge`, `paper.shadow`, `paper.drift` — множители (1 = как было);
  - кадр (`main.js`): `post.vignette`, `post.sat`, `post.tint` + `post.tintA`, `post.warm` (`lookPost` после сцены, до субтитров);
  - 3D (`stage3d.js`, `lookFx`): `fx.*` поверх fx каждого мира — `on: false` выключает эффект, `on: true` включает с умолчаниями (`FX_ON`);
    время суток и свет решает сцена, не лук;
  - свои ручки (`custom.*`) — код сцен: Claude получает их в брифе («ручки лука и что делают») и читает `LOOKV('custom.outline', 2)`.
- Бриф (`videos_api.brief_text`): `Визуал: техника / лук — описание`, `Настройки лука: …` (человеческим языком, только изменённые),
  `Герои: …` или `Герои: нет постоянного героя — персонажи по сюжету`.

### 4.2 Встроенные техники и луки (стартовые, правятся)

- **Бумажная аппликация** (2D) — «Тетрадь и крафт» (как ролики канала сейчас), «Газетный коллаж» (сильное зерно, грубая кромка, приглушённый цвет),
  «Нуар» (без цвета, жёсткие тени, сильная виньетка, один акцент — `post.tint`).
- **3D-диорама** (3D) — «Paper Mario: тёплый макет» (мягкий свет, белая кромка карточек, без размытия), «Octopath HD-2D» (свечение, тилт-шифт, глубина резкости, зерно).

## 5. Превью

- **Демо-сцена техники** — `stands/looks/paper.js`, `stands/looks/diorama.js`: 4–6 с петлёй, фон, пара предметов, плашка-заметка, и **герои лука**
  (`LOOK.heroes`: картинка из библиотеки — вырезкой / `spriteCard`; без героев — сцена без персонажа). Свой лук / своя техника — `scene.js` от Claude по тому же контракту.
- **Живое** — стенд в панели, ручки через `postMessage`.
- **mp4** — задача `lookprev` (локальная, `LOCAL_KINDS`): `render_clip.js` 4 с → ffmpeg 360 px по ширине → `preview.mp4` + `poster.jpg`;
  `sig` = хэш(params, heroes, palette, scene) — не пересниматься без изменений. Очередь одна на канал: новая правка отменяет ждущую.

## 6. Задачи Claude

| задача | модель | что |
|---|---|---|
| `lookq` | Sonnet + Read | вопросы интервью лука по полке референсов и уже данным ответам |
| `lookbuild` | Opus (`VISUAL_MODEL`) + Read/Write/Edit + `node render_shot.js` | техника или лук, ручки, свои ручки, код сцены, палитра, герои; 2–3 прохода со снимками; затем `lookprev` |
| `lookhero` | (локальная) | «🦸 Сделать» героя лука — нынешний `hero_setup`, элемент-персонаж с референсами героя лука |

## 7. Переезд (`tools/migrate_s14.py`, однократно, с копией `channel.json` в `style/.history`)

- `looks[]` с `engine` → техники `paper` (2d) / `diorama` (3d) + луки с теми же ключами; описание и референсы — как были; `params` — заводские значения техники.
- Палитра канала (`style/palette.json` → colors) копируется в каждый лук; шрифты остаются в `palette.json` и показываются в «Голос и субтитры».
- Герои: у «Доедать будешь» — **пусто** (решение автора). Старое `channel.hero` и `rules.hero` переносятся в `heroLegacy` (не теряются, нигде не используются).
- `chanstyle` («✨ Собрать стиль» по интервью канала) по-прежнему пишет `channel.hero` — это только описание из интервью; в ролики идут герои лука.

### 10.1 Свои визуалы у каждого канала (после S14, 3 окт 2026)
Автор завёл канал Drugan под новое направление, а в «Визуалах» оказались луки «Доедать будешь» — переезд копировал все стартовые луки из `ref.json`.
Теперь: новый канал получает **только техники** (движки), своих луков нет. Луки `ref.json` — каталог шаблонов: в пустой технике «+ взять в канал» (`/api/looks/take`).
Первый визуал канала собирается из его интервью: «✨ Собрать стиль» (`chanstyle`) в конце, если своих луков нет, вызывает `looks_api.from_interview` — черновик лука
с ответами блока «Визуал и герой» и референсами интервью (полка `interview.refs` + вложения к ответам) → `lookbuild` (в промпт — ещё начало стайл-гайда и палитра канала).
То же — кнопкой «✨ Собрать визуал из интервью канала» в пустой технике (`/api/looks/from-interview`). Выбор лука в поп-апе и брифе — только луки канала (`Styles.looks`).
