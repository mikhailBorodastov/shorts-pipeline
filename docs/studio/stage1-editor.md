## 1. Что получает автор

1. В карточке 3D-сцены препродакшена — кнопка **«🎬 Оформить сцену»** (вместо «✋ Расставить»). Если версия ещё старого формата — предложение «Перевести сцену в редактор (Claude, ~5–10 мин)».
2. Редактор на весь экран: `#/p/<plan>/pre/<el>/stage`, Esc (вне полей) или «← Препродакшен» — назад.
3. В редакторе: расставить, повернуть, масштабировать, сгруппировать, дублировать, скрыть, удалить; ключи движения объектов и камеры; склейки-планы камеры;
   маркеры; звуки препродакшена на таймлайне; отмена и повтор; автосохранение и версии; mp4 сцены; простая просьба агенту.

## 3. Данные и файлы

- Рабочая копия: `<канал>/videos/<видео>/preprod/<el>/work/scene.json` + `prefabs.js` + `history.jsonl` (формат — [architecture §3.3–3.4](architecture.md#33-сцена-scenejson--главный-формат-редактора)).
- JSON-схема: `engine/scene.schema.json`; сервер проверяет каждую запись.
- Документ для операций: ключ `scene:<plan>/<el>` в `ideas_api` (тот же `apply_op`, пути через `id`), файл — рабочий `scene.json`.
- **Версия** («💾 версия», Ctrl+S, и после каждой правки агента): `v<N>/` = копия `scene.json` + `prefabs.js` + кадры `element.png`, `element_*.png` (со стенда в режиме сцены)
  + запись в `renders[]` элемента `{…, "stage": true, "scene": "v<N>/scene.json"}` — карточка препродакшена показывает её как обычную версию.
- `authored`: каждая операция автора добавляет путь; агент получает список и не трогает его без прямой просьбы (валидатор на сервере).

## 4. Движок (`engine/scene.js`)

- `buildFromScene(w, scene, PREFABS)` → `{ objects: Map(id → THREE.Object3D), camera, lights }`; группы — `THREE.Group`, дети внутри.
- `applyScene(S, t)`: для каждого объекта — статичные значения или `evalKeys` по `pos / rot / scale / hide`; камера — ключи внутри сегмента между `cuts`
  (склейка = без интерполяции через неё); `handheld` — шум от `t`; свет — позиция и `intensity` по ключам. Карточки и префабы с `dynamic` перерисовываются от `t` как сейчас.
- `evalKeys(keys, t, base)`: `linear | io | in | out | hold`; вне диапазона — крайние значения; углы — без скачка через ±π.
- Стенд: `stand3d.html?stage=/rscene/<plan>/<el>/work/scene.json&prefabs=…` — строит сцену из данных (для рендера кадров, клипа и редактора — один код).
- Тесты `engine/test/scene.test.js` (node, без браузера): интерполяция, ease, hold, склейки, группы, углы. Запуск — `node engine/test/scene.test.js`.

## 5. Конвертер старой сцены (`sceneconvert`, Opus)

Вход — `element.js` выбранной версии (+ блок расстановки `w.groups / w.layout`, если есть). Выход — `work/prefabs.js` + `work/scene.json`.
- Каждый предмет — объект с человеческим `name` (элементы состава — их названия из препродакшена, `src.el` — их id); повторяющиеся (ели, книги) — один префаб, много объектов; составное — группа.
- Окружение (стены, пол, окно, небо) — префаб `env`. Свет — `lights[]`. `camKeys` → `camera.keys` (+ `handheld`, `fov`).
- Движение из `update()`: простое (переезд, поворот) → ключи; сложное (метель, мерцание экрана, пар от чая) — внутри префаба от `T`.
- Расстановка и группы автора из старого блока — переносятся (сдвиги уже вписаны в позиции, группы — в `type: group`) и помечаются `authored`.
- **Проверка:** стенд рендерит старую и новую версию на `t = 0.6, 2.5, len − 0.5`, сервер считает разницу пикселей (PIL: средняя разница и 95-й перцентиль).
  Порог: средняя < 4/255 и перцентиль < 24/255 — иначе Claude правит (до 3 проходов), затем показать автору кадры «было / стало» с предупреждением.
- Промпт — в `ideas_claude.py` (`sceneconvert_spec`), инструменты: Read/Write/Edit + `node render_shot.js` + `python scene_diff.py`.

## 6. Редактирование

**Выбор:** клик в 3D-виде (прозрачные края карточек не ловятся — как сейчас в стенде) или в дереве; Shift+клик — добавить; A / Alt+A; клик по части группы — группа, Alt+клик — часть
(как в нынешнем «✋ Двигать»), двойной клик по группе в дереве — войти внутрь.
**Трансформации:** гизмо `TransformControls` (three r186 examples, MIT — скачать в `vendor/`) + модальные G / R / S как в Blender: движение мыши, оси X / Y / Z, Shift+ось — плоскость,
ввод числа («G X 0.5 Enter»), Ctrl — шаг сетки 0.1 м / 15°, Esc или ПКМ — отмена; одна трансформация = одна операция.
**Разумные пределы:** как в нынешнем стенде (±12 м по полу, −2…+6 м по высоте, ×0.25…4) — предупреждение, а не запрет, если автор ввёл число руками.
**Свойства:** числа позиции (м), поворота (°, только Y по умолчанию; X / Z — раскрыть), масштаба, видимость, блокировка (не выбирается в виде), источник (элемент, префаб), параметры префаба.
Колёсико над числом — ±шаг, перетаскивание по подписи — плавно (как в Blender).
**Дерево:** виртуальный список (сотни объектов), поиск, группы сворачиваются, перетаскивание в группу / из группы, переименование F2, иконки типа, ◆ у анимированных, 👁 и 🔒 в строке.
Клавиатура: ↑↓ по дереву, → / ← раскрыть / свернуть, Enter — выбрать, F2 — переименовать.
**＋ Добавить (Shift+A, кнопка «＋ добавить»):** меню с поиском — предметы из `prefabs.js` этой сцены (кроме `env`; у префаба с `home` — на его месте), 3D-пропсы и персонажи видео и библиотеки канала (`/api/scene` → `props3d`, `chars3d`), пустая группа; новый объект встаёт в центр вида на пол и сразу в режиме G (Esc — оставить в центре). Новых предметов по описанию тут нет — препродакшен или 💬 агент.
**Дубль / удаление / скрытие:** Shift+D (дубль сразу в режиме G), X / Delete (с подтверждением, если объект из состава препродакшена), H / Alt+H.
**Группы:** Ctrl+G (имя — в дереве сразу в режиме переименования), Ctrl+Alt+G — разгруппировать.

## 7. Время и ключи

- **Автоключ ⏺** (по умолчанию включён, клавиша — кнопка в шапке):
  у свойства **без ключей** правка меняет статичное значение (анимация не начинается); у свойства **с ключами** правка ставит / обновляет ключ на текущем времени.
  I — ключ всех трансформаций выбранного на текущем времени (начать анимацию), Alt+I — удалить ключи на текущем времени.
- **Таймлайн** (canvas): линейка секунд и кадров, курсор (клик / перетаскивание по линейке), рабочая область I / O (петля воспроизведения), масштаб колесом с Ctrl, прокрутка — колесом.
  Дорожки: маркеры · камера (ключи + ✂ склейки) · объекты (свёрнутая строка — все ключи объекта; раскрытая — pos / rot / scale / hide / свет: intensity) · звуки.
- **Ключи:** клик — выбрать (и объект), рамкой — несколько, Shift — добавить; тянуть — сдвиг во времени (прилипает к кадрам, к курсору и маркерам; Alt — без прилипания);
  Delete — удалить; ПКМ — меню ease (linear / плавно / вход / выход / стоп-кадр), копировать / вставить (Ctrl+C / Ctrl+V на курсор); двойной клик — перейти к моменту.
- **Воспроизведение** (Premiere): пробел, J / K / L (назад / стоп / вперёд, повтор — быстрее), ← / → кадр, Shift+← / → 5 кадров, ↑ / ↓ предыдущий / следующий ключ, Home / End.
  Воспроизведение в реальном времени (пропуск кадров, если не успевает), звуки дорожки играют синхронно (WebAudio, как «▶ Слушать вместе» сейчас).
- **Маркеры:** M — маркер на курсоре (имя сразу вводится), перетаскивание, двойной клик — переименовать. Это будущие якоря к словам голоса (S6).
- **Длина сцены:** поле в шапке таймлайна (любая, по умолчанию из черновика); укорачивание не удаляет ключи за концом, а показывает их серыми.

## 8. Камера

- В дереве — «🎥 Камера»; выбрал — гизмо двигает камеру, у цели (`target`) своя ручка; в свойствах — fov, handheld, фокус.
- **Numpad 0** — основной вид «глазами камеры» (и обратно); **Ctrl+Alt+Numpad 0** — «ключ с этого вида»: камера сцены = текущий вид редактора, ключ на курсоре (или обновление ключа).
  Кнопка «🎥 ключ с этого вида» в шапке — то же для тех, у кого нет Numpad.
- В 3D-виде: путь камеры линией через ключи, маленькая рамка кадра в каждом ключе; выбранный ключ — большая рамка.
- «Глазами камеры»: кадр 9:16 с затемнением вне кадра и безопасными зонами (субтитры y 1400–1540, плашка 170–250, поля 60 px, правый и нижний край интерфейса Shorts) — переключатель «зоны».
- **Склейки** (планы): C на курсоре или ✂ на дорожке камеры; ключи по разные стороны склейки не интерполируются между собой.

## 9. Звуки и маркеры

- Дорожка звуков: звуки элементов препродакшена этой сцены (`sounds[]` в `scene.json`: момент, громкость, пометка) — перетаскивание, ПКМ «убрать», «+ звук» из элементов-звуков штурма.
- Нет подходящего звука — комментарий «💬 Claude, подставь звук на 1.2 с (щелчок ЭЛТ)» уходит в пометки (сделать — в S7 или кнопкой «✨ подобрать» на элементе, как сейчас).

## 10. Отмена, история, версии

- Все правки — операции ([architecture §5](architecture.md#5-операции-история-отмена)), пачкой на одно действие (перетаскивание, G…Enter, дубль).
- Ctrl+Z / Ctrl+Shift+Z (и Ctrl+Y) — стек пачек в браузере; правка агента — одна пачка. Панель «История» (в меню ☰): список `desc` с автором, клик — откатить до этой точки (новой пачкой).
- Автосохранение: операции сразу уходят на сервер (как сейчас в «Штурме»); индикатор «сохранено / сохраняю».
- «💾 Версия» / Ctrl+S — снапшот `v<N>` + кадры + запись в `renders[]` (раздел 3). Переключение версий — в шапке (открыть v3 только для просмотра / «сделать рабочей копией»).

## 11. Клип сцены

- «🎞 клип» → задача `sceneclip`: `render_clip.js` снимает кадры стенда в режиме сцены (1080×1920, 30 к/с, как рендер ролика: JPEG, несколько вкладок) → ffmpeg → `work/clip.mp4`
  (+ звуки дорожки сведены, если есть). Прогресс в шапке, по готовности — плеер во всплывающем окне и «📂 открыть папку».
- Цель скорости: «Комната» 10 с — не дольше ~30 с на RTX 4070 Ti.

## 12. Агент (простой, S1)

- Панель справа («/» или «💬 агент»): поле ввода, лента ответов. Одна просьба = задача `sceneagent` (`claude -p`, Sonnet; переключатель Opus).
- Claude получает: `scene.json`, `prefabs.js` (для чтения), хвост `history.jsonl` («что сделал автор»), список `authored`, кадр текущего момента (PNG, Read), выбранные объекты и время курсора.
- Отвечает JSON по схеме: `{ reply, desc, ops[] }` (операции над `scene.json`) и, если надо, `prefabs` (новая версия `prefabs.js` — только если просьба про вид предмета).
  Сервер проверяет операции (схема, `authored`, пределы), применяет одной пачкой, рендерит кадр для ленты. Отмена — Ctrl+Z или «↺» у ответа.
- Пока задача идёт — редактор сцены только для просмотра (плашка «Claude работает… ✕»).
- Живой лог, сообщения посреди работы, комментарии на объектах — это S7.

## 13. Интеграция со «Штурмом»

- Карточка сцены: «🎬 Оформить сцену» (новая версия формата) / «Перевести в редактор» (старая); картинка версии — кадр редактора.
- `element_spec` (кнопка «Поправить» / «🎨 Нарисовать» у сцены в новом формате): Claude правит `prefabs.js` и `scene.json` через операции (не переписывает файл целиком),
  соблюдает `authored`, результат — новая версия. Старые версии (`element.js`) рисуются как раньше.
- «✋ Расставить» и блок `w.layout / w.groups` остаются только для старых версий; конвертер их поглощает.
- Экспорт в проект (`preprod.export`): у сцены нового формата в папку элемента кладутся `scene.json`, `prefabs.js`, `clip.mp4`, README объясняет, как собрать её в ролике
  (`buildFromScene` + `applyScene` из `scene.js` шаблона).

## 16. Приёмка (автор проверяет сам)

1. «Комната зимним утром» переведена в редактор; кадры «было / стало» почти не отличаются; в дереве человеческие имена (стол, монитор, лампа, ёжик…), мебель — группой.
2. Стол с монитором сдвинуты G, кресло повёрнуто R, книга на полке продублирована Shift+D и поставлена рядом; всё отменяется Ctrl+Z и возвращается Ctrl+Shift+Z.
3. Камера: 4 ключа (общий план → наезд на ёжика → склейка → крупно монитор), один из них — «ключ с этого вида»; «глазами камеры» с безопасными зонами.
4. Ёжик: 2 ключа позиции (подъезжает к столу), ease «плавно».
5. Маркер «чешет затылок», звук «гул системного блока» на дорожке, играет при воспроизведении.
6. «💾 версия» → в карточке препродакшена новая версия с кадром; «🎞 клип» → mp4 10 с.
7. Агенту: «поставь лампу на стол и включи её потеплее» — одна пачка, видна в истории, отменяется.
8. Хоткеи из [architecture §8](architecture.md#8-хоткеи) работают; всё доступно с клавиатуры (дерево, свойства, таймлайн).
9. Старые сцены других штурмов (склон «Про Дэйва») открываются как раньше, «✋ Расставить» у них работает.
