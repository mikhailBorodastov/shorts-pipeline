## 0. Зачем и что меняется (коротко)

Сейчас видео идёт по 8 вкладкам (Идея → Вопросы → Название → Сценарий → Препродакшен → Голос → Монтаж → Упаковка), и каждая вкладка — отдельная страница.
Автор хочет **одно рабочее окно видео**, как в монтажке: пайплайн слева, плеер и таймлайн в центре, Claude справа. Вход в видео — поп-ап «Новое видео», после которого Claude **сразу**
ресерчит и пишет сценарий. Плюс новые разделы студии: **Обложки** (нодовый канвас + генерация картинок по API), **Рендеры** (очередь и список готовых), **Память** (правила из правок),
**Стиль** (подачи и визуалы с референсами). Библиотека упрощается: смотреть ассеты и править их с Claude, как в препродакшене; редакторы скелета и мастерские из неё уходят.

| | было | стало |
|---|---|---|
| Главная | 🏠 канал: список видео по статусам + мини-библиотека | **Видео**: сетка карточек с обложками, поиск, фильтры |
| Боковая панель | канал, «+ шортс / + длинное», Проект / Библиотека / Стиль / Настройки, 12 последних видео | лого, канал, ⌘K-поиск, **Библиотека · Видео · Редактор**, раздел «Студия»: **Стиль · Память · Обложки · Рендеры**, внизу Настройки |
| Старт видео | Идея → 15–20 вопросов → углы названий → «🚀 Начать производство» | поп-ап «Новое видео» → проект создаётся сразу → Claude ресерчит и пишет |
| Видео | 8 вкладок-страниц | одно окно: пайплайн · плеер+таймлайн · чат Claude |
| Сценарий | iframe раскадровки с сервера проекта | окно «Сценарий» в студии: раскадровка, правки, источники, версии |
| Монтаж | «✨ Смонтировать» → потом смотрим | «▶ Сделать» → монтаж **в прямом эфире**, смотреть и помечать можно сразу |
| Обложки | концепты, «🎨 Отрисовать» кодом | раздел «Обложки»: канвас нод (картинки, промпты, текст → генерации) + режим «просто промпт» |
| Экспорт | «🔨 Собрать», один «готовый ролик» | окно «Экспорт» (имя, .srt, главы) → очередь «Рендеры», уведомление |
| Тема | тёмная, эмодзи-иконки, фиолетовые градиенты | тёмная «как в референсе»: почти чёрный фон, серые панели, белые главные кнопки, линейные иконки |

## 1. Дизайн-система

### 1.1 Ощущение (по скриншотам)
- Почти чёрный фон окна, панели на тон светлее, тонкие границы 1px, **без** градиентов и цветных заливок кнопок.
- Главная кнопка — **белая «таблетка»** с чёрным текстом («+ New project», «Export»). Остальные — тёмные таблетки с тонкой обводкой или «призрачные».
- Цвет — только как сигнал: зелёный («Ready», «Applied»), синий/бирюзовый (активное, «Editing»), красный (удалить, ошибка), жёлтый (маркеры, пометки).
- Шрифт — Inter (интерфейс), моноширинный для таймкодов и путей. Caveat — только в логотипе.
- Иконки — **линейные (Lucide)**, 16–18px, обводка 1.5. Эмодзи из интерфейса убираем (кроме пользовательского контента).
- Скругления: карточки 12–14px, поля 10px, таблетки — полные. Отступы — сетка 4px.
- Подсказки серым мелким текстом прямо под элементом («Click to select · drag to scrub…») — так же делаем у таймлайна, поп-апов и полей.

### 1.2 Токены (`web/ui/tokens.css`) — стартовые значения, сверить пипеткой со скриншотами
```css
:root{
  --bg:#0e0e10;        /* окно */          --bg-raise:#151517;  /* панели, сайдбар */
  --card:#1b1b1e;      /* карточки */      --card-hover:#222226;
  --field:#121214;     /* поля ввода */    --line:#2a2a2e;  --line-strong:#3a3a40;
  --text:#ececee;      --text-dim:#9a9aa2; --text-mute:#62626a;
  --primary-bg:#f2f2f2; --primary-fg:#111;  /* белая таблетка */
  --ok:#3ddc97; --info:#5aa9ff; --warn:#f5c04a; --danger:#ff5a5f; --agent:#b48cff;
  --r-sm:8px; --r:10px; --r-lg:14px; --r-pill:999px;
  --font: Inter, "Segoe UI", system-ui, sans-serif; --mono: "JetBrains Mono", Consolas, monospace;
}
```
- Все цвета — только через токены (сейчас в `app.css` много захардкоженных `#2d2d31`, `#5a1830` и градиент `button.claude` — убрать).
- Светлую тему **не делаем** (автор просил тёмную); токены оставляют дверь открытой.

### 1.3 Компоненты (один набор на всё приложение и редактор)
`Button` (primary / secondary / ghost / danger, размер s/m), `IconButton`, `Pill`/`Chip` (фильтры, статусы, чипы выделения в чате), `Field` (+ подпись и серая подсказка),
`Select`, `Dropzone` («Choose audio file… or drop it here»), `Modal` (заголовок, × справа, футер с кнопками справа), `Drawer`, `Tabs` (сегменты-таблетки «Chat | History»),
`Card` видео, `Toast`/уведомление, `ProgressBar` (с подписью «450 / 36044 frames · 249 fps · ~2m 23s left»), `Kbd` (Ctrl K), `Tooltip`, `ContextMenu`, `EmptyState`
(иконка + строка + 1–2 кнопки, как «Drop images here, or start with a prompt»).

### 1.4 Иконки
Lucide (ISC-лицензия) — **кладём локально** SVG-спрайтом в `web/ui/icons.svg` (без CDN: приложение офлайн). Нужный набор ~60 иконок.

### 2.2 Глобальный поиск (Ctrl K)
- Ищет по **текущему каналу**: видео (имя, тема, текст сценария), элементы препродакшена, ассеты библиотеки, рендеры, правила памяти.
- Тот же ввод — **команды**: «новое видео», «экспорт», «открыть папку», «перейти: Стиль»…
- Результаты группами, ↑↓ Enter, Esc. Сервер: `GET /api/search?q=` (простой индекс в памяти, пересобирается по `rev`).

### 2.3 Маршруты
`#/videos` (главная), `#/v/<id>` (рабочее окно видео; `?panel=script|pre|export`), `#/v/<id>/pre/<el>` (карточка элемента), `#/lib`, `#/lib/<kind>/<slug>`,
`#/style[/<tab>]`, `#/memory`, `#/thumbs[/<board>]`, `#/renders`, `#/settings`. Старые `#/p/<id>/<tab>` перенаправляются.

## 3. Главная: «Видео»

По фрейму «Главная страница»:
- Заголовок «Видео» + серый подзаголовок («Каждое видео — папка в канале со своей историей»). Справа белая кнопка **«+ Новое видео»**. Кнопки «Import folder / Import .zip» — **не делаем** (автор: «пока не нужен»).
- Строка поиска по видео + фильтры-таблетки: **Все · Черновики · В работе · Готовые · Вышли** (`draft` / `prod` / есть рендер / `out`; `archived` скрыто).
- Сетка карточек (4 в ряд на 1920, адаптивно):
  - обложка: **выбранная обложка видео, иначе первый кадр** (кадр из `out/*.mp4` или клипа первой сцены), в углу — длительность;
  - название;
  - «**N сцен**» (строку «· Crisp 640 look» не показываем — автор зачеркнул);
  - внизу: статус-таблетка (стадия производства: «Сценарий», «Препродакшен», «Монтаж», «Готово», «Вышло»), «2 ч назад», иконки: **открыть папку** · **препродакшен** · **удалить**.
  - Иконку «дублировать» из референса не делаем (не просили).
- Клик по карточке — рабочее окно видео. Удалить — подтверждение, уводит в `_archive/videos` (как сейчас, без жёсткого удаления).
- Служебные видео («🛠 Мастерская», «Герой канала») в сетке не показываем.

## 4. Поп-ап «Новое видео»

По фрейму «Создание нового видео» + правки автора:

| поле | обяз. | что делает |
|---|---|---|
| **Название** | да | рабочее название = имя папки видео |
| **Формат** | да | Шортс 9:16 (1080×1920) / Длинное 16:9 (1920×1080). В Figma поля нет, но автор просит размер превью по формату — без поля его не узнать |
| **Озвучка** | нет | «Выбрать аудиофайл… или перетащить» (WAV, MP3, M4A). Подсказка: «можно добавить позже». Если дана — тайминги берутся из неё |
| **Подача** | нет | (у автора «Стиль») — как пишется сценарий: инфоповод / история / сюжет / игровой формат / … Список из «Стиль → Подачи», «авто» по умолчанию |
| **Визуал** | нет | (у автора «Жанр», в референсе «Look») — как выглядит: бумажная аппликация 2D, 3D-диорама, нуар… Список из «Стиль → Визуалы». Под селектом — серое описание выбранного (как «The Brains vs Brawn look: …») |
| **Ориентировочная длина** | нет | `мм:сс`, «к чему стремиться» (монтаж может изменить). Подсказка: «≈ N слов при 2,65 сл/с» |
| **Тема** | нет | «Claude поищет и напишет сценарий» |
| **Сценарий** | нет | «вставьте свой текст вместо темы»: Claude только разложит его по сценам, **текст голоса не меняет** |
| **Указания для Claude** | нет | тон, персонажи, на чём сделать акцент, камера |
| **Референсы** | нет | (нет в Figma, есть сейчас на «Идее») свёрнутый блок: ссылки, видео, картинки → `refs[]` |

### 4.1 Шаг 2: вопросы Claude (решение автора, В1)
Поп-ап — **из двух шагов**. На первом шаге кнопка «Далее →» (белая), на втором — «Создать».
1. По «Далее» Claude по полям первого шага (тема, сценарий, подача, визуал, указания, рефы) готовит вопросы. Это нынешняя ✨-задача `questions`, Sonnet; с 🌐 — с поиском.
   В окне — индикатор «Claude готовит вопросы…» и «← Назад».
2. Второй шаг — список вопросов **как сейчас на этапе «Вопросы»**: группы, ответ полем, «–» (пропустить), «реши сам», «+ свой вопрос», «✨ ещё вопросы»; фильтр «без ответа».
3. «Создать» — видео создаётся с ответами (`qa[]`), и Claude пишет сценарий по ним (§5.1). Шаг можно пропустить («Создать без вопросов»).
4. Если в первом шаге вставлен **готовый сценарий** — вопросов меньше (только про подачу, картинку, финал); если есть только тема — полный набор.
5. Поп-ап можно закрыть на втором шаге — видео уже создано со статусом «Черновик», вопросы потом открываются из «Брифа» в шапке.

«Углы названий» (этап «🎯 Название») — уходят в упаковку (там уже 5 названий по углам атаки; где живёт упаковка — В14).

Правила:
- Если есть **сценарий** — ресерч не нужен, Claude раскладывает текст по сценам (`script.md`).
- Если есть **озвучка, но нет сценария** — расшифровка (faster-whisper) становится текстом голоса, Claude раскладывает её по сценам.
- Если нет ни темы, ни сценария — Claude спрашивает в чате, о чём видео.

## 5. Рабочее окно видео («Редактор»)

Три колонки (по фреймам «Пайплайн видео» и «В это же время монтаж»):

```
┌ шапка: Название видео  ✓ сохранено · история      [Opus 5.5 ▾] [⟲ версии] [папка] [Экспорт] ┐
├──────────────┬───────────────────────────────────────────┬──────────────────────┤
│ СЦЕНЫ (N)    │            превью 9:16 или 16:9            │ Claude  [Чат|История]│
│ 1 миниатюра  │                                           │  …лента…             │
│ 2 …          │  ⏮ ▶ ⏭  0:12.32 / 1:05.0  Сцена 2 · …    │  [Применено …]       │
│ ПАЙПЛАЙН     │  📷 🔊 🔁  0.5× 1× 1.5× 2×                 │  быстрые подсказки   │
│ ✓ Сценарий   ├───────────────────────────────────────────┤  [поле ввода, @]     │
│ ✓ Озвучка    │ Таймлайн  подсказка…            − + ⤢     │  Выделение|Сцена|Всё │
│ ○ Тайминги   │ Сцены   ▮1▮▮2▮▮▮3▮…                        │            [Применить]│
│ ○ Препрод.   │ Текст+голос ~~~слова/волна~~~              │                      │
│ ○ Монтаж     │ Музыка  ────                               │                      │
│              │ Звуки   ▮ ▮  ▮ ▮                           │                      │
└──────────────┴───────────────────────────────────────────┴──────────────────────┘
```

### 5.1 Что происходит после «Создать»
1. Создаётся видео **и сразу проект ролика** (`new_project.py --into`, сейчас это «🚀 Начать производство» — отдельная кнопка уходит).
2. Открывается рабочее окно. Превью пустое: «Сцен пока нет — Claude собирает видео».
3. В чате само появляется первое сообщение (от имени автора, по полям поп-апа): «Исследуй тему и напиши сценарий» — и Claude начинает работу (режим `script`).
   - Ресерч: агенту в режиме `script` **включаем WebSearch/WebFetch** (сейчас у агентской сессии их нет).
   - Источники и заметки ресерча Claude пишет в `research.md` (вкладка «Ресерч и источники» в окне сценария, §6).
   - Викторина уже прошла во втором шаге поп-апа (§4.1): ответы — в промпте, повторно Claude не спрашивает (кроме того, что всплыло в ресерче — тогда коротко в чате).
4. Сценарий готов → галочка «Сценарий» закрашивается, кнопка «Написать» превращается в «Открыть». Сразу запускается **черновой голос** (`tts.py`) → галочки «Озвучка (черновая)» и «Тайминги».

### 5.2 Пайплайн (левая колонка)
Шаги — со статусом (○ не сделано · ◐ идёт · ✓ готово · ! устарело) и кнопкой действия. **Семь шагов** (решения автора В3 и В14): Сценарий → Озвучка → Тайминги → Препродакшен → Синхронизация → Монтаж → Упаковка. Экспорт — кнопкой в шапке.

| шаг | кнопка | что делает | откуда |
|---|---|---|---|
| **Сценарий** | Написать → Открыть | окно «Сценарий» (§6) | Script written |
| **Озвучка** | Добавить → Заменить | черновой голос нейросетью ставится сам; «Заменить» — своя запись (один файл или по сценам) → нарезка и сверка, как сейчас в «🎙 Голос»; 🐾 звериная речь — здесь же | Voiceover added |
| **Тайминги** | Запустить → Повторить | выравнивание слов (faster-whisper / tts-тайминги), отсюда субтитры и привязка сцен к словам. Обычно идёт само после озвучки | Words timed |
| **Препродакшен** | Открыть | персонажи, пропсы, сцены, звуки, B-roll (§7) | новое (вместо Storyboard written) |
| **Синхронизация** | Синхронизировать → Повторить | Claude соединяет ассеты препродакшена со сценами и голосом: шаги персонажа, звуки на действиях, анимации персонажей в нужных местах, музыка под смысловые куски (§8.0) | Sound design mixed |
| **Монтаж** | Сделать → Пересобрать | Claude собирает ролик в прямом эфире (§8): тайминги сцен под голос, переходы, надписи, субтитры | Scenes built |
| **Упаковка** | Открыть | название и описание для YouTube + выбор обложки (§9.3); при экспорте всё кладётся в `out/` | новое (В14) |

- «Audio cleaned» — **убрать** (автор вычеркнул). «Video exported» — **убрать** (экспорт — кнопкой в шапке).
- Над пайплайном — **список сцен** (как «SHOTS» в референсе): миниатюра, имя, таймкод, длина. Клик — переход в момент; активная сцена подсвечивается при движении бегунка.
- Шаг «устарел» (!) — например, сценарий изменили после монтажа: кнопка «Пересобрать» подсвечена.

### 5.3 Шапка
- Название (правится по клику), «✓ Сохранено локально · история» — клик открывает **историю версий** (§11).
- **Модель Claude**: Opus 5.5 / Sonnet 5.5 (пин автора). Это модель агента для этого видео (`video.json → agentModel`), по умолчанию — из ⚙ Настроек.
- Плашку «Pixel art · Crisp 640» **не делаем** (зачеркнуто). Визуал и подача видны в «Брифе» (см. ниже).
- Иконки: **история версий** · **бриф** (поля поп-апа, можно править) · **открыть папку проекта** · белая **«Экспорт»**.
- Иконку «клавиатура» (горячие клавиши) — по В-мелким: делаем «?» со шпаргалкой горячих клавиш в подвале чата (как в референсе), из шапки убираем.

### 5.4 Превью
- Размер — по формату видео: 9:16 или 16:9, вписывается в центр.
- Это живая страница проекта (как сейчас «⚙ живой»), а при наличии свежего mp4 — видео (быстрее для 3D). Переключатель «видео / живой» — маленьким значком.

- **Пометки на кадре**: при наведении курсор-крестик; клик ставит пин в этот момент → поповер «что поправить» → пометка уходит в список «Правки» (вкладка в чате) и в `fixes[]`.
  Кнопка «Исправить все (N)» — Claude правит и отвечает по каждой «сделано». Это нынешнее «✋ поправить кадр» + «🔨 Пересобрать с правками» в новой оболочке.

### 5.5 Транспорт (под превью)
⏮ ▶ ⏭ (⏮⏭ — к границам сцен), **покадрово** (← → по кадру, Shift — по секунде), таймкод `0:00.00 / 1:05.0`, «Сцена N · название»,

### 5.6 Таймлайн
Подсказка: «Клик — выбрать · тянуть — перемотка со звуком · Shift+тянуть — диапазон · Ctrl+колесо — масштаб». Справа: − + и «развернуть таймлайн».

Дорожки (по пинам автора):
| дорожка | что | действия |
|---|---|---|
| **Сцены** | блоки сцен с номером и названием (как главы YouTube). Пока Claude работает над сценой — она растянута на весь свободный хронометраж с «…» | клик — выбрать; **Ctrl+клик / Shift+клик — несколько** (как в Premiere); **двойной клик — открыть сцену в нашем редакторе** (Ctrl+S, выйти → всё пересобралось само); перетаскивание краёв — длина (как сейчас) |
| **Текст и голос** | одна дорожка: сверху фразы и слова (что сейчас звучит, = субтитры и привязка таймингов), под ними волна голоса | клик по слову — перейти; двойной — поправить текст субтитра; маркеры сцен «прилипают» к словам |
| **Музыка** | клипы музыки | громкость, фейды |
| **Звуки** | **мультидорожка**: звуки сами раскладываются по полосам без наложений (как в экспорте в Premiere) | перетаскивание, громкость, удалить, «заменить из библиотеки» |

- Дорожки **Cues, Cards, Ambience** — не делаем (автор: «выкинуть»; эмбиент — это просто звук в мультидорожке).
- Надписи монтажа (`overlays`) — если есть, показываем тонкой дорожкой «Надписи» под сценами; пустую не показываем.
- Масштаб: при отдалении сцены — цветные полосы, при приближении — названия и миниатюры.

### 5.7 Чат Claude (правая колонка)
По фреймам «Как в чате выглядит написание сценария» и «В это же время монтаж»:
- Вкладки **Чат · История** (история = прошлые запуски и сессии этого видео) и «+» — новая сессия. Третья вкладка — **Правки (N)** (пометки с кадра, `fixes[]`, заметки сценария).
- Лента: сообщения автора справа «пузырями», шаги Claude — серым свёрнутым списком («Читает script.md», «Рендерит кадры 53.5, 58.8…» — с миниатюрами отрендеренных кадров), «Claude работает · opus-5.5 · 1m 0s  [■ Стоп]».
- **Карточка «Применено»** после каждого запуска: время, файлы `+N −M`, **До / После** (кадр сцены до и после правки, переключатель или слайдер), **«Посмотреть изменения»** (дифф), **«Откатить»**. Принять / отклонить — откат и есть «отклонить»; Ctrl+Z после запуска = откатить последний запуск (§11).
  Цену «$1.58» не показываем: мы на подписке — вместо неё время и, по желанию, токены.
- **Быстрые подсказки** над полем (2–4 чипа по контексту: «Проверь всё видео и поправь, что выглядит не так», «Сделай надписи читаемыми на телефоне», «Проверь, что каждая картинка попадает в своё слово»).
- Поле ввода: «Опишите правку или кликните что-нибудь в превью». Пока Claude работает — «Поставить следующую правку в очередь…» (очередь сообщений).
- **@-ссылки**: персонажи, пропсы, сцены, звуки, B-roll видео — подсвечиваются чипами (механизм `@[Название]` уже есть).
- **Область правки**: сегменты **Выделение · Сцена · Всё видео**. Над полем — чип того, что выбрано: «Сцена 1: команда из десяти… ×», «Сцены 3–5 ×», «0:12–0:18 ×», объект в превью. «Очистить».
  Несколько сцен — для переходов («между 3 и 4 сделай плавный переход») и сквозных вещей («один и тот же ассет в 2, 5, 7»).
- «?» — горячие клавиши, «Применить» (белая).

## 8. Монтаж в прямом эфире

### 8.0 Синхронизация (отдельный шаг, перед монтажом)
Что делает Claude (агент, режим `sync`, по сценам):
- **шаги и действия**: у персонажей с `walk` — звуки шагов к касаниям ног; удары, падения, появления предметов — звуки к моментам сцены (маркеры сцены → `sfx`);
- **анимации персонажа**: ставит клипы, которые персонаж умеет (машет, кивает, пугается…), там, где их требует сценарий или «Для финала», — см. §10.1 «Claude помнит анимации»;
- **звуки препродакшена**: каждый утверждённый звук находит своё место (из «где в ролике» и @-ссылок);
- **музыка**: подбор куска под настроение, вход/выход на границах смысловых блоков, приглушение под голос.
Итог — карточка «Применено» со списком «что к чему привязано» (сцена · момент · звук/анимация), каждая строка кликабельна (переход в момент). Можно запускать по одной сцене (выделение) или по всему видео.
Шаг «устаревает», если после него поменяли сцены или голос.

### 8.1 Как сейчас и что меняется
Сейчас: «✨ Смонтировать» → агент пишет `montage` целиком → `montage gen` → смотрим. Новое: **автор смотрит и помечает ролик, пока Claude его собирает**.

### 8.2 Поведение
1. «▶ Сделать» → агент в режиме `montage` (или `build`, если сцен ещё нет).
2. Сразу раскладка по сценарию (нынешнее «⚡ Разложить», без Claude, секунды): все сцены сценария встают по таймингам голоса **заглушками** — серый кадр с названием и текстом голоса.
3. Агент собирает **по одной сцене** и после каждой фиксирует её операцией (`montage ops` + `montage gen` на эту сцену). Сайт опрашивает `/api/revs` (как сейчас `Sync`) — сцена на таймлайне превращается из заглушки в настоящую, превью обновляется на месте.
   Сцена, над которой агент работает сейчас, — с бегущей полосой «Claude собирает…».
4. В это время автор может смотреть, ставить пометки (§5.4) и писать в чат — сообщения встают в очередь и уходят агенту после текущей сцены.
5. Синхронизация уже сделана на прошлом шаге (§8.0); монтаж её не трогает, только сдвигает вместе со сценами (звуки едут за маркерами, как сейчас).
6. Конец — «Монтаж собран», карточка «Применено» со списком сцен и кнопкой «Экспорт».

Нагрузка: `montage gen` пересобирает весь `scenes.js`; для живого режима нужно уметь перегенерировать **одну сцену** (или хотя бы делать gen быстрым и без перезагрузки превью — перезагрузка на том же таймкоде уже есть).

## 9. Экспорт и «Рендеры»

### 9.1 Окно «Экспорт» (фрейм RENDER)
- **Имя файла** (по умолчанию — slug названия) → `out/<имя>.mp4`. Под полем серым: «1080×1920 · 30 fps · H.264 (GPU) · голос + звук. Сохраняется в out/».
- ☐ **Субтитры (.srt) рядом с видео** — из таймингов слов.
- **«Главы YouTube»** — только для длинных: список «0:00 Название сцены», копировать в буфер / `out/chapters.txt`.
- «Закрыть» · белая «Экспорт».
- Во время рендера: полоса прогресса, «450 / 36 044 кадров · 249 fps · ≈ 2 мин 23 с», «Отменить», **«Свернуть»** — окно закрывается, рендер продолжается в очереди.

### 9.1а Что лежит в `out/` после экспорта
Чтобы при «открыть папку» всё для загрузки на YouTube было в одном месте:
`<имя>.mp4` · `<имя>.srt` (если галка) · `<имя>_thumbnail.png/.jpg` (выбранная обложка) · `<имя>.txt` — название и описание из шага «Упаковка» (+ главы для длинного).
Если упаковка ещё пустая — экспорт не мешает, в окне серым: «Название и описание не заданы — шаг „Упаковка“».

### 9.2 Раздел «Рендеры»
- **Очередь** сверху: что рендерится (видео, прогресс, fps, ETA, отмена), что ждёт. Рендеры идут **по одному** (видеокарта одна).
- **Готовые** ниже: список всех `out/*.mp4` канала — превью, название, видео, дата, длительность, разрешение, размер; ▶ посмотреть в окне, открыть папку, «.srt», удалить файл (в корзину `_archive`).
- По окончании — **уведомление Windows** (Tauri notification) «Рендер готов» + тост в приложении; клик ведёт в «Рендеры».
- Сервер: задачи рендера в `.studio/renders.json` (очередь переживает перезапуск страницы; при перезапуске сервера незавершённые помечаются «прерван»).

### 9.3 Шаг «Упаковка» (решение автора, В14)
Седьмой шаг пайплайна, открывается в центре окна (как препродакшен). Только нужное для загрузки:
- **Название** — 5 вариантов от Claude по углам атаки (число / образ / срочность / противоречие; бывший этап «🎯 Название» и `packtext`), ★ выбранный, правится руками;
- **Описание** — Claude пишет (короткое для Shorts или с источниками из `research.md`), правится руками;
- **Обложка** — выбор из сделанных в разделе «Обложки» (доска этого видео) или первый кадр; ссылка «Открыть доску обложек».
Хэштеги, закреп, провокация и «Права» в шаг не выносим (автор: «только название / описание + тамб»); «Права» продолжают собираться для `out/`, если в ролике есть чужие кадры (одна строка в `<имя>.txt`).
Данные — `video.json → pack {title, desc, thumb}` (поля `pack` уже есть). При экспорте — в `out/` (§9.1а).

### 9.4 Скорость рендера (отдельная работа)
Автор: «у референса очень быстрый экспорт, у меня хорошая видеокарта — поработаем над движком». Сейчас: 2D ~113 fps, 3D ~47 fps (JPEG-кадры на диск → ffmpeg).
План замеров и улучшений (делаем по замерам, не вслепую):
1. Кадры **сразу в ffmpeg через pipe**, без файлов на диске; кодирование `h264_nvenc` (GPU).
2. Захват canvas внутри страницы (`canvas.toBlob`/`VideoFrame` + WebCodecs `VideoEncoder` с аппаратным кодеком) вместо скриншота puppeteer — потенциально главный выигрыш.
3. Подбор числа вкладок для 2D/3D заново.
Цель — ×2 к нынешнему; итог — замер в этом документе.

| Отдельные кнопки 3D-генерации | `idea.js`, `libitem.js` | одна «✨ Сделать 3D» в препродакшене (§7); `comfy3d.py`, `models3d.py`, Blender — остаются |

**Claude помнит анимации персонажа.** Раз экранов нет, знание переезжает в промпт:
- `scene brief` и бриф агента для каждого персонажа сцены перечисляют **что он умеет**: клипы `library/anims/<type>/*` (имя, длина, «когда уместно»), эмоции, костюмы, предметы в руках (grips), а для ёжика — движения из `ANIMATIONS.md` / `moves3d.js`;
- у клипа — поле `when` («удивление», «приветствие», «идёт к цели») — Claude заполняет при обучении, автор может поправить словами в чате;
- агент использует их сам там, где сценарий или «Для финала» этого требует (шаг «Синхронизация», §8.0), и по просьбе («пусть тут помашет»); новое движение — «научи ёжика …» в чате → клип в библиотеку.
- Где видно автору: на странице персонажа в библиотеке — **список «Умеет»** (только просмотр: имя, превью-гифка, когда уместно).

### 10.2 Стиль
Автор: «глобальная настройка канала с рефами (фото, видео) и описанием» + редакторы подач и визуалов. Вкладки:
- **Обзор** — описание канала, референсы (фото, видео-ссылки с разбором), стайл-гайд (`style/style-guide.md`).
- **Подачи** (у автора «стили») — пресеты сценария: имя, описание, схема (А/Б/В из гайда), хук, темп, пример. Стартовые: Инфоповод (схема В), История, Сюжет, Игровой формат («Не жми эту кнопку»). Файлы `style/deliveries/<slug>.md`.
- **Визуалы** (у автора «жанры», в референсе «look») — пресеты картинки: имя, описание, референсы, движок (2D-аппликация / 3D-диорама), палитра, тулкит, пример кадра. Стартовые: Бумажная аппликация, 3D-диорама (бумажный макет), Нуар. Файлы `style/looks/<slug>.json` + `refs/`.
- **Голос и субтитры**, **Герой**, **Правила**, **История** — как сейчас, в новом виде. «🎤 Интервью» — кнопка «✨ Собрать стиль с Claude» на «Обзоре».

### 10.3 Память
Автор: «глобальные моменты, которые ты запоминаешь на основе правок, новое подписываешь также».
- После запуска с правками Claude может **предложить правило**: «Запомнить: звуки на переходах тише на 6 дБ — потому что в 3 видео ты просил тише». Оно попадает в «Память» с меткой «new» (счётчик в сайдбаре).
- Автор: ✓ принять / ✎ поправить / ✗ отклонить. Принятые — список: текст, «почему», откуда (видео, дата), область (весь канал / только подача Х / только визуал Y), вкл/выкл.
- Принятые правила **попадают в системный промпт** агента и ✨-задач (как стайл-гайд канала).
- Хранение: `<канал>/memory/<id>.md` (frontmatter: `scope, why, from, created, on`) + `memory/index.json`. CLI: `studio.py memory list|add|on|off`.
- Область — вопрос В-мелкие (канал или вся студия).

### 10.4 Обложки
По фрейму «Пока идёт монтаж, можно сделать thumbnail». Отдельный раздел; можно работать, пока идёт монтаж.
- Слева — **доски**: по одной на видео (+ «свободная» доска канала). Сверху доски: имя, переключатель **Канвас · Промпт**, ключ API (`Higgsfield · …5b5d`), очистить.

  - Ноды: **Картинка** (перетащить файл или вставить из буфера; кадр из ролика; элемент препродакшена/библиотеки), **Текст**, **Промпт**, **Результат**.
  - Нода «Промпт»: чипы входящих картинок `@img1 @img2` (на них можно ссылаться в тексте), текст промпта, внизу — **модель**, **формат** (9:16, 16:9, 1:1), **качество** (1k/2k), «Сгенерировать».
  - Каждое «Сгенерировать» создаёт **новую ноду-результат ниже по ветке** (старые остаются). Статус: «В очереди Higgsfield», «Генерация», ошибка.

  - Нижняя панель: + Промпт · + Картинка · + Текст · масштаб · вписать.
- **Промпт** — тот же движок без канваса: поле, картинки, модель, сетка результатов.
- Провайдер: **Higgsfield API** (ключ в ⚙ Настройках → `.studio/secrets.json`). Какие модели и эндпоинты он даёт — **проверить до разработки** (в референсе «GPT Image 2.5»; это надо подтвердить по их документации). Провайдер — модулем `server/imagegen/<provider>.py`, чтобы позже добавить локальный (у нас уже стоит ComfyUI для TRELLIS — FLUX/Qwen-Image через него, «по приколу», опционально).
- Хранение: `<видео>/thumbs/board.json` (ноды, связи, позиции) + `thumbs/gen/*.png` + `thumbs/in/*`.
- Нынешние «концепты» и «🎨 Отрисовать» (Claude рисует обложку кодом с нашим ёжиком) — вопрос В4.
- Обложка 1080×1920 для шортса; безопасная зона y 260–1620 подсвечивается рамкой на результате (из памяти про обрезку в сетке Shorts).

## 11. Версии и Ctrl+Z

Пины автора: «версионирование, история изменений, откатиться, Ctrl+Z», «отменить изменения — и через Ctrl+Z».
- **Снимок** (чекпоинт) — после каждого запуска Claude, после выхода из редактора сцены, после ручных правок (с задержкой, пачкой). Хранится коммитом в git канала (тяжёлое — mp4, кадры, модели — в `.gitignore`, как сейчас).
- Окно **«История версий»** (из шапки): список «14:02 · Claude: монтаж сцен 3–5», «13:40 · Вы: сцена 2 в редакторе»… → посмотреть (дифф, кадр до/после) → «Вернуть к этой версии» (создаёт новую версию, не теряет историю).
- **Ctrl+Z / Ctrl+Shift+Z** в окне видео: отменить последнюю операцию; если последней была работа Claude — откатить весь запуск (как «Откатить» в карточке). Внутри редактора сцены — свой undo, как сейчас.
- Уже есть и переиспользуем: операции `Store`, `history.jsonl` сцен, откат запусков агента (`.studio/agent/runs`), `backups[]` и «↶ Прошлые версии».

## 12. Техническая часть

### 12.1 Фронтенд
- Оставляем **vanilla JS без сборки** (Tauri + локальный сервер, офлайн, без npm-шага), но:

## 15. Риски
- **Объём.** Это переписывание почти всего UI (~400 КБ фронта). Смягчение: части по одной, старый UI рядом до конца.
- **Живой монтаж** упирается в скорость `montage gen` и перезагрузку превью; без поштучной генерации будет «дёргаться».
- **Ресерч в агенте** (WebSearch) — медленнее, сценарий 3–6 минут; показывать шаги, чтобы ожидание было видно.
- **Higgsfield API** — модели, цены и лимиты не проверены; держим провайдер отдельным модулем.
- **Удаление экранов (В2)** — данные и движок старых видео не трогаем, иначе сломаются готовые ролики.
- **Права**: в обложки и B-roll попадут чужие кадры и персонажи — «Права» упаковки собирают их, как сейчас.
