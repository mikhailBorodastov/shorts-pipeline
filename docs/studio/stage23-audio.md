# S23 «Звуковой редактор монтажа»

**Боль автора.** Со звуком на монтаже у Claude пока проблемы, а автор не может сам довести его до ума.
- Музыка и звуки на таймлайне — цветные плашки без волны.
- Звук можно только сдвинуть, а обрезать — только музыку и только справа.
- Выделить можно одну плашку.
- Звуки сцен (шаги и двери из `scene.json`) не видны.
- Своего файла не добавить, кнопки «добавить звук» нет.
- Зациклить кусок (дождь, толпу) нечем.

**Решение.** На шаге «Монтаж» появляется полноценный звуковой редактор:
- настоящие дорожки с фейдером и mute/solo;
- волна на каждой плашке;
- обрезка с обоих краёв, сдвиг звука внутри плашки, растяжение с циклом;
- редактор звука с ровным швом цикла;
- мультивыделение, как у правок;
- разрезать, копировать, вставить и дублировать, прилипание;
- панель «Звуки» и перетаскивание из неё и из проводника;
- автоприглушение музыки под голос;
- «Заменить похожим…».

Макет — `stage23-audio-mockup.html`.

**Ответы автора** (6 окт 2026):
- **Звуки сцен** — показать и править на монтаже. Правка пишется в саму сцену, при сдвиге сцены звук едет с ней.
- **Источники** — свои файлы из проводника, панель «Звуки» (библиотека пайплайна, канал, препродакшен, мои), поиск в интернете, Claude в чате.
- **Растяжение** — цикл. Сначала звук можно подрезать (кривой хвост, тишина), чтобы цикл шёл ровно.
- **Громкость** — ручки на плашке (уровень и фейды), автоприглушение под голос, фейдер дорожки + mute/solo.
  Ключей громкости внутри плашки нет — при нужде режь плашку на куски.
- **Дорожки** — настоящие, как в Premiere: звук лежит там, куда его положили.
- **Ручные правки автора** Claude может менять, но сначала спрашивает.
- **Инструменты:**
  - разрезать (S / C);
  - копировать / вставить / дублировать (Ctrl C / V / D, Alt + перетаскивание);
  - прилипание к словам, склейкам, плейхеду и краям соседей, Shift — без прилипания; по пику звука — Ctrl;
  - «Заменить похожим…».

## 1. Данные: дорожки и плашки (`video.json → montage`)

**Дорожки.** `montage.tracks[]` — `{id, kind: 'voice' | 'music' | 'sfx', name, gain, mute, solo}`:
- `gain` — в dB, 0 по умолчанию;
- у старых видео дорожки создаются сами: `voice`, `m1` «Музыка», `s1` «Звуки».
  Плашки старых звуков встают на `s1`, наложения раскладываются на `s2`, `s3` по прежней автостопке.

**Плашка.** Музыка и звуки — один формат:
```
{ id, track, at, src,
  in: 0,        // с какой секунды файла играть (левый край / сдвиг звука внутри)
  dur: null,    // длина плашки; null — до конца файла (или куска loop)
  loop: null,   // { a, b, xf } — кусок файла, который повторяется, и кроссфейд шва (с)
  gain: 0,      // dB
  fadeIn: 0, fadeOut: 0,
  align: '' | 'peak',   // как раньше: at — это пик звука
  by: 'author' | 'claude', note }
```
- Старые поля читаются: у музыки `from` → `in`, у звуков `gain` (множитель) → dB. Миграция — при первом открытии, одной операцией.
- `by: 'author'` ставит любая ручная правка на таймлайне. Агент, у которого правка задевает такие плашки, получает отказ с их списком и спрашивает автора `[[выбор: Меняй | Не трогай]]`, потом повторяет с `--force`. Правило — в промпте агента и в `montage_api` (проверка операций с `by=claude`).

**Звуки сцен.**
- Показываются на дорожке, указанной в `track` у звука в `scene.json` (по умолчанию `s1`), со значком сцены и её цветом.
- Время — по карте юнита (`map`): обратная карта переводит `at` в `t` сцены.
- Правка пишется операцией сцены `scene ops … set sounds.<id>.* --by author`. У локаций — в оверлей `mscene`, а не в локацию.
- Если сцена встречается в монтаже дважды, правка идёт в сцену — значит, в оба места. Подсказка в свойствах так и говорит.
- В `sounds` сцены добавляются те же поля `in`, `dur`, `loop`, `fadeIn`, `fadeOut`, `track`.

**Автоприглушение.** `montage.duck = {on, depth: -10, attack: 0.15, release: 0.4, tracks: ['m1']}`. Огибающая строится по словам голоса (`vo_timing`) с паузами < 0,35 с внутри, без анализа RMS: одинаково в превью и в сборке.

## 2. Сведение (`template/audio.py`, `MTA` в `web/montage.js`)

- **Генератор** (`montage_api.generate`) пишет в `MONTAGE_SFX` / `build/music.json` всё, что нужно:
  - `in`, `dur`, `loop`, фейды;
  - итоговый gain = плашка + дорожка (dB → множитель);
  - mute/solo применяются здесь, заглушённое не попадает;
  - `duck` — в `build/music.json`.
- **`audio.py`** получает общий `render_clip(y, e)`: срез `in`, цикл `[a,b]` с равномощным кроссфейдом `xf` до длины `dur`, фейды, `align: 'peak'`. Им пользуются `build_sfx` (ветки `file:` / `lib:` / `el:`) и `build_music_files`. Старые события без новых полей звучат как раньше (`fade_out` по умолчанию остаётся).
- **Превью (WebAudio):** тот же расчёт — `MTA.clip()`. Цикл — повтор `BufferSource` с `loopStart`/`loopEnd` и кроссфейдом двумя источниками. Приглушение — `GainNode` с ключами огибающей. Сверка: `node stands/audio_parity.js <видео>` — разница превью и `build/mix.wav` не больше −40 dB.

## 3. Таймлайн (`web/montage.js`)

**Дорожки:**
- Строки «Голос», «Музыка», «Звуки 1…N». Под последней — пустая строка «＋ перетащи сюда — новая дорожка».
- В шапке строки: имя (двойной клик — переименовать), фейдер dB, M / S, ⋯ (удалить пустую, порядок ↑↓).
- Дорожки «Надписи», «Сцены», «Правки», «Сторож» — как были.

**Плашка:**
- волна (пики считает `MTA.buf`, кэш как у голоса);
- имя;
- линия уровня — тянешь вверх-вниз, подсказка в dB;
- треугольники фейдов в верхних углах;
- ↻ — зубцы шва на каждом повторе цикла;
- ⚑ — пик при `align: peak`;
- 🔒 — `by: author`;
- цвет сцены — для звуков из сцен.

**Мышь:**
- **тянуть** — сдвиг по времени и между дорожками;
- **Alt + тянуть** — копия;
- **левый край** — обрезка начала (`in` и `at` вместе);
- **правый край** — длина; дальше конца файла — цикл (сам ставится `loop` = весь звук или его кусок из редактора);
- **Ctrl + тянуть внутри** — сдвиг звука в плашке (`in`), плашка стоит на месте;
- **двойной клик** — редактор звука (§5);
- **правый клик** — меню: разрезать, дублировать, заменить похожим…, редактор звука, на дорожку…, в библиотеку, удалить.

**Мультивыделение** — адаптер `TLSel.ADAPT.clips` (тот же модуль, что у правок):
- Ctrl / Shift + клик, рамка по пустому месту дорожек (через несколько дорожек);
- групповой сдвиг (`TLSel.drag`, подписи «сдвиг N звуков» обобщаются);
- групповой уровень (тянешь линию у одной — меняются все на ту же разницу dB);
- Delete, Esc, Ctrl+A (по наведённой дорожке: правки или звуки).
- В свойствах при выборе нескольких — общие поля («смешанно», если разные).

**Прилипание** (порог 8 px):
- слова голоса (начало), склейки сцен и камеры, плейхед, края соседних плашек на любой дорожке;
- с **Ctrl** прилипает пик звука, а не начало (и ставит `align: peak`);
- **Shift** — без прилипания;
- линия-подсказка показывает, к чему прилипло («слово "бах"»).

**Клавиши:**
- S или C — разрезать выделенное (или всё под плейхедом на наведённой дорожке) по плейхеду;
- Ctrl C / V — вставка по плейхеду на ту же дорожку;
- Ctrl D — дублировать сразу за собой;
- без нампада: ← → сдвиг выделенного на кадр, Shift — на 0,5 с; `[` `]` — фейд вход/выход ±0,1 с; `-` `=` — уровень ±1 dB.
- Конфликты с клавишами окна видео проверяются в `workspace.js`. Пробел и J K L остаются за плеером.

**Отмена** — `Workspace.track`: каждое действие мыши — одна запись, групповое — тоже одна.

## 4. Панель «Звуки» и перетаскивание

**Где.** Кнопка «🔊 Звуки» в шапке таймлайна открывает панель слева вместо списка сцен. Вкладки:
1. **Библиотека** — пайплайн `sfx_library` (поиск по index, категории);
2. **Канал** — `lib:sounds/*`;
3. **Видео** — звуки препродакшена, свои загруженные этого видео;
4. **Интернет** — `sounds.py search`: YouTube первым, Freesound, Commons, с полями «с / по».

**Строка звука:** ▶ (прослушать по наведению / клику, не останавливая плеер ролика), длина, мини-волна. Перетаскивается на дорожку — встаёт туда, где отпустил, с прилипанием. Из «Интернета» сначала встаёт заглушка «⬇ качаю…», задача `sndfetch` подменяет её готовым файлом.

**Свои файлы из проводника:** .wav .mp3 .ogg .m4a .flac и видео (берётся звук) бросаются на дорожку или в панель.
- `POST /api/montage/upload` → ffmpeg в wav 48 кГц → `<видео>/files/sfx/own/<имя>.wav`, `src: 'file:files/sfx/own/…'`;
- в панели — во вкладке «Видео»;
- «📚 в библиотеку» на плашке — в звуки канала с лицензией «свой».

**Claude в чате** — как сейчас: «поставь удар на "бах"». Агент пишет плашки операциями монтажа (`by: claude`). Добавлены краткие команды:
- `montage clip <видео> add|set|split|del …`;
- `montage tracks <видео>`;
- `montage brief` показывает дорожки и 🔒.

## 5. Редактор звука (двойной клик по плашке)

Поп-ап на всю ширину окна: крупная волна всего файла, ▶ / ⏹, масштаб.

**Ручки:**
- `in` / `out` — какой кусок играет;
- **кусок цикла** `a…b` (зелёная зона);
- **кроссфейд шва** `xf` (0–1 с).

**Кнопки:**
- **«▶ Слушать шов»** — играет 2 с до шва и 2 с после, по кругу. Так слышно, ровно ли.
- **«✂ Срезать тишину»** — убирает тихие края (порог −45 dB): обрыв дождя с пустотой исчезает.
- **«🔁 Найти шов»** — ищет `a`, `b` с максимальной похожестью (автокорреляция огибающей и спектра около краёв, `server/audio_edit.py loop`). Шов попадает между похожими местами, а не в ударение.
- **«↺ Сбросить»**.

Правки — параметры плашки, файл не меняется. «💾 Сохранить как новый звук» пишет обработанный wav в «Видео» (для повторного использования). У звука из сцены редактор правит звук сцены.

## 6. «Заменить похожим…»

В меню плашки — задача `sndalt` (Sonnet, 1 проход):
- описание звука, момент ролика и слово голоса → поиск по библиотеке пайплайна и канала, если мало — `sounds.py search` YouTube;
- 3–5 кандидатов поп-апом у плашки: ▶ слушать **на месте в ролике** (секунда до и после), «Взять» — подмена `src` с сохранением `at`, пика, длины, фейдов и уровня.
- Без Claude — «🔎 похожие в библиотеке» по тегам `index.md` (мгновенно).

**Отличия от плана:**
- `gain` плашки остался множителем (как у старых монтажей и агента); в окне показывается в dB. Громкость дорожки — в dB.
- Приглушение по умолчанию −6 dB (старое сведение давало около −5 dB); выключается по дорожке (кнопка ⇩ в шапке) или целиком (правый клик — глубина, 0 — выкл).
- Solo — только в живом звуке окна, в экспорт не идёт (забытый solo не испортит ролик); mute — и в экспорт.
- Клавиши без конфликтов с окном: сдвиг — Alt + ← →, громкость — Alt + ↑ ↓ (− и = заняты масштабом, стрелки — плейхедом), фейды — `[` `]` (Shift — уменьшить).
- «Найти шов» и «Срезать тишину» считаются в браузере по декодированному звуку, без сервера.
- «📚 в библиотеку» на плашке не делали: свои и обработанные звуки лежат во вкладке «Видео» панели.
- Отдельного `audio_parity.js` нет: сверены куски плашки (`clip_pieces` = `MSnd.pieces`) на наборе случаев, сведение — `build.sh audio` на тестовом видео (цикл без щелчков на швах).
- Звук локации в сцене монтажа (S13) на дорожке полупрозрачный — правится в локации.
- Составной звук препродакшена (несколько слоёв): обрезка и длина работают по всем слоям, а цикл — только у звука из одного файла.

### 8.1 Правки после первого показа (6 окт 2026)
- **Перетаскивание из панели — мышью, а не HTML5:** окно Studio (Tauri / WebView2) на Windows забирало HTML5-перетаскивание себе. Плюс в окне выключен свой обработчик (`disable_drag_drop_handler` в `app/src-tauri/src/main.rs`), чтобы файлы из проводника доходили до страницы (окно пересобрано, работает после перезапуска Studio).
- **Вкладки панели** — «Общие · Канал · Видео · Сеть» (было «Библиотека…», не помещалось).
- **«＋ Пак»** во вкладке «Общие»: папка или .zip → `POST /api/audio/import` → `sfx_library.import_pack` фоном, прогресс в панели; фильтр по пакам. Импорт: категории по смыслу из имён (`AUTO_CAT`: whoosh, riser, glitch, ui, impact, explosion, cartoon, ambience…, коды UCS вроде `WHSH`, `IMPCT`, `AMB`) — для больших паков, где папки названы по студиям; 6 потоков, повторный запуск продолжает с места, лицензия пака — в каждом звуке. CLI: `python sfx_library.py import <папка|zip> [--auto|--folders] [--pack имя] [--license "…"]`.
- **Mixkit** во вкладке «Сеть» (первым): страницы тегов mixkit.co (`audio_api.search_mixkit`), бесплатно и без атрибуции; русские слова переводятся (`SYN`).
- **Sonniss GDC** напрямую не качается (403 без браузера) — автор скачивает бандл в браузере или торрентом и добавляет через «＋ Пак».
- **Размеры окна видео тянутся мышью** (`WSize` в `web/ui/workspace.js`, стили — `web/ui/audio.css`): ширина левой панели (у сцен и у «🔊 Звуки» — своя, по умолчанию 330 px), высота таймлайна (верхний край), ширина чата Claude (левый край, `--agent-w`). Хранятся в localStorage, двойной клик по ручке — как было; ⤢ сбрасывает высоту таймлайна.
- **Список сцен слева — аккордеоном**, по умолчанию свёрнут (`ws-scenes-open`).
- Исправлено «nullnullnull» над результатами поиска (перерисовка панели вставляла пустые элементы текстом).
