# S8. Ревью с правками в кадре и упаковка — ТЗ реализации

Цель ([roadmap](roadmap.md#s8-ревью-и-упаковка)): автор правит готовый ролик **прямо из ревью** — подвинул ёжика в кадре, подписал «почему», Claude перенёс правку в сцену как авторскую и пересобрал;
упаковка выдаёт обложки в проект и `packaging.md` (названия, описания, закреп, хэштеги, «Права» из лицензий).

**Готово, когда** (решения автора: правка — **3D-кадр на паузе**; упаковку проверяем на **«Ностальгии»**):
- пометка «ёжик застрял в стене» с перетаскиванием ёжика исправлена Claude при пересборке;
- упаковка выдаёт обложку и `packaging.md`.

## 1. ✋ Правка в кадре

- **Ревью** (этап «👀 Ревью», страница ревью проекта в окне) — над ним полоса: «✋ поправить кадр», открытые правки, «🔨 Пересобрать с правками (N)».
- «✋ поправить кадр»: приложение спрашивает у ревью момент паузы (`postMessage {getT}` → `{reviewT}`, шаблон `review.js`), переводит его в сцену и её время по карте монтажа
  (`GET /api/montage/at?video=&t=` → `{el, ts}`, обратная карта `_video_to_scene`) и открывает редактор сцены поверх **в режиме правки** (`editor.html?…&fix=1&t=&vt=`):
  камера ролика («глазами камеры»), курсор в этом моменте, плашка «✋ Правка в кадре».
- В режиме правки всё работает как обычно (двигать, поворачивать, поза, ключи, автоключ), но правки **не уходят в сцену**: копятся на странице (`ED.fix.ops`).
  «💾 Сохранить пометку» (нужно «почему») → `POST /api/montage/fix` → `video.json → fixes[] = {id, el, vt, ts, ops, why, desc, status: open|done|drop, reply}`; «Отмена» — ничего не меняется.
- «🔨 Пересобрать с правками» — просьба агенту (S7, Opus): для каждой открытой пометки применить её `ops` командой `scene ops … --by author` (решение автора → `authored`),
  поправить соседние ключи своей пачкой, если правка должна держаться и рядом по времени, посмотреть кадры, закрыть пометку (`fixes.<id>.status = done`, `reply`),
  потом `montage gen` → `montage snap` → `montage build`. Отменяется, как любой запуск агента (↺).
- Проект, собранный монтажом, получает свежий `review.js` при каждом `montage gen`.

## 2. 📦 Упаковка

- Этап «📦 Упаковка»: **📝 Тексты** — «✨ Написать / Переписать» (задача `packtext`, Sonnet, `ideas_claude`): 5 названий по четырём углам атаки (★ лучшее), описания (короткое, с источниками, провокация),
  закреп, 6–10 хэштегов, «Права»; всё правится на месте (`video.json → pack`), «📄 packaging.md» — запись в `out/packaging.md` проекта (после ✨ — сама).
- **«Права»** (`server/pack_api.py rights`) — из того, что реально вошло в ролик: звуки препродакшена в сценах и монтаже (название, автор, лицензия, ссылка),
  звуки библиотеки пайплайна (по пакам), персонажи и пропсы библиотеки канала (`license.json`: своё / чужое), ассеты элементов. Claude дописывает человеческий абзац (бренды, игры, пародии).
- **🖼 Обложки** — концепты и «🎨 Отрисовать» (как в Штурме, `plan.js`); «📤 Обложки в проект» — текущая версия каждой отрисованной обложки (выбранная связка — первой) → `out/thumbnail_N.png` + `.jpg`.

## 3. Как сделано / проверено

- Тест «ёжик застрял в стене» — «Проверка сборки» (`261001-2feb`): ошибка создана руками (ёжик на 1.0–1.5 с сцены «утро» уходит в шкаф), ролик пересобран;
  пауза ревью на 5.7 с → «утро», 1.21 с сцены → в режиме правки ёжик вытащен на дорогу к креслу (ключ 1.21 с), «почему»: «ёжик застрял в стене…» → пометка; сцена не тронута до пересборки.
- «🔨 Пересобрать с правками» (агент, Opus, $0.41): нашёл причину — три ключа ёжика на 1.0–1.5 с внутри шифоньера; ключ автора на 1.21 с внёс как авторский,
  эти три перенёс на пол по линии к креслу, проверил кадры сцены (0.9 / 1.21 / 1.5 с) и ролика (5.2 / 5.7 / 6.2 с), закрыл пометку с ответом, пересобрал mp4 — ёжик идёт по ковру.
- Упаковка «Ностальгии»: «✨ Тексты» за 18 с (5 названий, лучшее — «Играть можно только по выходным. Но не сегодня»; описания, закреп, 10 хэштегов, «Права»:
  Rockstar / Take-Two, Microsoft, Blizzard, Valve, Nickelodeon, Genius + звуки Freesound CC0 со ссылками, тема SA, пак пайплайна); концепт «Связка» → «🎨 Отрисовать» (Opus) →
  «📤 Обложки в проект» → `out/thumbnail_1.png/.jpg`, `out/packaging.md`.
- Генератор монтажа предупреждает о разных `prefabs.js` только когда они правда разные (копии одной локации собираются вместе).
