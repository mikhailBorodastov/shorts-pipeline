# Задание для реализатора (вставить в новый чат Claude Code, модель Opus, рабочая папка `D:\work\Animations`)

---

Ты — реализатор Claude Studio: видеоредактора, совмещённого с ИИ-агентом, который вырастает из нашего «Штурма идей» и пайплайна шортов.
План утверждён автором, твоя задача — реализовать его по этапам.

**Прочитай перед началом, по порядку:**
1. `_pipeline/docs/studio/README.md` — видение, решения автора, правила работы.
2. `_pipeline/docs/studio/architecture.md` — целевое устройство (папки, `scene.json`, скелеты, анимации, операции, агент, хоткеи).
3. `_pipeline/docs/studio/roadmap.md` — этапы S0–S9 и критерии готовности.
4. `_pipeline/docs/studio/stage1-editor.md` — подробное ТЗ первого этапа.
5. `_pipeline/docs/preproduction.md` и `_pipeline/docs/shturm.md` — как устроено сейчас (раздел 13 preproduction.md — протокол вопросов к автору).
6. `_pipeline/CLAUDE.md` — правила пайплайна роликов (стиль, грабли, как проверять кадры).
7. Код: `_pipeline/ideas/` (ideas_api.py, ideas_claude.py, preprod.py, web/idea.js, web/core.js, web/render/stand3d.html), `_pipeline/template/src/stage3d.js`.

**Как работать:**
- Иди по этапам: S0, затем S1. После каждого этапа — покажи автору результат по его критериям готовности (скриншоты, короткий список «что сделано / что проверено / что нет»)
  и жди «принято», прежде чем начинать следующий. Если автор сразу скажет «дальше» — продолжай S2 и так далее.
- Этап большой — дроби на куски; после каждого куска — тесты и коммит в git (сообщения по-русски).
- **Не ломай работающее:** «Штурм» на порту 8790 у автора открыт и перезагружает `ideas_api.py` на лету. Для экспериментов подними тестовую копию:
  скопируй нужные штурмы в свою папку и запусти `IDEAS_DIR=<копия> IDEAS_PORT=8795 python _pipeline/ideas/ideas_server.py`.
  Меняешь то, от чего зависит страница, — подними `API_VERSION` в `ideas_api.py` и `API` в `web/core.js`.
- **Проверяй глазами:** встроенный браузер (скриншоты страницы редактора), `node _pipeline/ideas/render_shot.js …` для кадров стенда. Не пиши «должно работать» без проверки.
- **Скачивание** (TransformControls для S1, Electron для S2, иконки и т. п.) — одним коротким вопросом со списком «имя · источник · размер».
- **Спека — источник правды:** меняешь устройство — обнови `architecture.md` / документ этапа в том же коммите. Нет решения в спеке — спроси автора (AskUserQuestion, с вариантами и твоей рекомендацией первой).
- Пиши и говори с автором по-русски, коротко; «локальный скрипт / приложение», не «сервер». Не цитируй `master-planer.pdf`.
- Кнопки ✨ на странице — `claude -p` на подписке автора (см. `run_claude` в `ideas_api.py`): текст — Sonnet, визуал — Opus. Твои новые задачи подключай туда же.

**Начни с S0** (git в `_pipeline\` и в `_ideas\` по roadmap.md), затем **S1 — редактор сцены** на эталоне «Комната зимним утром»
(штурм `260930-08d8`, элемент `e6640ce01`, версия v4). Первым делом в S1 — формат `scene.json`, движок `scene.js` с тестами и конвертер эталонной сцены
со сравнением кадров «было / стало»: на этом стоит всё остальное.
