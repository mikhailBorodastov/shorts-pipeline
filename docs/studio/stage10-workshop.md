## S10.1 Мастерская: скелет и анимации
**Что это.** Страница `🛠 Мастерская` ассета = редактор сцены (S1) в особом режиме на служебной сцене, где стоит только этот ассет на нейтральном полу, камера и свет по умолчанию.
Открывается: из библиотеки (страница предмета → «🛠 Мастерская»), из препродакшена (карточка персонажа / пропса → «🛠 Мастерская»).
Служебная сцена — элемент `kind: scene` с `ws: { src }` (src — `lib:<kind>/<slug>@N` или `el:<id>@vN`) в том же видео (препродакшен) или в служебном видео канала «🛠 Мастерская»
(`service: true`, для библиотеки); в списках сцен, монтаже и «Начать производство» её нет. Всё, что умеет редактор, работает и тут: ключи позы, IK, клипы, агент, история, кадры.

**Режимы — как Setup / Animate в Spine:**
- **🦴 Сборка** (скелет). 2D, риг частей: суставы мышью, кость — добавить / удалить / переименовать / сменить родителя, пределы поворота, порядок частей (z), к какой кости
  прикреплена часть (было в `stands/skel.html` — переносим внутрь мастерской). 3D, риг `model`: таблица «наша кость ← кость модели, ось, знак» с проверочными позами
  (руки вверх, шаг) — как retarget-маппинг в Maya HumanIK / Blender Rigify; «✨ Claude, собери / почини скелет» (charparts / auto_rig). Позы и эмоции — библиотека поз
  (как Pose Library в Blender): сохранить текущую, применить, по имени.
  Сохранение — новая версия ассета (библиотека — `fork`, элемент — vN+1).
- **🎞 Анимация** (клипы). Таймлайн редактора + **Dope Sheet** по каналам (кости, лицо, карточка): ключи — выделить рамкой, сдвинуть, растянуть, копировать / вставить,
  **вставить зеркально** (Blender Ctrl+Shift+V: L↔R), ease ключа (linear / io / in / out / hold — как интерполяция в Graph Editor), **onion skin** (полупрозрачные позы ±N кадров,
  как в Toon Boom / Spine), автоключ, ключ всем (I), IK-ручки на кончиках лап с FK/IK. Рабочая область [in, out] → **«💾 Сохранить как клип»** (`library/anims/<тип>/<slug>.json`,
  петля, длина) — клип сразу доступен всем персонажам этого типа скелета (как retarget по общему скелету). «+ научить» (Claude пишет клип словами) и «✨ доведи».
  Клип можно открыть обратно в мастерской и поправить (клип ↔ ключи позы).

## S10.2 Предметы в руках (слоты и вложения — как Spine slots/attachments, Maya parent constraint)
- Слоты скелета (`slots`: handL, handR, head, back…) принимают **предмет**: любой пропс (`lib:` / `el:`). В сцене — ключи `keys["hold.handR"] = [{t, v: ref | null}]`
  (взял в 4.2 с, положил в 7 с); в мастерской — пробный предмет в слоте.
- **Хват под предмет** — у персонажа `grips[<id пропса>] = { slot, offset [x,y,z], rot, scale, pose }`: как предмет сидит в руке и как сжаты пальцы / согнута лапа.
  Подгоняется в мастерской с предметом в руке (двигаешь предмет гизмо — пишется offset), сохраняется в версии персонажа. Без хвата — по умолчанию (по центру кисти).
- 2D (карточка): предмет-карточка или 3D-пропс у точки кисти в плоскости карточки, поворот — с костью; 3D-модель: прикрепление к кости арматуры.
- **Жена-ёжиха**: нейтральная версия без трубки (костюм без `phone`), трубка — отдельный пропс «Телефонная трубка» + хват.

## S10.3 Живые пропсы и экраны
- Префаб объявляет **каналы** — что в нём оживает: `channels: { screen: { kind: 'media' }, led: { kind: 'blink' }, door: { kind: 'range' } }`; в сцене — ключи `keys["ch.<имя>"]`.
- **Экран (media)**: видео (mp4), последовательность кадров или нарисованная «программа» на поверхности экрана, с кривизной кинескопа, сканлайнами и свечением; время клипа —
  от времени сцены (с какого момента, скорость, петля). Источник — файл видео (refs, «⬇ по ссылке», YouTube через yt-dlp, кусок «с / по»). Права на кадры — у владельца (в «Права» упаковки).
- **Индикаторы**: мигание (частота, скважность), вкл / выкл по ключам.
- Монитор «Ностальгии»: экран → канал `screen` (xp / select / game остаются «программами», плюс media), запуск San Andreas — настоящие кадры игры, курсор мыши — ключами.
- Claude: в мастерской пропса и из сцены (`scene ops` по `keys["ch.screen"]`), агент знает каналы из `scene brief` (префаб перечисляет свои каналы).
