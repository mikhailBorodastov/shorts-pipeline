# S10. Мастерская — персонаж и пропс: скелет, анимации, предметы в руках, живые части

Пожелание автора (1 окт 2026): библиотека и препродакшен — полноценное место, где ассет можно посмотреть, собрать скелет (Claude собирает, автор правит),
сделать анимации, дать персонажу предмет в руку и подогнать хват, оживить пропс (индикаторы, экран с настоящими кадрами игры) — для 2D и 3D.
Claude делает всё то же из любого места (агент, редактор сцены): «пусть на мониторе запустится San Andreas», «дай жене трубку».
Порядок (решение автора): **S10.1 скелет и анимации → S10.2 предметы в руках → S10.3 живые пропсы и экраны**. Экран показывает **настоящие кадры игры**.
Ориентир — профессиональные программы, их приёмы перечислены у каждого пункта.

## 0. Рисуем с прицелом на анимацию (сделано)
`ideas_claude.ANIM_READY` — в промптах черновиков элементов и сборки персонажа: части, которые будут двигаться (дверь, шторы, экран, индикаторы, силуэт в окне отдельно от рамы и штор),
— отдельно с параметром `o.*`; персонаж без «вшитых» предметов, руки свободны; повторяющееся — одной функцией с параметрами; в summary — список частей и параметров.

## S10.1 Мастерская: скелет и анимации
**Что это.** Страница `🛠 Мастерская` ассета = редактор сцены (S1) в особом режиме на служебной сцене, где стоит только этот ассет на нейтральном полу, камера и свет по умолчанию.
Открывается: из библиотеки (страница предмета → «🛠 Мастерская»), из препродакшена (карточка персонажа / пропса → «🛠 Мастерская»).
Служебная сцена — элемент `kind: scene` с `ws: { src }` (src — `lib:<kind>/<slug>@N` или `el:<id>@vN`) в том же видео (препродакшен) или в служебном видео канала «🛠 Мастерская»
(`service: true`, для библиотеки); в списках сцен, монтаже и «Начать производство» её нет. Всё, что умеет редактор, работает и тут: ключи позы, IK, клипы, агент, история, кадры.

**Режимы — как Setup / Animate в Spine:**
- **🦴 Сборка** (скелет). 2D, риг частей: суставы мышью, кость — добавить / удалить / переименовать / сменить родителя, пределы поворота, порядок частей (z), к какой кости
  прикреплена часть (было в `stands/skel.html` — переносим внутрь мастерской). 3D, риг `model`: таблица «наша кость ← кость модели, ось, знак» с проверочными позами
  (руки вверх, шаг) — как retarget-маппинг в Maya HumanIK / Blender Rigify; «✨ Claude, собери / почини скелет» (charparts / auto_rig). Позы и эмоции — библиотека поз
  (как Pose Library в Blender): сохранить текущую, применить, по имени.
  Сохранение — новая версия ассета (библиотека — `fork`, элемент — vN+1).
- **🎞 Анимация** (клипы). Таймлайн редактора + **Dope Sheet** по каналам (кости, лицо, карточка): ключи — выделить рамкой, сдвинуть, растянуть, копировать / вставить,
  **вставить зеркально** (Blender Ctrl+Shift+V: L↔R), ease ключа (linear / io / in / out / hold — как интерполяция в Graph Editor), **onion skin** (полупрозрачные позы ±N кадров,
  как в Toon Boom / Spine), автоключ, ключ всем (I), IK-ручки на кончиках лап с FK/IK. Рабочая область [in, out] → **«💾 Сохранить как клип»** (`library/anims/<тип>/<slug>.json`,
  петля, длина) — клип сразу доступен всем персонажам этого типа скелета (как retarget по общему скелету). «+ научить» (Claude пишет клип словами) и «✨ доведи».
  Клип можно открыть обратно в мастерской и поправить (клип ↔ ключи позы).

## S10.2 Предметы в руках (слоты и вложения — как Spine slots/attachments, Maya parent constraint)
- Слоты скелета (`slots`: handL, handR, head, back…) принимают **предмет**: любой пропс (`lib:` / `el:`). В сцене — ключи `keys["hold.handR"] = [{t, v: ref | null}]`
  (взял в 4.2 с, положил в 7 с); в мастерской — пробный предмет в слоте.
- **Хват под предмет** — у персонажа `grips[<предмет без версии>] = { off, rot, scale, follow, back, pose, handL?/handR? }`: как предмет сидит в руке и как согнута лапа.
  Подгоняется в мастерской с предметом в руке (ползунки, поза — «с курсора»), сохраняется в версии персонажа (`grips.json`). Без хвата — нижним краем в кисти, вдоль предплечья.
- 2D (карточка): предмет-карточка или 3D-пропс у точки кисти в плоскости карточки, поворот — с костью; 3D-модель: прикрепление к кости арматуры.
- **Жена-ёжиха**: нейтральная версия без трубки (костюм без `phone`), трубка — отдельный пропс «Телефонная трубка» + хват.

## S10.3 Живые пропсы и экраны
- Префаб объявляет **каналы** — что в нём оживает: `channels: { screen: { kind: 'media' }, led: { kind: 'blink' }, door: { kind: 'range' } }`; в сцене — ключи `keys["ch.<имя>"]`.
- **Экран (media)**: видео (mp4), последовательность кадров или нарисованная «программа» на поверхности экрана, с кривизной кинескопа, сканлайнами и свечением; время клипа —
  от времени сцены (с какого момента, скорость, петля). Источник — файл видео (refs, «⬇ по ссылке», YouTube через yt-dlp, кусок «с / по»). Права на кадры — у владельца (в «Права» упаковки).
- **Индикаторы**: мигание (частота, скважность), вкл / выкл по ключам.
- Монитор «Ностальгии»: экран → канал `screen` (xp / select / game остаются «программами», плюс media), запуск San Andreas — настоящие кадры игры, курсор мыши — ключами.
- Claude: в мастерской пропса и из сцены (`scene ops` по `keys["ch.screen"]`), агент знает каналы из `scene brief` (префаб перечисляет свои каналы).

## Как сделано (S10.1, часть 1 — 1 окт 2026)
- `server/ws_api.py`: `open_ws` — ассет из библиотеки берётся в служебное видео канала «🛠 Мастерская» (`service: "workshop"`, не в списке роликов), из препродакшена — в своё видео;
  служебная сцена `ws: {el}` (не в препродакшене, списке сцен, монтаже, упаковке, экспорте — `preprod.live`, `montage_api`, `pack_api`, `studio.js`), объект `asset` = текущая версия
  (`el:<id>@vN`, обновляется при каждом открытии), камера по росту. `/api/scene` → `ws` (ассет, тип скелета, из библиотеки ли). CLI `ws open <src> [--video]`, `ws clip …`.
- Входы: «🛠 Мастерская» на странице предмета библиотеки и в карточке персонажа / 3D-пропса препродакшена; «← назад» возвращает туда, откуда пришёл.
- `web/editor/workshop.js` — вкладки «🎞 Анимация» (💾 сохранить как клип — окно I/O → `ws_api.save_clip` / `pose_to_tracks`; 📂 клип → ключи позы — поправить готовый;
  ⇋ отразить позу L↔R — знак поворота по зеркальным пределам костей, цели IK и взгляд по x) и «🦴 Сборка» (карточка ассета, 📚 в библиотеку — `ws_api.publish`).
- Проверено: «Жена-ёжиха» из библиотеки → мастерская → «Машет лапой» в ключи → отражено → «Машет левой лапой» (`hog/maset-levoi-lapoi`), лента на жене — левая лапа.
- Дальше в S10.1: редактор суставов прямо в мастерской (сейчас — в карточке), карта костей 3D-модели, onion skin, Dope Sheet по каналам (рамкой, растянуть).

## Как сделано (S10.1, часть 2)
- **🦴 Сборка** (`ws_api.setup_info` → `/api/ws/setup`): риг частей — «🦴 Суставы и части» (редактор `stands/skel.html` во всплывающем окне мастерской; сохранение — задача `charrig`,
  мастерская ждёт её, переключает объект на новую версию и перезагружается); ёжик (`param`) — пояснение (скелет параметрический); 3D-модель — таблица «наша кость ← кость модели,
  ось, знак» (кости модели — из `info.json` или Blender `normalize` один раз, имена как в three.js без точек; карта читается из prefab.js с любыми кавычками и `off`)
  → «💾 Сохранить карту» (`/api/ws/bonemap` → `save_bonemap`: новая версия элемента — та же модель, новый prefab.js, кадры поворотного стола и поз).
- **👻 Калька** (onion skin): позы t − Δ (голубая) и t + Δ (оранжевая) рисуются `rigDraw` на прозрачном холсте поверх 3D-вида в рамке плоскости карточки (bounding box геометрии,
  тень на полу пропускается); совпадающее с текущей позой вычитается — видно, что сдвинулось. Для 2D-персонажей (карточки); у 3D-моделей — позже.
- **🗑 версия черновика** в препродакшене (`/api/el/render/archive`): неудачная лепка TRELLIS / рисунок → `_archive/videos/…/preprod/<el>/vN-…`, текущей становится прошлая.
- **Dope Sheet** (`web/editor/timeline.js`): «▸ 🦴 поза» раскрывается по каналам (`armL.rot`, `ik.armR`, `face.mouth`, `sit`…) — ромбы там, где ключ позы задаёт канал,
  тянешь — едет весь ключ позы; рамкой выделяются ключи любых строк; ПКМ → «⟷ растянуть / сжать по времени…» (вокруг первого выделенного, ×2 — медленнее вдвое);
  кривые (плавно / линейно / разгон / торможение / стоп-кадр) — и для ключей позы. S10.1 закрыт.

## Как сделано (S10.2 — предметы в руках)
- **В сцене** (`engine/scene.js`): `o.hold = { handR: ref }` — всё время, `o.keys["hold.handR"] = [{ id, t, v: ref | null }]` — ступенькой (взял / положил);
  `sceneHoldSlots / sceneHoldAt / sceneHoldRefs`, ссылки предметов входят в `scenePropRefs` (загружаются с пропсами сцены; редактор догружает новый через `ED.loadProp`).
  Предмет строится тем же `scnBuildPrefab`, клик по нему выбирает персонажа. Карточка: точка кисти — `lastJoints` (`armR.end`, у рига частей — кость слота `skel.slots`),
  поворот — по предплечью; ставится в `card.onJoints` сразу после перерисовки карточки, поэтому едет с лапой в том же кадре. 3D-модель — дочерний узел кости кисти (карта костей).
- **Хват** (`engine/rig.js`): `char.grips` из `prefab.js` + `grips.json` рядом (`rigLoadExtras`); ключ предмета — без версии (`props/<slug>` для `lib:`, `el:<id>`), `'*'` — для любого,
  `grips[k].handL` — особый хват левой (`rigGrip`). `off: [поперёк, вдоль]` — доли роста **в осях предмета** (как вложение на кости в Spine), `rot` — к предплечью
  (`follow: false` — держит ровно, как трубку у уха), `scale`, `back` — за карточкой. `pose` — поза руки при хвате: слой `c.holdLayer(T)` под ключами позы
  (`scenePose = сцена → хват → ключи`): взяла трубку — лапа сама у уха, ключами поверх можно доиграть.
- **Мастерская, вкладка «✋ Предметы»** (`web/editor/workshop.js`): рука (правая / левая), сетка 3D-пропсов видео и библиотеки (копии библиотечных — только `lib:`, чтобы хват
  был один на предмет), ползунки «поперёк / вдоль / поворот / размер», «вслед за предплечьем», «за лапой» — живьём (`char.grips` страницы); «📌 Поза руки = поза на курсоре»
  забирает ключи позы кадра в хват; «💾 Сохранить хват» → `POST /api/ws/grips` (`ws_api.grips_save`) пишет `grips.json` рабочей версии ассета (данные, без новой версии —
  как `emotions.json`), в библиотеку — «📚 В библиотеку». CLI: `studio.py ws grips <видео> <ассет> ['<JSON>']`.
- **Агент**: правило в `SCENE_RULES` («дай трубку на 3-й секунде, на 6-й положи» — ключи `hold.handR`, отдельный объект не ставить), `RULES_REV = 6`.
- **Жена-ёжиха**: `lib:characters/jena-ejiha@4` — нейтральная (`wearOpt['svitr-zheny'] = { phone: false, hold: false }`), трубка — `lib:props/telefonnaa-trubka@1`
  (наклейка `P3.sticker`, низ — микрофон), хват — у уха (`follow: false`, `rot 0.3`, поза `armR rot −2.6 len 0.65`, взгляд вбок, рот «о»). Тесты — `engine/test/scene.test.js` (21).
