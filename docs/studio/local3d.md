# Локальная 3D: TRELLIS.2 и Pixal3D (вне плана, после S9)

Решения автора: отдельный ComfyUI для Studio (свой `D:\Neuro\ComfyUI` 0.3.26 не трогаем), модели TRELLIS.2 + Pixal3D (+ multiview), основное применение — персонажи,
refine — все четыре вида: черновик → чистовик, перетекстурить, правки по пинам, несколько ракурсов.

## Как устроено
- **Установка** — `tools/comfy_setup.py` (или ⚙ Настройки → «🖥 Локальная 3D» → Установить): ComfyUI portable v0.38.0 (nvidia, GitHub, 2 ГБ) в `_studio/tools/comfyui/`
  (в git не лежит) + модели Hugging Face Comfy-Org (MIT), int8: `trellis_2_int8_convrot` 5,25 ГБ, `pixal3d_int8_convrot` 5,58, `pixal3d_multiview_int8_convrot` 5,58,
  VAE формы 1,10 и текстуры 0,95, `dino_v3_L_naf_fp32` 1,22, `birefnet` 0,44, `moge_2_vitl_normal_fp16` 0,63. Докачка с места обрыва (`.part` + Range).
- **Запуск** — `server/comfy3d.py`: Studio сама поднимает ComfyUI без окна на `127.0.0.1:8199` при первой лепке (лог — `tools/comfyui/comfy.log`), держит модели в видеопамяти (~6 ГБ в покое);
  «⏹ Освободить видеопамять» в настройках — остановить. CLI: `python _studio/server/comfy3d.py status|start|stop|run <картинка> <папка> '<JSON>'`.
- **Граф** — шаблоны Comfy-Org (`server/comfy/*.json`), переведённые в API-формат по `/object_info` (`to_api`: виджеты по порядку, `control_after_generate`, вложенные поля
  динамических списков как `имя.поле`, новые обязательные входы — по умолчанию); правки по id узлов (`comfy3d.N`), `prune()` убирает цепочки без входа. Ошибки проверки графа — сразу наверх.
- **Режимы** (`charmodel`, `source: trellis`, `models3d.char_job` → `comfy3d.generate`):

| режим | что меняется | сиды | время на RTX 4070 Ti SUPER 16 ГБ |
|---|---|---|---|
| `draft` 🖥 TRELLIS | форма 512³ без апскейла, текстура 1024, сетка 150k | новые | 70–90 с |
| `final` ⬆ Довести | + апскейл 1536³, текстура 2048, сетка 400k | структура, форма, текстура — от черновика | ~190 с |
| `retex` 🎨 Перекрасить | форма та же; новый сид текстуры или другая картинка только для текстуры (`texref` → своё conditioning в `Trellis2TextureStage`) | структура, форма, апскейл — от базы | ~190 с (стадии формы считаются заново) |
| `fix` Поправить | что скажет Claude (`trellisfix`): `reseed` стадий, движок, картинка, `pad`, `bg`, сетка, текстура | остальные — от базы | как draft/final |

  Движки: `pixal3d` (по умолчанию: точнее повторяет картинку), `trellis` (TRELLIS.2: свободнее достраивает спину), `multiview` (Pixal3D по 2–4 ракурсам front/left/back/right — свои картинки вместо кусков листа-разворота).
  Всё, чего не передали, наследуется от базовой версии (`meta`: seeds, pad, bg, tex, faces, ref, views, texref) — иначе вход сети другой и фигура «плывёт».
- **«Поправить»** у версии TRELLIS — действие Claude `trellisfix` (Sonnet, только Read): читает пины (`fx.main.pins3d`, лист `pins.png` с четырёх сторон) и «в целом», смотрит кадры и копии референсов,
  отвечает настройками (`reseed`, `engine`, `stage`, `ref`, `texref`, `views`, `pad`, `bg`, `faces`, `tex`) и фразой автору; правки снимаются, страница по `onResult` запускает `charmodel` с `mode: fix`.
  Чего нейросеть словами не умеет (мимика, «короче клинок» не гарантирован) — Claude так и говорит и предлагает поправить референс.
- Дальше как у Meshy/Tripo: Blender `normalize` → авто-скелет (конверты, 15 костей) → `prefab.js` (`rig: 'model'`) → кадры поворотного стола и поз → `renders[]` (`source: trellis`, `meta`).

## Проверено (1 окт 2026, тестовый элемент «Ульджан — TRELLIS тест» в WoW)
v1 черновик Pixal3D по концепт-арту (81 с) → v2 «Довести» (193 с, та же фигура, детали и цвета ближе к концепту) → v3 «Поправить» по заметке «кинжал длинный, шкура темнее концепта»
(Claude: reseed shape/upsample/texture + texref) → v5 «Перекрасить» новым сидом (форма v3 сохранилась; v4 — до исправления наследования `pad`, фигура поплыла) → v6 черновик TRELLIS.2 (90 с вместе с запуском ComfyUI).
Multiview — граф проверен на двух ракурсах (82 с). Сырые GLB обоих движков смотрят вперёд одинаково (проверено в Blender).

## Ограничения
- Перетекстурить чужую модель (не из TRELLIS) нельзя: нужна форма в латенте TRELLIS. Для ассетов — Meshy/Tripo-ретекстур или Blender.
- `retex`/`final` пересчитывают стадии формы (кэш латентов между запусками не храним).
- Позу сеть повторяет с картинки (присевший тролль — присевший); для персонажа лучше референс в A/T-позе — авто-скелету так проще.
