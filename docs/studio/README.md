## Видение в пяти строках

1. **Один путь в одном окне:** Идея → Вопросы → Название → Сценарий → Препродакшен → Голос → Монтаж (с ревью) → Упаковка — с S11 (2 окт 2026), см. [stage11-flow.md](stage11-flow.md); раньше было Препродакшен → Сцены → Сценарий → … → Ревью.
2. **Препродакшен — сердце:** до сценария готовы все персонажи, пропсы, сцены и звуки, согласованные с автором; сцены оформлены в редакторе
   (расстановка, камера, движение, анимации) — это «репетиция», которую при монтаже растягивают под голос.
3. **Библиотека канала:** утверждённые персонажи (со скелетами, костюмами, эмоциями, анимациями), пропсы, 3D-ассеты и звуки
   переиспользуются во всех роликах; у каждого канала свой стиль и своя библиотека.
4. **Агент рядом всегда:** панель чата справа и комментарии на объектах; всё, что делает автор, агент видит понятными строками;
   всё, что делает агент, отменяется одним Ctrl+Z. Ручные правки автора агент не трогает без прямой просьбы.
5. **Один движок везде:** three.js + наш бумажный тулкит в редакторе, черновиках, ревью и финальном рендере — что видишь, то и получаешь.

## Решения автора (сводка)

**Продукт**
- Название — Claude Studio. Отдельное окно (десктоп-оболочка), первый экран — проект-канал: слева видео со статусами, справа библиотека, ⚙ стиль, «+ видео».
- Несколько каналов в одной рабочей папке, проект переключается сверху. Каналы: «Доедать будешь» (ёжик), в будущем другие (например, WoW с троллем).
- У канала свой стиль и стайл-гайд; новый канал начинается с подробного интервью Claude (визуал и герой, подача и голос, монтаж и звук, упаковка);
  стиль меняется в настройках проекта.
- Убрать: банк идей, лист проекта, старый путь «Штурм идей», просмотры, итоги, биты, смыслы, выбор жанра. Всё старое — в архив, не удалять.
- Новое видео: идея (без подсказки), контекст — широкое поле с редактором (туда можно вставить хоть целый сценарий), референсы,
  вопросы Claude, углы атаки и финалисты названия. Упаковка — в конце.
- Приложение закрывает весь путь, включая сценарий, голос, монтаж, ревью; «✨ Собрать» — агент делает то, что сейчас делает Claude Code в чате.
- Готовые ролики переезжают в проект «Доедать будешь»; утверждённое из них — в библиотеку.

**Редактор**
- Раскладка как в Blender: кадр в центре, справа дерево объектов и свойства, внизу таймлайн; агент — панель справа (вызывается в любой момент) + комментарии на объектах.
- Хоткеи: объекты — как в Blender, таймлайн — как в Premiere Pro. Ctrl+Z / Ctrl+Shift+Z.
- Таймлайн: клипы анимаций + ключи движения, раскрывается до свойств.
- Приоритеты: положение объектов → камера → движение объектов и персонажей → анимации персонажа (включать, учить промптом) → поза.
- Поза: тянешь лапу за кость (IK) — сразу ключ; 💬 подпись + «✨ Claude, доведи».
- Персонажи — 2D-карточки в 3D (Paper Mario: доворачиваются к камере — правило канала «Доедать будешь»); заложить 3D-персонажей на будущее.
- Сцена в препродакшене — репетиция движений, длина любая, может быть целым роликом с несколькими планами камеры. Ходьба по пути — автоматически, с возможностью перебить.
- Утверждается вся петля сцены. Во время работы агента сцена блокируется; написать агенту посреди работы можно.

**Персонажи и библиотека**
- Новому персонажу Claude прикидывает скелет (похож на ёжика — скелет ёжика; монстр — свой); кости поверх рисунка, правятся руками и промптом.
  Заложить подробный риг (веса, ограничения суставов).
- Два режима рига: «гнущиеся части» (основной) и «кукла на булавках»; стыки прячем.
- Анимации наследуются между персонажами с одним скелетом; «+ научить» промптом — дальше автор использует анимацию сам.
- Эмоции — вкладка персонажа + дорожка лица; липсинк нужен.
- Костюмы и пропсы надеваются на точки крепления скелета, персонаж составной; версии персонажа, сцена помнит версию.
- В библиотеку попадает утверждённое ✓ (в том числе 3D-ассеты, сделанные Claude).
- 3D-пропсы: из фигур кодом, из бесплатных моделей, через Blender (установит автор) — по сложности.

**Инфраструктура**
- Движок остаётся (three.js в браузерном движке), визуал редактора — «профессиональный», отдельный от нынешних страниц.
- Git заводим. Монтаж (общий таймлайн) — делаем сейчас, со всеми дорожками. Правки в ревью — пометки для Claude (двигаешь / меняешь позу + комментарий).

## Правила для реализатора

1. **Этапы по порядку** из [roadmap.md](roadmap.md). Этап закончен, когда выполнены его критерии готовности и автор посмотрел результат.
   Не начинай следующий этап, пока автор не принял предыдущий.
2. **Каждый этап оставляет рабочую систему.** Старые ролики должны собираться (`build.sh`), «Штурм» / Studio — открываться.
3. **Git с этапа S0:** коммит на каждый законченный кусок, понятные сообщения по-русски.
4. **Спека — источник правды.** Меняешь устройство — обнови `architecture.md` и документы этапа в том же коммите. Решения, которые не описаны, — спроси автора, не придумывай.
5. **Всё понятно агенту:** любое действие в редакторе — операция с человекочитаемым описанием в истории; у Claude есть те же команды через CLI.
6. **Скачивание файлов** (библиотеки, Electron, модели) — одним коротким вопросом со списком (имя · источник · размер), как принято в пайплайне.
7. **Язык и тон:** интерфейс и документы по-русски; пользователю — «локальный скрипт / приложение», не «сервер».
8. **Доступность:** всё доступно с клавиатуры; фокус виден; Tab ходит по спискам и подсказкам.
9. **Проверка глазами:** после каждой видимой правки — скриншот (встроенный браузер или `render_shot.js`), а не «должно работать».
