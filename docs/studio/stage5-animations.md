# S5. Анимации персонажа — ТЗ реализации

Цель ([roadmap](roadmap.md#s5-анимации-персонажа), форматы — [architecture §3.3, §3.6](architecture.md#36-скелет-риг-анимации)): персонаж в сцене двигается **данными** —
клипами из библиотеки типа скелета, ключами позы с IK, эмоциями, ходьбой и липсинком; новые движения Claude выучивает по просьбе автора.

**Готово, когда** (решение автора: приёмка в **копии «Комнаты»** — «Комната — проверка анимаций», сама «Комната» не меняется; второй ёжик — **жена-ёжиха**):
ёжик подходит к столу (ходьба включается сама), чешет затылок (клип, выученный промптом при авторе), тянется к кнопке монитора (IK + «✨ доведи»), удивляется (эмоция);
тот же «чешет затылок» работает у жены-ёжихи без доработки.

## 1. Данные

- **Клип** `library/anims/<type>/<slug>.json`: `{ schema: 1, id: '<type>/<slug>', name, type, dur, loop, tracks, prompt, by, preview, created }`.
  `tracks` — дорожки `"<кость>.<rot|len|sq>"`, `"face.<поле>"`, `"ik.<кость>"` (цель лапы `[x, y]` в долях роста от ног, y вверх),
  `"card.<y|rz|ry|sy>"` (карточка целиком: подпрыгнуть, качнуться, повернуться, сплющиться), `"sit"`, `"facing"`.
  Ключ дорожки — `[t, значение, ease?]` (ease — к следующему, как у ключей сцены; строки и логические — ступенькой). Значения костей — от позы покоя, как в позе S4.
  Процедурные клипы — `proc: 'gait'` (ходьба: фаза от пройденного пути).
- **Объект-персонаж в сцене** (`src.prefab = 'lib:characters/<slug>@N'`): `clips: [{ id, t, dur, anim, speed, loop }]`, `pose: [{ id, t, bones, ik, note, refine: 'open'|'done' }]`,
  `walk: 'auto' | 'off' | '<anim>'`, `lipsync: { sound: '<id звука сцены>', gain }`; эмоции и костюмы — ключи `emotion`, `wear.<костюм>` (S4; architecture `face[]` = дорожка `emotion`).

## 2. Движок — `engine/rig.js` + `engine/scene.js`

- Слои позы (снизу вверх): база персонажа → поведение префаба (если есть) → **клипы** (вес 1 внутри, кроссфейд 0.2 с на краях и пересечениях) → **ходьба** (если объект едет по `keys.pos`
  и ноги не заняты клипом) → **ключи позы** (интерполяция по каналам между ключами, IK решается последним) → эмоция / костюмы → липсинк (рот).
- IK: ёжик — аналитически (`rigHogAim`: угол + длина лапы), риг частей — две кости (плечо + предплечье), закон косинусов, сгиб по знаку `bend` кости.
- Ходьба ёжика: фаза = путь / шаг · π; лапы вверх по очереди, руки навстречу, карточка качается и подпрыгивает (как `gait3`). Вес ходьбы — от скорости по ключам позиции.
- Липсинк: огибающая громкости звука (RMS окнами 1/30 с, считает сервер — `/api/scene/env`) → рот `open` выше порога, с удержанием 2 кадра.

## 3. Редактор

- Таймлайн: у персонажа строки **клипы** (полосы: перетащить — сдвиг, край — длина, двойной клик — скорость / петля / удалить) и **поза** (ромбы ключей позы).
- **Tab** (или «+ клип») с выбранным персонажем — список анимаций его типа скелета (поиск, ↑↓, Enter) → клип на текущем моменте; последний пункт — «+ научить…».
- **Поза**: у выбранного персонажа — ручки на кончиках лап; тянешь — ключ позы с целью IK на текущем моменте; в свойствах ключа — 💬 подпись и «✨ Claude, доведи» (агент сцены: наклон, подход и отход, лицо).
- Свойства персонажа: ходьба (сама / выкл), липсинк по звуку сцены.

## 4. «+ научить»

- В листе персонажа (вкладка «Анимации») и в редакторе: просьба словами («чешет затылок левой лапой») → задача Claude (Opus) `animteach`: пишет клип по формату §1, снимает ленту кадров
  (`stands/char.html?…&anim=…&strip=1`), смотрит, правит 2–4 прохода → `library/anims/<type>/<slug>.json` + `preview.png` (лента). Дальше автор ставит клип сам.
- Клип типа доступен всем персонажам этого скелета (наследование) — жена-ёжиха получает «чешет затылок» без доработки.
- Базовый набор ёжика (руками, из `moves3d.js` / `ANIMATIONS.md` / поведения «Комнаты»): ходьба (proc), прыжок, машет лапой, трёт глаза, радуется, поворот спиной, кивает.

## 5. Порядок работ

1. `rig.js`: клипы, слои, IK, ходьба, липсинк; базовый набор ёжика; стенд `char.html` с `&anim` и лентой; тесты чистых функций.
2. Жена-ёжиха на скелете hog (Claude: костюм по её листу) — `charparts` для «похожих на ёжика» пишет персонажа `param` с костюмами.
3. Копия «Комнаты» с ёжиком из библиотеки: ключи позиции — ходьба сама.
4. Редактор: строки клипов и позы, Tab-список, ручки IK, «✨ доведи».
5. «+ научить» (лист и редактор) → «чешет затылок»; эмоция «удивление»; липсинк по тестовой фразе; жена с тем же клипом; клип сцены.
