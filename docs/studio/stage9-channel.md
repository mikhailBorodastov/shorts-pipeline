# S9. Новый канал — ТЗ реализации

Цель ([roadmap](roadmap.md#s9-новый-канал)): **«+ Канал»** — интервью Claude по стилю → стайл-гайд, палитра, шрифты, голос, субтитры, правила **только этого канала**,
тулкит, главный герой в библиотеку со своим скелетом; ⚙ Стиль — правка всего этого из приложения с историей.

**Готово, когда** (решения автора: на интервью отвечает **сам**; тролль — по **референсам из интернета**, **3D-модель в Blender**):
создан тестовый канал «WoW» с троллем: интервью пройдено, стиль сохранён, тролль со своим скелетом стоит в пустой сцене.

## 1. Канал

- «+ новый канал…» в переключателе каналов → `#/newchan` (название, иконка, одна строка о канале) → `POST /api/channel/new` (`server/channel_api.py new_channel`):
  папка `<рабочая папка>/<Название>/` — `channel.json`, `style/` (style-guide.md, стартовый `toolkit.js` = бумажный), `library/` (characters, props, skeletons, anims, sounds, index.json), `videos/`,
  `.gitignore` как у других каналов, **свой git** с первым коммитом; канал становится текущим. CLI: `studio.py channel new "Имя" --icon --about`.

## 2. Интервью и сборка стиля

- ⚙ Стиль → «🎤 Интервью»: «✨ Вопросы» (задача `chanq`, Sonnet) — ≈20 вопросов по блокам: 🎨 визуал и герой, 🗣 подача и голос, 🎞 монтаж и звук, 📦 упаковка;
  ответы — `channel.json → interview.qa[]` (операциями), «+ ещё» по блоку, свои вопросы.
- «✨ Собрать стиль» (задача `chanstyle`, Opus): `style/style-guide.md` (8 разделов), `palette.json` (цвета + шрифты), `voice.json` (edge-tts), `captions.json`,
  `channel.json`: `about`, **`rules` + `ruleDefs`** — ТОЛЬКО правила, нужные этому каналу (подпись, тип, значение, «зачем»; движок понимает `paperFacing` / `facingMaxDeg` — лишь у бумажных карточек,
  `style3d`, `toolkit`; остальные — для Claude при сценариях и сборке), `toolkitChoice`, `hero` (имя, внешность, характер, тело). Страница перечитывает стиль, когда сборка закончилась.
- Каждое сохранение файла стиля кладёт прошлую версию в `style/.history/` — вкладка «🕘 История», «↺ вернуть».

## 3. ⚙ Стиль — вкладки

- 📝 Стайл-гайд (+ название, иконка, «о канале»), 🎨 Палитра и шрифты (цвета, шрифты заголовков / субтитров / рукописный с превью),
  🎙 Голос и субтитры (голос, скорость, высота, «▶ послушать»; субтитры — шрифт, жирность, кегль, цвет, **цвет сказанного слова**, обводка и толщина, подложка, тень, ЗАГЛАВНЫЕ, появление слова, высота;
  превью как в ролике; **«⬆ свой шрифт»** — `style/fonts/`; **«⬆ пример субтитров»** + «✨ как на картинке» — задача `chancaps`, Claude смотрит скрин и подбирает настройки),
  ⚙ Правила (только `ruleDefs` канала), 🦸 Герой, 🕘 История.
- Субтитры канала попадают в ролики: генератор монтажа пишет `CAPTION_STYLE` из `style/captions.json`, копирует `style/fonts/*` в `assets/fonts` проекта; шаблон `main.js drawCaptions` понимает все поля.

## 4. Герой канала

- 🦸 Герой: имя, внешность, характер, тело (из сборки стиля, правится), «как делать»: **3D-модель в Blender** | бумажная карточка из частей | по параметрам (как ёжик); референсы — `style/hero/`.
- «🦸 Сделать героя» (задача `chanhero`) → служебное видео «Герой канала — <имя>» (`heroSetup`): элемент-персонаж с референсами (`make`) и **пустая сцена редактора** (`channel_api.empty_scene`: пол и задник цветами палитры).
- **3D-герой**: «🦴 со скелетом» у персонажа с `make: blender` (`ideas_claude.charblender_spec`, Opus): `model.py` (bpy: меш, арматура Rig, автовеса, материалы по палитре, shape keys лица) →
  `blender_run.py` → `model.glb`; `prefab.js` — `character({ rig: 'model', model, h, skeleton, bones: { <кость позы>: { bone, axis, k, off } }, face: { mouth, lid } })`;
  кадры — `render_prop.js` (поворотный стол, `--params` — позы), 2–4 прохода. 📚 в библиотеку — `library/characters/<slug>/vN` (prefab.js, model.glb, model.py) + `skeletons/<тип>.json` (`rig: model`, кости).
- **Движок** (`engine/rig.js modelChar`): персонаж-модель в сцене — клон glb (SkeletonUtils), поза студии (клипы типа скелета, ключи позы, ходьба, эмоции) поворачивает кости арматуры
  вокруг осей модели по карте `bones`, `card.*` — вся модель, лицо — shape keys, `idle` — клип glTF как база. IK для моделей — позже.
- Голос канала: `tts.py` берёт `style/voice.json` канала (voice, rate, pitch), если в шапке `script.md` нет своих строк; агент при «✨ Собрать» следует стайл-гайду и правилам канала.

  10 цветов, голос DmitryNeural (+5%, −8 Гц), субтитры (пергамент и золото, обводка, тень, ЗАГЛАВНЫЕ, «всплывает»), правила только этого канала: стиль 3D «как в игре», 2D-набор интерфейса WoW,
  костёр в начале и конце, доза «мон», кадр от 5 с, переходы интерфейсом WoW, точность лора, нативная реклама. Paper Mario в WoW нет.
- Референсы тролля — 4 картинки с warcraft.wiki.gg (`WoW/style/hero/`, права у Blizzard, только для художника).

## 6. Правки автора после первой приёмки (2026-10-01)

- **Библиотека чужого канала** — исправлено: кандидаты в библиотеку — только видео текущего канала; страница сбрасывает библиотеку, если канал сменился не через переключатель.
- **⚙ Настройки приложения** (`#/settings`, `server/settings_api.py`): ключи Sketchfab / Meshy / Tripo (`.studio/secrets.json`, показываются замаскированными; Sketchfab — ещё и `.studio/sketchfab_token.txt` для `assets.py`),
  путь к Blender (`state.json → blender`), модели Claude (`state.json → models`; переменные `IDEAS_*` важнее).
- **Источники 3D** (`assets.py`): + Quaternius и Kenney (их каталоги на Poly Pizza, у Quaternius — персонажи со скелетом и анимациями), Smithsonian 3D (CC0-сканы, `3d-api.si.edu`, Draco),
  Objaverse (модели Sketchfab из `allenai/objaverse` на Hugging Face — без токена; карта моделей 20 МБ — один раз в `.studio/cache`).
- **3D-модели** (`server/models3d.py`): каждая скачанная или загруженная модель проходит Blender — `normalize` (glb / gltf / fbx / obj / stl / usd / blend / Draco → чистый `model.glb` + `info.json`:
  кости, анимации, высота, полигоны); в ассете видно «🦴 скелет», «🎬 анимации». **⬆ своя модель** в карточке ассетов (`POST /api/assets/upload`, задача `assetupload`).
- **Скелет готовой модели подстраивается**: `bone_map` узнаёт кости Mixamo, Rigify, Tripo, Meshy, Quaternius, наши (`upper_arm.L` …) и строит карту `bones` для `rig: 'model'` (оси и знаки по договорённости поз студии);
  **анимации модели** — клипы `gltf:<имя>` на таймлайне (Tab показывает их «🎬 … (из модели)»), `idle` — база; поза студии ложится поверх.
- **Нет скелета** — `auto_rig`: арматура наших имён по пропорциям гуманоида (руки — по крайним точкам, ноги — по кластерам) + автовеса (не вышли — конверты).
- **Герой из модели** — `POST /api/char/model {source: asset | meshy | tripo}` (задача `charmodel`, без Claude): модель → скелет (готовый / авто) → `prefab.js` → кадры стола и поз → версия персонажа (`model3d`, `source`).
  «✨ Meshy» / «✨ Tripo» — «картинка → 3D» с текстурой по первому референсу и их авто-скелетом (Meshy `/openapi/v1/image-to-3d` + `/rigging`; Tripo v3 `/files`, `/generation/image-to-model`,
  `/animations/rig-check`, `/animations/rig` со `spec: mixamo`); ключи — в ⚙ Настройках. **Проверено без ключей не было** — первый прогон с ключом автора.
- **Blender (Claude)**: задание больше не просит low-poly — детальная модель по референсам (органика через subdivision и проминание, пальцы, пряди, складки, рисованные тени цветами вершин, до ~200 тыс. треугольников).
- Проверено: нормализация и распознавание костей Ульджана (16 костей позы — как у Claude), авто-скелет на модели без арматуры (18 костей, автовеса, позы «руки вверх» и «шаг»), загрузка своей модели и «🦴 Сделать героем».

## 7. 3D-герои: IK, обучение движениям, четвероногие, анимации провайдеров

- **IK для 3D-моделей**: ключ позы `ik: { armR: [x, y] }` (доли роста от ног, x — вправо в кадре, y — вверх, глубина — как у плеча) решается по арматуре (`modelChar.solveIK`, CCD по цепочке плечо → предплечье → кисть / бедро → голень → стопа);
  `rigSolveIK` у персонажа-модели только передаёт цели. Ручки IK в редакторе для моделей — ещё нет (цели — ключами позы и «✨ доведи»).
- **«+ научить» на 3D-скелете**: `render_anim.js` сам узнаёт персонажа-модель и снимает ленту с 3D-стенда (`stand3d.html?prop=<персонаж>&anim=<клип>&still=1`, кадры по длине клипа) —
  обучение движениям работает так же, как у бумажных героев (клип типа скелета, дорожки `armR.rot` …). Стенд играет клипы и позы персонажа (`tick`), `&still=<угол>` — неподвижный ракурс.
- **Четвероногие**: `auto_rig` сам узнаёт по пропорциям (длина > 1.15 роста) или берёт `rig_type` Tripo: root → hips → spine → neck → head, лапы `thigh/shin.FL/FR/BL/BR` по углам, хвост из трёх звеньев;
  кости позы `legFL … legBR`, `shinFL …`, `neck`, `tail`…; общие `armL/armR` = передние лапы, `legL/legR` = задние (ходьба студии — рысью).
- **Анимации провайдера**: ходьба и бег Meshy (отдельные glb того же скелета) вклеиваются в модель дорожками NLA (`merge_anims`) — клипы `gltf:walking`, `gltf:running`.
  Готовые анимации Tripo (retarget по пресетам) — ещё нет: имена пресетов в документации не опубликованы.
