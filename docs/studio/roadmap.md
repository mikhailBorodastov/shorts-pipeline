# Claude Studio — этапы

Порядок — по приоритетам автора: сначала страховка (git), потом редактор сцены (самое нужное), потом каркас студии и переезд, потом персонажи и анимации, монтаж, агент, ревью, онбординг каналов.
Каждый этап оставляет рабочую систему и заканчивается показом автору. Размер — ориентир в «заходах» реализатора (один заход = несколько часов работы с тестами).

## S0. Git и страховка

**Цель:** перед большой переделкой можно откатить что угодно.
- `git init` в `_pipeline\` (код, шаблон, документы) и в `_ideas\` (только `plans/*.json`, `*.md`, `bank.json`, `brand.json`, `stats.json`; `files/`, `render/`, `.jobs/` — в `.gitignore`).
- `.gitignore` по [architecture.md §2.1](architecture.md#21-git). Первый коммит «исходное состояние».
- Проверка: `git status` чистый, `build.sh` любого проекта работает, «Штурм» открывается.
- Вне этапа: git каналов (S2).

## S1. Редактор сцены

Подробно — [stage1-editor.md](stage1-editor.md). Коротко:
- формат `scene.json` + `prefabs.js` ([architecture §3.3–3.5](architecture.md#33-сцена-scenejson--главный-формат-редактора)), `engine/scene.js` (`buildFromScene`, `applyScene`, `evalKeys`) с тестами;
- конвертер старых сцен (`element.js` + блок расстановки → префабы + `scene.json`, через Opus) — на эталоне «Комната зимним утром»;
- экран «Оформление сцены» внутри нынешнего «Штурма» (из карточки сцены), раскладка Blender, профессиональная тема;
- дерево объектов, свойства с числами, манипуляторы (`TransformControls`), группы, дубль, удаление, скрытие;
- таймлайн (Premiere): курсор, воспроизведение, J/K/L, дорожки камеры и объектов, ключи-ромбы, ease, маркеры, звуки препродакшена на дорожке;
- камера: ключи, склейки-планы, «ключ с этого вида», вид «глазами камеры» 9:16 с безопасными зонами;
- операции + история + Ctrl+Z / Ctrl+Shift+Z, `authored`, версии и автосохранение, «🎞 клип сцены» (mp4);
- простая панель агента: одна просьба → `claude -p` с командами сцены → пачка операций (отменяемая).
- **Готово, когда:** автор открывает «Комнату», переставляет объекты, делает 3–4 ключа камеры и 2 ключа движения ёжика, отменяет и возвращает, сохраняет версию,
  получает mp4 сцены — всё без Claude; просьба в панели агента («поставь лампу на стол и включи её») выполняется одной отменяемой пачкой.

## S2. Claude Studio: каркас и переезд

**Цель:** приложение становится Claude Studio с каналами; лишнее убрано; всё старое сохранено.
1. **Архив:** банк, лист проекта, статистика, `youtube.py`, старые штурмы и путь «Штурм идей», итоги → `_archive/` (данные) и из интерфейса.
2. **Папки** по [architecture §2](architecture.md#2-папки): `_pipeline` → `_studio` (пути в коде через один модуль `paths`), каналы с `channel.json`, `style/`, `library/`, `videos/`.
   Переезд — скриптом `tools/migrate_v2.py` с сухим прогоном (`--dry-run` печатает, что куда) и журналом; старые проекты → `Доедать будешь/videos/`.
   После переезда `build.sh` каждого ролика проверяется (хотя бы `snap` одного кадра).
3. **Новое видео** (`video.json`): этапы Идея → Вопросы → Название → Препродакшен → Сцены → Сценарий → Голос → Монтаж → Ревью → Упаковка
   (этапы S6–S8 пока открывают нынешние страницы / пустышки «скоро»). Идея и контекст без подсказок, контекст — широкое поле с редактором markdown;
   нет жанра, битов, смыслов, 7 вопросов; название — углы атаки и финалисты. Промпты кнопок переписаны без удалённых полей (жанр Claude выводит сам из идеи и контекста).
4. **Первый экран — проект:** переключатель канала сверху, слева видео со статусами и этапом, справа библиотека, ⚙ стиль (пока — открыть `style-guide.md` в редакторе приложения), «+ видео».
5. **Библиотека v1:** `library/index.json`, публикация утверждённых элементов (персонажи, пропсы, 3D-ассеты, звуки) с версиями и превью; поиск и фильтры;
   ссылка `lib:…@v` в сценах; перенос утверждённого из старых роликов (ёжик и его варианты, пропсы) — отдельным шагом миграции с просмотром списка автором.
6. **Окно:** Tauri-оболочка (`_studio/app`, решение автора), ярлык «Claude Studio», запуск без .bat; все хоткеи перехватываются окном.
7. **Git каналов** (`Доедать будешь/`), `.gitignore` тяжёлого.
- **Готово, когда:** ярлык открывает окно Claude Studio на проекте «Доедать будешь», видны перенесённые ролики и библиотека с ёжиком;
  новое видео проходит Идею → Вопросы → Название → Препродакшен; старый ролик пересобирается; в интерфейсе нет банка, листа, статистики, итогов.
- **Риски:** пути, зашитые в проектах (`../_studio/…` в `build.sh`, `review_server.py`) — переезд обязан их переписать и проверить; держать симлинк `_pipeline → _studio` на переходный период.

## S3. Препродакшен 2D / 3D

- У персонажа и пропса выбор `dim: 2d | 3d` (по умолчанию из канала). 2D — как сейчас (лист на `page.html`).
- 3D-пропс — три способа (Claude выбирает по сложности, автор может указать): из фигур кодом (префаб `group`), из бесплатной модели 📦 с доработкой (`model` + детали кодом),
  через Blender (скрипт `bpy` в фоне → `model.glb`; Blender ставит автор, путь в настройках; нет Blender — способ скрыт).
- Осмотр: поворотный стол (turntable) прямо в карточке элемента, орбита мышью; **пины в 3D** — клик по поверхности ставит пин с координатой на модели, Claude получает кадры с номерами с нескольких ракурсов.
- Утверждённый 3D-пропс → библиотека (префаб и / или glb + превью).
- **Готово, когда:** в «Комнате» ЭЛТ-монитор и системный блок сделаны 3D-пропсами (фигурами или моделью), поправлены пином «добавь кнопки на корпус», стоят в сцене вместо карточек.

## S4. Персонажи и скелеты

- Форматы — [architecture §3.6](architecture.md#36-скелет-риг-анимации): тип скелета, персонаж, риг `param` / `parts`, режимы `bend` / `pins`.
- **Ёжик** — риг `param` поверх `drawHog` (таблица кость ↔ параметр); все его варианты из библиотеки (в пижаме, сыщик…) — костюмы на одной базе.
- **Новый персонаж:** Claude рисует части (для `parts`) и предлагает скелет (`skeleton propose`): похож на ёжика — тип `hog`, иначе новый тип; кости поверх рисунка,
  сустав тянется мышью, список костей, «▶ проверить позами» (5 стандартных поз), правка промптом («добавь хвост из 3 костей»), ✓ → библиотека.
- **Лист персонажа** в библиотеке: превью со скелетом, вкладки Костюмы / Анимации / Эмоции / Версии; тип скелета и кто его наследует.
- **Костюмы и пропсы на персонаже** — к точкам крепления (`slots`), версии отдельно.
- **Эмоции** — набор лиц, которые рисует Claude, автор утверждает; используются дорожкой `face`.
- **Paper Mario** — доворот карточки к камере по правилу канала; спина — по сюжету.
- **Готово, когда:** в «Комнате» ёжик в пижаме — персонаж библиотеки со скелетом `hog`; новый персонаж (например, мама) получает предложенный скелет, автор двигает сустав, утверждает;
  у ёжика надета и снята кепка; в сцене ёжик доворачивается к облетающей камере.

## S5. Анимации персонажа

- Библиотека анимаций по типу скелета (JSON-дорожки костей и лица), наследование; базовый набор ёжика собирается из того, что уже есть (`moves3d.js`, `ANIMATIONS.md`, позы `drawHog`).
- Клипы на таймлайне: вставка из списка (Tab / Enter), длина краем, скорость, петля, кроссфейд.
- **«+ научить»** в листе персонажа и в редакторе: промпт → Claude (Opus) пишет дорожки, рендерит ленту кадров, проверяет, сохраняет в библиотеку типа скелета; дальше автор использует сам.
- **Ходьба:** при движении по ключам позиции клип ходьбы включается сам, фаза от пройденного пути; перебить — выключить `walk` или поставить свой клип.
- **Поза:** выбрал персонажа → ручки на концах костей; тянешь лапу (IK) → ключ позы; 💬 подпись → «✨ Claude, доведи» (пальцы, наклон, подход и отход) — результат новой пачкой.
- **Лицо:** дорожка эмоций; **липсинк** по громкости голоса (включается на монтаже, до голоса — по тестовому звуку).
- **Готово, когда:** в «Комнате» ёжик подъезжает к столу (ходьба сама), чешет затылок (клип, выученный промптом при авторе), тянется к кнопке монитора (IK + «доведи»), удивляется (эмоция);
  та же «чешет затылок» работает у ёжика-мамы без доработки.

## S6. Сценарий, голос, монтаж

- **Сценарий** в приложении: нынешняя раскладка `script.html` (сцены, VO, заметки, «переозвучить», `check_script.py`) как этап видео; сцены сценария связаны со сценами препродакшена.
- **Голос:** TTS / своя озвучка (нынешние `tts.py`, `align.py`), волна и слова на таймлайне.
- **Монтаж** — общий таймлайн ([architecture §3.8](architecture.md#38-монтаж-videojson--montage)): сцены + переходы, голос + субтитры, звуки + музыка (приглушение под голос), 2D-накладки, метки.
  Маркеры сцены перетаскиваются к словам — сцена растягивается кусочно-линейно; предпросмотр живьём (как ревью, с кнопкой «🎞 видео / ⚙ живой»).
- **Сборка из приложения:** `montage → src/scenes.js + audio` (генератор), затем `build.sh` в фоне с прогрессом; результат — во вкладке Ревью.
- **Готово, когда:** ностальгический ролик собран из одной сцены «Комната» с тремя планами камеры, голосом, субтитрами, звуками, и маркер «чешет затылок» прилип к слову.

## S7. Агент

- Панель агента с живым логом шагов, сообщением посреди работы и прерыванием (Agent SDK / stream-json — [architecture §6](architecture.md#6-агент)).
- Инструменты агента = команды студии; валидатор `authored`; блокировка сцены на время работы.
- Комментарии на объектах и ключах (`do` / `note`), лента пометок.
- **«✨ Собрать»:** агент проходит то, что сейчас делает Claude Code в чате по `CLAUDE.md` (шаги A–E): сценарий → голос → монтаж → сборка → проверка кадров → ревью; автор вмешивается в любой момент.
- **Готово, когда:** «поставь вокруг стола три стула и сделай наезд на ёжика за 2 секунды» выполняется у автора на глазах, с логом, прерывается и отменяется;
  «✨ Собрать» доводит видео из препродакшена до mp4 в ревью.

## S8. Ревью и упаковка

- Ревью внутри приложения (нынешний `review.html`: видео, пины, звуки, правки) + **пометки-действия**: в кадре ревью подвинуть персонажа или объект / поменять позу, подписать «почему» →
  пометка для Claude; при пересборке Claude переносит это в сцену (как `authored`) и больше не трогает.
- **Упаковка** (в конце): обложки (нынешний «🎨 Отрисовать» + THUMBNAILS), названия (финалисты из этапа «Название»), описания, хэштеги, «Права» (собирается из лицензий библиотеки и ассетов).
- **Готово, когда:** пометка «ёжик застрял в стене» с перетаскиванием ёжика исправлена Claude при пересборке; упаковка выдаёт обложку и `packaging.md`.

## S9. Новый канал

- «+ Канал»: подробное интервью Claude по стилю (визуал и герой, подача и голос, монтаж и звук, упаковка) → `style/style-guide.md`, палитра, шрифты, голос, субтитры, правила (`paperFacing`…),
  стартовый тулкит (копия бумажного или новый), главный герой в библиотеку (через S4).
- ⚙ Стиль в настройках проекта: правка всех этих файлов из приложения; изменения — операциями с историей.
- **Готово, когда:** создан тестовый канал «WoW» с троллем: интервью пройдено, стиль сохранён, тролль со своим скелетом стоит в пустой сцене.

## Общие риски

- **Размер переделки.** Держать старый путь рабочим до конца S2; переезд — только скриптом с сухим прогоном и журналом.
- **Конвертация старых сцен** — самое хрупкое место S1: код Claude бывает сплошным. Правило: конвертер делает префабы и `scene.json`, рендерит кадры до и после и сравнивает (разница пикселей), при большой разнице — показать автору.
- **Производительность редактора** на больших сценах (склон — 800+ объектов): дерево — виртуальный список, автогруппы сохраняются, рендер по требованию.
- **Агент в приложении** зависит от возможностей установленного Claude Code (потоковый ввод) — проверить в начале S7, запасной путь — «задача + отмена», как сейчас.
- **Лицензии** в библиотеке: у каждого ассета `license.json`; без лицензии в библиотеку не публикуется.
