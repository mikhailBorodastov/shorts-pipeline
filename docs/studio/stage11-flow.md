# S11. Новый порядок производства: сценарий → препродакшен (почти финал) → голос → монтаж

Решение автора (2 окт 2026): сцены собирались «вслепую», без текста, а монтаж не знал, подо что их подгонять. Теперь — классический порядок анимации:
**сценарий → сцены и звуки, близкие к финалу → запись голоса → монтаж, который собирает финал и где его доводят правками.**

## Этапы видео

| было | стало |
|---|---|
| Идея → Вопросы → Название → **Препродакшен → Сцены → Сценарий** → Голос → Монтаж → **Ревью** → Упаковка | Идея → Вопросы → Название → **Сценарий → Препродакшен** → Голос → **Монтаж (с ревью)** → Упаковка |

- **Сценарий** (после названия): текст и порядок сцен; черновой голос нейросетью — чтобы знать длительности. Проект ролика заводится здесь («🚀 Начать производство»);
  «✨ Написать сценарий» / «✍️ Исправить по правкам» — агент в режиме `script` (S7).
- **Препродакшен** — уже по сценарию: «✨ Накидать по сценарию» — **каждой сцене сценария — сцена препродакшена** (связь `e.script = {sec, title}`, длина — по голосу),
  персонажи, пропсы и звуки — из «Картинки» и текста. Сцены можно добавлять, править, склеивать и разбивать руками. 3D-сцена после рисунка сразу в редакторе
  (см. stage1-editor §5), «🎬 Для финала» — задачи агенту в сцене (preproduction.md). Сцены здесь — **почти готовые**.
- **Вкладка «Сцены» убрана**: редактор открывается из карточки сцены (🎬 Оформить сцену), версии и клип — там же.
- **Голос**: сюда кладут готовую запись (Дима): один файл или по сценам → Claude режет по сценам, сверяет слова (faster-whisper), правит строки VO под сказанное.
  Нет записи — работает черновой голос (tts.py); запись пришла — монтаж перестраивается под новые длины.
- **Монтаж = сборка + ревью** (вкладка «Ревью» слита сюда): «✨ Смонтировать» — Claude собирает финал из сценария с голосом, сцен препродакшена и звуков:
  сцены растягивает / ускоряет под голос (`map`, маркеры к словам), звуки — к моментам, музыка. Предпросмотр, готовое видео, правки пинами («✋ поправить кадр»),
  «🔨 Пересобрать с правками». **Двойной клик по сцене** на таймлайне — редактор сцены в этом моменте; закрыл — **пересборка сама** (без Claude, секунды: `montage gen` —
  маркеры держатся слов, лишнее подрезается, звуки едут за моментами). Claude — только если сцена сильно поменяла длину («✨ подогнать заново») или по правкам.
- **Новые предметы из редактора**: то, что агент сделал в сцене и чего не было (новый пропс), сразу появляется элементом препродакшена; в библиотеку — по ✓ (одна кнопка).

## Части (по одной, после каждой — «принято»)
1. Порядок этапов, вкладка «Сцены» убрана, «Сценарий» до препродакшена, «✨ Накидать по сценарию» (сцены 1:1 с разделами, пропсы и персонажи из «Картинки»).
2. Голос: загрузка записи → нарезка и сверка (align), черновой голос кнопкой.
3. Монтаж: «✨ Смонтировать» (агент, режим `montage`), ревью внутри, двойной клик → редактор, автопересборка после правки сцены.
4. Предметы, созданные в редакторе → элементы препродакшена (+ «📚 в библиотеку» по ✓).

## Как сделано
**Часть 1 (2 окт 2026).** Порядок вкладок — `web/ref.json → flows.idea` (идея, вопросы, название, сценарий, препродакшен, голос, монтаж, ревью — до части 3, упаковка),
`STAGES` в `ideas_api.py` и `pages.js`; `#/p/<id>/scenes` ведёт в препродакшен (`Plan.view`). В препродакшене: без сценария — плашка «📝 Сначала сценарий» (`Plan.scriptState`
→ `/api/script/state`), со сценарием — «✨ Накидать по сценарию»: `ideas_claude.script_of(plan)` (script.md проекта, не заглушка шаблона) уходит в промпт `elements`,
сцены — по одной на раздел сценария, в ответе `sec` → `elements[].script = {title}` (в карточке — «📝 …», в «Где в ролике» — «сцена сценария «…»»).

**Часть 2 (2 окт 2026) — 🎙 Голос** (`server/voice_api.py`, страница — `Plan.voice` в `web/studio.js`):
- **Запись диктора**: перетащить файл (или 📎) → `POST /api/voice/upload` (сырые байты, до 600 МБ) → `refs/voice/<время>-<имя>` → задача `voicesplit`:
  faster-whisper `small` на процессоре (слова со временем, подсказка — текст сценария) → `difflib` сопоставляет слова записи со словами сцен (разбор script.md —
  `tts.parse_script` проекта) → граница сцены — самая тихая точка (RMS 20 мс) в паузе между последним словом сцены и первым словом следующей →
  `build/vo/sec<N>.wav` (моно, края без тишины `silenceremove`) → `align.py` (тайминги слов, `src/vo_timing.js`). Прошлый голос нейросети — в `build/vo_tts/`.
  `build/vo/source.json` = `{kind: rec, file, cuts, diff}` — расхождения «в сценарии / сказал» без мелочей (знаки, апострофы).
  Не нашлась сцена (диктор пропустил) — ошибка с её названием. Проверено: 7 сцен «Невозможных игр» склеены в один дубль с паузами и разрезаны обратно — границы в паузах.
- **Черновой голос**: «🔊 черновой голос» → задача `voicetts` (tts.py; запись диктора уезжает в `build/vo_rec/`, `source.kind = tts`). `montage tts` не затирает запись диктора.
- Страница: откуда голос (🎤 запись / 🤖 нейросеть), зона загрузки, записи (послушать, «✂ нарезать по сценам»), расхождения + «✨ Поправить сценарий под запись»
  (агент правит VO под сказанное, потом `voice align`), сцены с плеерами (`GET /api/voice/audio?video=&i=` / `&rec=`, с Range) и длинами, «Дальше → 🎞 Монтаж».
- CLI: `voice show|split|tts|align VID`.

**Часть 3 (2 окт 2026) — 🎞 Монтаж = сборка + ревью** (`web/montage.js`, `server/montage_api.py`, режим агента `montage`):
- Вкладка «Ревью» убрана из пути (`#/p/<id>/review` → монтаж). На монтаже: «✋ поправить кадр» (кадр — курсор предпросмотра, `ReviewFix.grab`), «🔨 Пересобрать с правками»,
  «🎬 Готовый ролик» — плеер `out/*.mp4` (`GET /api/montage/video`, с Range).
- **⚡ Разложить по сценарию** (`POST /api/montage/auto`, CLI `montage auto VID [--save]`, `auto_layout`) — без Claude: секции голоса (сцены сценария, `vo_timing` с `title`)
  ← сцены редактора по `elements[].script.titles` («📝 Сцены сценария» в карточке сцены — чипы секций, можно несколько подряд: одна сцена на несколько битов — один юнит),
  без связи — по порядку. Юнит стоит там, где звучит его секция, длится до следующей; сцена растягивается / ускоряется под него (`map [[0,0],[длина сцены, длина юнита]]`),
  если ускорение больше ×1.45 — играет как есть, хвост обрезан (в отчёте). Звуки, музыка, надписи сохраняются. Ролик без диктора — «⏱ разметить тайминги» на «Голосе» (tts.py
  размечает тихие биты по таймкодам сценария).
- **✨ Смонтировать** — агент (Opus, режим `montage`): каркас `montage auto --save` → маркеры и склейки к словам (`map` с `w:i`), скорость ×0.7–1.45, переходы по смыслу,
  sfx из звуков препродакшена и библиотеки к моментам из «*(Звук: …)*» сценария и действиям, музыка → `montage gen` → `snap` → `build`. Пожелания автора — в окне перед запуском.
  `montage brief` печатает секции голоса и «📝 сцена сценария» у сцен.
- **Двойной клик по сцене** на таймлайне → `/api/montage/at` → `StageEditor.openScene(vid, el, ts)` — обычная правка сцены в этом моменте (`editor.html?…&t=&back=montage`);
  закрыл → `Montage.afterEdit`: свежие длины сцен, у юнитов с простым растяжением новая длина подставляется в `map` (сцена снова точно под голосом), предпросмотр пересобирается
  (`montage gen`, без Claude, секунды); mp4 — «🔨 Собрать». Проверено на «Проверке монтажа»: двойной клик открыл сцену в 1.98 с, длина 4 → 5 с подставилась в карту, предпросмотр обновился.

**Часть 4 (2 окт 2026) — новые предметы из редактора → препродакшен** (`scene_api.adopt`, вызывается из `apply` после каждой пачки, кроме отмены и возврата версии):
- объект с `src.prefab` = `el:<id>` — связь (`src.el`, состав сцены `uses`); `lib:<props|characters>/…` — тот же элемент, если он уже взят из библиотеки, иначе импорт
  (`import_to_video`, утверждён ✓); свой префаб сцены (не env / overlay) — новый пропс `by: scene`, `from: {scene, obj, prefab}`, «💡 предложен»
  (совпало имя с существующим персонажем / пропсом — связь с ним). Связь пишется служебной пачкой `by: studio` (не «правил руками»).
- Карточка такого пропса: «🎬 Сделан в сцене «…» — живёт в её коде», «открыть сцену», **«📦 Сделать отдельным ассетом»** — задача `element` с `extract`
  (`element_spec`: Claude переносит префаб из prefabs.js сцены в самостоятельный `prop3d` prefab.js — без глобальных имён, начало координат в центре низа — и снимает 4 ракурса
  `render_prop.js`) → обычная 3D-версия (`three3`). В библиотеку — как всегда: ✓ → «📚 в библиотеку».
- Проверено на «Проверке монтажа»: ковёр со своим префабом стал пропсом «сделан в сцене», лампа из библиотеки — импортирована и связана; тест отменён. «📦 Сделать отдельным ассетом»
  (прогон Opus) живьём не запускали.
- Агенту: правило в `SCENE_RULES` (давать новым объектам понятные имена).

**Звук в предпросмотре монтажа (2 окт 2026) — живое сведение.** Предпросмотр играл только кадры. Первая версия пересводила файл (`build.sh audio`) после
каждой правки — звук отставал на 5–10 с. Теперь страница сводит сама (`MTA` в `web/montage.js`, Web Audio): `GET /api/montage/audiomap` даёт адреса
источников (слои `el:` звуков препродакшена, `lib:sounds/…` канала, `lib:<id>` пайплайна с пиком из index.json, `file:` сцены — `/rscene/…/work/`, монтажа и голоса —
`GET /api/montage/file`), звуки сцен во времени сцены и голос по секциям; по текущему монтажу строятся реплики (сцены — через карту юнита `pairs` / `s2v`), правила как в audio.py:
`align: peak`, библиотека — к пику 0.9, срезы `|с|длина`, затухание звука после пика, у музыки from / dur / fadeIn / fadeOut. Буферы декодируются заранее (`warm` при открытии
и после правки), ▶ / перемотка / любая правка монтажа (`save`) перестраивают звук сразу, расхождение с кадрами > 0,3 с — перезапуск с кадра. Проверено на «Ностальгии»: 13 реплик,
▶ со звуком через 0,3 с (первый раз, с декодом), добавленный звук слышен сразу после правки. Готовый mp4 сводит `build.sh` как раньше.
