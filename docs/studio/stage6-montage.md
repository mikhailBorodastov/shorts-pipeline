# S6. Сценарий, голос, монтаж, сборка — ТЗ реализации

Цель ([roadmap](roadmap.md#s6-сценарий-голос-монтаж), формат монтажа — [architecture §3.8](architecture.md#38-монтаж-videojson--montage)): ролик собирается **в приложении** —
общий таймлайн из сцен редактора, голоса и субтитров, звуков и музыки, надписей; кнопка «🔨 Собрать» делает mp4, результат — во вкладке «Ревью».
Сейчас это делает Claude руками (`scenes.js`, `WT()`, `sfx(add)`): монтаж генерирует те же файлы проекта, `build.sh` и рендер остаются.

**Готово, когда** (решения автора):
- **«Ностальгия»** собрана как задумано: ~15 с, **без голоса**, одна сцена — оригинальная «Комната» с **тремя планами камеры**, POV-надпись, тёплый эмбиент → тема San Andreas, звуки комнаты;
- **голос, субтитры и «маркер к слову»** — на коротком тестовом видео «Проверка монтажа» (копия «Комнаты» с анимациями, 2–3 фразы): маркер сцены прилип к слову, сцена растянулась кусочно-линейно.

## 1. Данные — `video.json → montage`

```json
{ "units":   [{ "id": "u1", "scene": "<элемент-сцена>", "at": 0, "len": 12, "from": 0, "map": [[0, 0], [3.2, "w:12"], [10, 12]], "trans": { "type": "cut", "dur": 0 } }],
  "voice":   { "on": true },                                  // голос проекта: build/vo/*.wav + src/vo_timing.js (tts.py / align.py)
  "captions":{ "on": true },
  "sfx":     [{ "id": "x1", "at": 1.2, "src": "lib:<id> | el:<звук препродакшена> | file:<путь>", "gain": 0.8, "align": "peak" }],
  "music":   [{ "id": "mu1", "at": 0, "src": "file:…", "gain": 0.6, "from": 0, "dur": 8, "fadeIn": 1, "fadeOut": 2, "duck": true }],
  "overlays":[{ "id": "ov1", "at": 0, "dur": 4, "kind": "pov", "text": "POV: …" }],
  "len": 15 }
```
- `map` — пары `[время сцены, время ролика | "w:<индекс слова>"]`, между ними — линейно (время ролика отсчитывается от `at` юнита). Маркер сцены, притянутый к слову, — пара `[t маркера, "w:i"]`.
- Звуки сцены (`scene.sounds`) идут в ролик сами, по карте времени; `sfx` / `music` — поверх.

## 2. Генератор — `server/montage_api.py` (`montage → project`)

- Копирует в проект всё, что нужно сценам: `assets/studio/scenes/<el>/` (scene.json, prefabs.js), библиотеку (`assets/studio/lib/<kind>/<slug>/v<N>/…`, `emotions.json`), клипы (`assets/studio/anims/…`),
  черновики `el:` (`assets/studio/el/<el>/v<N>/…`), звуки (`assets/studio/sfx/…`, `assets/studio/music/…`).
- Пишет `src/montage.js` (данные + `SCENE_URLS` для движка), `src/scenes.js` (СГЕНЕРИРОВАН: юнит → сцена с `draw` через `sceneWorld`, карта времени, звуки), вставляет в `src/index.html`
  движок сцен (`paper.js, props3d.js, rig.js, scene.js`, prefabs.js сцены), без голоса — `src/vo_timing.js` на длину ролика, `build/music.json` для `audio.py`.
- Шаблон: `main.js` берёт границы сцен из `SCENE_B` (монтаж), если он есть; `audio.py` — музыку файлами из `build/music.json` (иначе — синтез, как было); `scene.js` — адреса из `SCENE_URLS`.
- ~~Ограничение: одна `prefabs.js` на проект~~ — снято: генератор кладёт `prefabs.js` каждой сцены в свою область видимости (`prefabs.scoped.js` → `window.SCENE_PREFABS[el] = {PREFABS, PICS}`),
  монтаж по умолчанию — все сцены редактора подряд; если монтаж длиннее голоса, ролик длиной в монтаж (`VO.total`, `build/vo_timing.json`). Проверено: «Комната» + пустая сцена с ёжиком в «Проверке монтажа».

### 2а. Как сделано (шаги 1–2)

- `server/montage_api.py`: `get` (монтаж или по умолчанию — первая сцена редактора подряд), `generate` (копии в `assets/studio/{scenes,lib,el,anims,env,sfx,files}`,
  `src/montage.js` — `MONTAGE`, `MONTAGE_SFX`, `STUDIO_SCENES`, `SCENE_URLS`, `SCENE_B`; `src/scenes.js` — СГЕНЕРИРОВАН; блок `<!-- studio -->` в `index.html` вместо `chars.js`;
  без голоса — «тихие» `src/vo_timing.js` и `build/vo_timing.json` на длину ролика; `build/music.json`), `build` (генератор + `bash build.sh`, прогресс «кадры N из M»).
  API: `GET /api/montage?video=`, `POST /api/montage/gen {video}`, `POST /api/montage/build {video}` → задача `montagebuild`. CLI: `studio.py montage show|gen|build <видео>`.
- Источники звука в `sfx` / `music`: `el:<звук препродакшена>` (все слои микса), `lib:sounds/<slug>@N` (библиотека канала), `file:<путь>` (от папки видео; у звуков сцены — от её `work/`), `lib:<id>|смещение|длина` (библиотека пайплайна — как есть).
- Шаблон: `main.js` ждёт `window.STUDIO_READY()` (грузит пропсы, персонажей, клипы и огибающие липсинка, строит миры `sceneWorld`) перед `stage3dInit`; `paper.js` берёт Caveat из `../assets/fonts/` в проекте.
- **«Ностальгия»** (`260930-08d8`): «Комната» 15 с, три плана (`cuts` 4.6 и 8.0: общий наезд → экран из-за головы ёжика → ёжик в свете монитора, отъезд);
  экран по времени — три экземпляра библиотечного ЭЛТ (`screen: xp | select | game`) с ключами `hide` (5.6, 6.6); музыка — тёплый пэд (Freesound, CC0) 0–7.4 с → тема SA с 6.65 с;
  звуки — гул системника и писк ЭЛТ (Freesound, CC0), часы, метель, двойной клик (библиотека пайплайна). POV-надпись — объект сцены (`povTitle`).

## 3. Приложение — этап «Монтаж»

- Таймлайн: **сцены** (полосы юнитов: сдвиг, длина краем, склейки камеры внутри), **маркеры сцен** (флажки по карте), **голос** (волна + слова), **музыка**, **звуки**, **надписи**.
  Маркер тянется на слово — пара карты `w:i`. Двойной клик — свойства (сцена, скорость, переход; громкость, срез; текст надписи).
- Предпросмотр — страница проекта (`src/index.html?preview=1`) в окне, после правки монтаж пересобирается (генератор, без рендера) и страница перезагружается на том же моменте.
- «🔨 Собрать» — задача `montagebuild`: генератор → `bash build.sh` (кадры, звук, mp4) с прогрессом → «Ревью».
- Нет проекта — «🚀 Начать производство» прямо на этапе (для видео без сценария — проект без голоса).

### 3а. Как сделано (шаги 3–4)

- `web/montage.js` — этап «🎞 Монтаж»: панель (▶, время, «+ сцена / музыка / звук / надпись», голос и субтитры галками, масштаб), таймлайн (линейка — перемотка;
  строки 🎬 сцены — полосы юнитов, пунктир — склейки камеры, ⚑ — маркеры сцены по карте; 🎙 голос — слова; 🎵 музыка, 🔊 звуки, 🔤 надписи — дорожками без наложений),
  свойства выбранного (сцена, длина, переход, точки карты с «×»; источник звука — звуки препродакшена или `lib:` с подсказками из библиотеки, громкость, срез, фейды, пик; текст надписи).
  Полоса: тянешь — сдвиг, край — длина (у юнита — длина и последняя точка карты). **Маркер ⚑ тянешь к слову** — прилипает в 14 px, зеленеет, в карту пишется `[t маркера, "w:i"]`;
  карта, где сцена пошла бы назад, не принимается. Правка → `set ['montage']` → через 0.7 с `POST /api/montage/gen` → предпросмотр перезагружается на том же моменте.
- Предпросмотр — `src/index.html?preview` проекта (`/api/studio/project {page: 'preview'}`) в своём окне поверх страницы (`MontagePreview`, держится над местом `.mt-prevslot`),
  поэтому перерисовка страницы его не перезагружает. Управление — `postMessage {seek}`, `{play}`; плеер отвечает `{studioT, playing}` (шаблон `main.js`, блок preview). Звука в предпросмотре нет — он в собранном ролике.
- «🔨 Собрать» — задача `montagebuild`, прогресс («кадры N из M», «кодирую mp4…») — в строке статуса; готово — «👀 Ревью →». Первый заход на этап в проект без монтажа сам генерирует файлы.
- Движок: `loadSceneProps` узнаёт префаб по пути от корня — в проекте ролика адрес относительный (`../assets/studio/…`), и персонажи библиотеки раньше не строились.
- Сервер: `_fresh` хранит отметку времени на модуле — после перезагрузки `ideas_api` вспомогательные модули больше не «залипают» (раньше надо было трогать файл).
- **«Проверка монтажа»** (`261001-e866`): копия «Комнаты — проверки анимаций (S5)» (`e8f625642`: клип «радуется» `hog/joy` у ёжика и жены-ёжихи на 5 с — `hog/wave` ёжик делал в сторону стола, лапу закрывал монитор; маркер «машет», POV скрыт), `script.md` — три фразы, `tts.py`;
  в монтаже край сцены дотянут до конца голоса (13.2 с), маркер «машет» — на слово «машет» (`[[0,0],[5,"w:9"],[10,13.2]]`): сцена до маркера почти в своём темпе, после — растянута.

## 4. Порядок работ

1. Шаблон и движок: `SCENE_URLS`, `SCENE_B`, музыка файлами, `ENGINE_FILES` (props3d, rig, paper).
2. Генератор + CLI `studio.py montage show|gen|build <видео>`; «Ностальгия»: проект, три плана в «Комнате», музыка (после «да» на ссылки), звуки, POV — mp4 из CLI.
3. Этап «Монтаж» в приложении (таймлайн, предпросмотр, «🔨 Собрать»).
4. Тестовое видео с голосом: сценарий 2–3 фразы, tts, маркер к слову, субтитры, mp4.

## 16:9 — длинные ролики (2026-10-01)

- Кадр — настройка проекта: `src/format.js` → `window.FRAME_SIZE = [1080, 1920]` (шортс) или `[1920, 1080]` (длинное видео). Пишут «🚀 Начать производство» (по `mode` видео) и монтаж (каждый `gen`); старые проекты получают его при генерации.
- `engine/lib.js`: `W`, `H`, `WIDE` из `FRAME_SIZE` (редактор и стенды — `?fmt=long`); `main.js` ставит холст W×H, субтитры 16:9 — ниже (0.86), мельче, до 6 слов; `render.js` (viewport, лист `snap`), `render_shot.js` (`fmt=long`) — по формату.
- Редактор сцены длинного видео — рамка камеры 16:9 (`viewport.js`: пропорция `W / H`). Проверено: «Комната» в проекте 16:9 — кадр 1920×1080, камера подстроилась.
