# S7. Агент — ТЗ реализации

Цель ([roadmap](roadmap.md#s7-агент), устройство — [architecture §6](architecture.md#6-агент)): Claude работает в приложении **на глазах у автора** —
живой лог шагов, сообщение посреди работы, остановка, отмена всего сделанного; комментарии на объектах; «✨ Собрать» доводит видео до mp4.

**Готово, когда** (решения автора: панель — **везде, справа**; «✨ Собрать» проверяем на **новом коротком тестовом видео** на «Комнате»):
- «поставь вокруг стола три стула и сделай наезд на ёжика за 2 секунды» выполняется у автора на глазах, с логом, прерывается и отменяется;
- «✨ Собрать» доводит видео из препродакшена до mp4 в ревью.

## 1. Как запускается

- `claude -p --input-format stream-json --output-format stream-json --verbose` (Claude Code 2.1.285, подписка автора). Проверено:
  события приходят по ходу (каждый вызов инструмента — сразу); сообщение посреди работы Claude подхватывает между командами (тот же ход);
  `control_request {subtype: interrupt}` обрывает идущую команду (ход кончается `error_during_execution`); следующая просьба — тот же разговор.
- Одна живая сессия на видео (`server/agent.py`, `SESS`), закрывается после 40 мин простоя или по «⟲ новый разговор». Смена модели (Sonnet / Opus) или режима (чат / сборка) — новая сессия.
- cwd — папка видео; `--add-dir` — `_studio` и канал. Системный промпт — канал (`ideas_claude.system`) + команды студии + правила + `SCENE_RULES`; для сборки — шаги «✨ Собрать».

## 2. Инструменты = команды студии

- Bash разрешён **только** для `python <_studio>/server/studio.py …` и стендов: `python stands/blender_run.py <model.py>`, `node stands/render_prop.js | render_char.js …`;
  Read / Grep / Glob — чтение (папки — Glob, не `ls`/`cd`: составные команды блокируются); Write / Edit — всегда, но по правилам промпта только: в папке версии,
  созданной `lib fork` в этом разговоре, в `prefabs.js` открытой сцены (если автор просит поменять сам предмет), в проекте ролика при «✨ Собрать».
  Код Studio, старые версии библиотеки, чужие видео и каналы — не трогает. `RULES_REV` в `agent.py`: поменялись права — старая сессия перезапускается сама.
- **Правка библиотеки** (после «да» автора или его прямой просьбы) — только новой версией: `lib fork KIND/SLUG@N [--as "Имя"] --note …` (копия vN → vN+1 или новый предмет;
  у персонажа-копии переписываются `id` и имя в prefab.js) → правка файлов → `lib preview KIND/SLUG@N` (кадры на стенде → preview.png) → `scene ops`: `src.prefab` = новая ссылка.
  Старые версии держат другие видео и не меняются; отмена в сцене — `scene undo`. `model info <glb>` — узлы модели (имена, габариты), чтобы делить её по частям.
  Файлы — только Edit / Write (скрипты Python / node, кроме стендов, блокируются); заблокировало — агент не просит разрешения, а делает то же доступными инструментами.
  Разделить предмет из prefabs.js: новые префабы на прежнем месте + объекты в сцене с копией ключей (проверено: «отдели клавиатуру, мышь и выдвижную полку» → kbShelf / kbKeys / kbMouse).
- Открытый редактор подхватывает правки агента без перезахода: новые `lib:` / `el:` догружаются перед сборкой объектов, поменялся `prefabs.js` (`prefabsRev` в `/api/scene` и `/rev`) —
  редактор перезагружается сам с тем же моментом, выделением и историей отмены.
  Проверено: «раздели Системный блок и принтер» → `props/sistemnyi-blok@1` + `props/printer@1`, два объекта в сцене, `@2` старого пропса не тронут.
- Новые команды для агента: `scene brief PLAN EL` (сцена целиком: объекты, свет, камера, префабы, authored, комментарии, последние правки),
  `scene frame PLAN EL t[,t2]` (кадр стенда → PNG, смотреть через Read), `montage brief` (монтаж, сцены с маркерами, **слова голоса с номерами**, звуки препродакшена),
  `montage tts | check | snap` (голос, проверка сценария, кадры ролика в папке проекта).
- Всё, что меняет сцену или видео, идёт через CLI — в историю и с отменой; authored защищён как раньше (`--allow` — только по прямой просьбе).

## 3. Запуск и отмена

- **Запуск** = просьба автора и всё, что агент сделал до конца ответа (дописки посреди работы — в тот же запуск; если ход кончился, а дописка уже ушла — Claude начинает новый ход сразу, сервер ждёт 2.5 с и не закрывает запуск).
- CLI знает текущий запуск: сессия запущена с `STUDIO_AGENT=<видео>`, сервер пишет id запуска в `.studio/agent/<видео>.run`.
  Пачки сцены получают `run` в `history.jsonl`; `set` / `op` видео — обратные операции в `.studio/agent/runs/<run>.jsonl`.
- **«↺ отменить (N)»** у записи «готово» — `POST /api/agent/undo {video, run}`: пачки сцен в обратном порядке (как Ctrl+Z, через `kind: undo`), правки видео — обратными операциями.
- Пока агент работает, сцена, открытая у автора, заблокирована (`scene_api.LOCKS[…] = "agent:<видео>"`): редактор только смотрит, «✕» на плашке останавливает агента.

## 4. Панель — `web/agent.js`

- Справа на всех страницах видео и поверх редактора сцены (редактор и страница сдвигаются); кнопка 💬 внизу справа, `/` — открыть.
- Лента: ты (с контекстом), Claude (ответы), шаги (✓ / … / ⚠, клик — команда и результат), «готово · время · $ · ↺ отменить (N)», заметки («■ остановлено», «↺ отменено»).
- Поле ввода всегда активно: в работе — «Дописать ↵» и «■ стоп». Модель — Sonnet / Opus, «⟲» — новый разговор.
- **Контекст** каждой просьбы: этап; в редакторе — сцена, момент курсора, выбранное (`window.agentCtx()` редактора); на монтаже — момент.
- API: `GET /api/agent?video=&since=` (записи после номера, `busy`), `POST /api/agent/say {video, text, ctx, model, mode}`, `/stop`, `/undo {run}`, `/reset`. Лог — `<видео>/agent.jsonl`.

## 5. Комментарии на объектах

- В редакторе: **правый щелчок без протяжки** по предмету (протяжка — по-прежнему камера) или Ctrl+/ — «💬 …»: «✨ Сделать сейчас» (просьба уходит в панель с объектом и моментом)
  или «📌 Пометка» (`scene.comments[] = {id, target, t, text, by, status: open, mode: note}` — операцией, в историю).
- На ключах: правый клик по ключу на таймлайне → «💬 Claude про это…» — то же окно, курсор встаёт на момент ключа, цель — объект ключа (или камера).
- Открытые пометки сцены — в панели («📌 пометки сцены», ✨ — отдать агенту), в `scene brief` и при «✨ Собрать».

## 6. «✨ Собрать»

- Кнопка на этапе «Монтаж» и в пустой панели: сессия Opus в режиме `build` — шаги CLAUDE.md (0 и A) без викторины: сценарий (`script.md` в формате сценариста, гайд, `montage check`) →
  `montage tts` → монтаж (`set plan:<id> montage …`, маркеры сцен к словам) → `montage gen` → `montage snap` и правки → `montage build` → ответ, что смотреть в «Ревью».

## 7. Как сделано / проверено

- Контрольная просьба на «Комнате — проверка монтажа» (`261001-e866/e8f625642`), Sonnet, 66 с, $0.21: агент прочитал сцену, снял кадры, поставил три кресла (стульев-префабов нет — взял офисные),
  сделал наезд к 2 с, по кадру увидел, что кресло закрывает ёжика, сдвинул камеру. «↺ отменить (3)» вернул сцену. Дописка посреди работы («и ещё ключ на 3 с») — в тот же ход;
  «■ стоп» оборвал облёт камеры на середине (1 пачка, отменена).
- **«✨ Собрать»** на «Проверке сборки» (`261001-2feb`, две копии «Комнаты»: «утро» с маркером «садится», «у окна» — жена с клипом «радуется»), Opus, ~4 мин, $0.84:
  завёл проект, посмотрел кадры сцен, написал `script.md` («Первый снег», 5 фраз), прогнал проверку по гайду (оставшиеся ❌ — длина: гайд рассчитан на 60 с),
  озвучил, собрал монтаж (маркеры к словам), снял кадры ролика, увидел, что ёжик загораживает жену во второй сцене — спрятал его там до 2.6 с (пачка сцены), собрал mp4 21.9 с.
  Попытку переписать файл скриптом python сессия запретила (разрешены только команды студии) — агент переписал через Write.
