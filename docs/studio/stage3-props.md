# S3. Препродакшен 2D / 3D: 3D-пропсы — ТЗ реализации

Цель ([roadmap](roadmap.md#s3-препродакшен-2d--3d)): у пропса выбор 2D / 3D; 3D-пропс Claude делает фигурами кодом, из бесплатной модели 📦 или через Blender;
автор крутит его в карточке, ставит **пины прямо на модель**, утверждает; утверждённый — в библиотеку и в сцену редактора вместо карточки.
**Готово, когда:** в «Комнате» (видео «Ностальгия») ЭЛТ-монитор и системный блок — 3D-пропсы, поправлены пином «добавь кнопки на корпус», стоят в сцене вместо карточек.

Персонажи в S3 остаются 2D-карточками: объём и скелет персонажа — S4.

## 1. Модель данных

- Элемент `prop` (и `char` — поле есть, но 3D включится в S4): `dim: '2d' | '3d'`. Нет поля — `2d` (все старые элементы).
  Новый пропс получает `dim` из канала: `channel.json → defaults.dim` (у «Доедать будешь» — `3d`, т. к. `engine: 3d`).
- `how: 'auto' | 'shapes' | 'model' | 'blender'` — способ для 3D (по умолчанию `auto`: Claude выбирает сам по сложности). `blender` доступен, если Blender найден (§5).
- Версия 3D-черновика `renders[]`: `{ id, v, dir, img, three3: true, how, h, shots: [4 ракурса], feedback }`; `img` — лист 2×2 из четырёх ракурсов.
- Пины в 3D: `fx.main.pins3d = [{ id, p: [x, y, z], n: [nx, ny, nz], text }]` — точка на поверхности модели в координатах пропса (метры, 0 — центр низа).
  «В целом» — как у 2D (`fx.main.notes[]`). Отправленные пины снимаются, текст — в `renders[].feedback`.
- Стиль 3D канала: `channel.json → style3d: 'paper' | 'toy'` — выбирает автор на примере ЭЛТ-монитора (первый шаг S3). Влияет на материалы `props3d.js`.

## 2. Формат 3D-пропса — `prefab.js`

Файл версии `<видео>/preprod/<el>/vN/prefab.js` (в документе `render/<id>/<el>/vN`), рядом `model.glb` (если есть), `model.py` (если Blender), кадры.
```js
prop3d({
  name: 'ЭЛТ-монитор', h: 0.45,                         // реальная высота, м; 0 — центр низа, перед — к +z
  models: { m1: 'model.glb' },                          // glb рядом с файлом (Blender) или из 📦 ассетов ('/files/<plan>/assets/<id>/model.glb')
  params: { screen: 'xp', glow: '#7cc4ff' },            // то, что автор сможет менять в сцене (P_(o, 'screen', 'xp'))
  build(w, o) { const G = new THREE.Group(); … return G; },   // или kind: 'model' + model: 'm1' + detail(w, o, G)
  tick(T, o, holder) { … },                              // анимация (экран мерцает, лампочка горит) — чистая функция времени
});
```
`prop3d()` регистрирует префаб в `PROPS3D[<url файла>]` (относительные `models` становятся абсолютными). Это тот же префаб, что в `prefabs.js` сцены (`kind: 'group'` / `'model'`),
поэтому редактор ставит его в сцену без переделки.

## 3. Движок — `engine/props3d.js`

- Материалы по стилю канала: `pmat(color, o)` — `paper`: матовый, зерно бумаги и крафта, лёгкий разброс цвета, тёмная кромка на сгибах (`edges`);
  `toy`: гладкий, мягкий блик, скруглённые края. `PROP_STYLE` задаётся каналом.
- Фигуры: `rbox(w, h, d, r)` (скруглённый ящик), `cyl`, `extrude(точки, глубина, фаска)`, `lathe` (тела вращения), `sticker(w, h, draw)` — плоская наклейка
  с белой кромкой (кнопки, логотипы, экран, надписи рисуются 2D-кодом тулкита), `screen(w, h, draw, dynamic)` — светящийся экран, `edges(mesh)` — линии сгибов.
- Подключается в стенд, в редактор и (S6) в шаблон ролика рядом со `stage3d.js`.

## 4. Стенд и осмотр

- `stand3d.html?prop=<url prefab.js>` — поворотный стол: бумажный фон-циклорама, мягкий свет с тенью, ёжик-карточка для масштаба (`&hog=1`).
  Время = угол: за `len = 8` с полный оборот; кадры `render_shot.js … 1,3,5,7` — четыре ракурса (¾ спереди, сбоку, ¾ сзади, другой бок), лист 2×2 — `element.png`.
- `&view=1` — живой просмотр в карточке (окно поверх страницы): крутить мышью, колесо — ближе; кнопка «📍 Пин» — клик по поверхности ставит пин (raycast),
  пин — номер в кружке на модели, текст — в списке справа; «💾 Сохранить пины» пишет `fx.main.pins3d` операцией.
- `&pins=<json>` — нарисовать пины номерами в кадре (скрытые за моделью — полым кружком). Для правки сервер снимает прошлую версию с пинами с четырёх ракурсов
  (`pins_1.png…pins_4.png`) — Claude смотрит их через Read и получает координаты текстом.

## 5. Blender

- Портативный Blender 5.2 LTS — `_studio/tools/blender/` (в git не идёт). Путь ищется: `.studio/settings.json → blender`, `_studio/tools/blender/*/blender.exe`, PATH, Program Files.
- `stands/blender_run.py model.py` — запускает Blender в фоне (`-b --factory-startup --python model.py`), пишет `model.glb` рядом и лог; Claude вызывает только его.
- `model.py` — скрипт `bpy`: меши, модификаторы (фаска, булевы, сглаживание), материалы-цвета; экспорт делает обёртка. Детали-наклейки (кнопки, логотип) — кодом в `prefab.js` поверх модели.

## 6. Кнопки ✨ (Claude)

- «🎨 Нарисовать черновик» у 3D-пропса — задача `element` с контрактом §2: Claude читает `props3d.js`, референсы (и 2D-черновик, если пропс был 2D), пишет `prefab.js`
  (и `model.py` → `blender_run.py`), снимает четыре ракурса, смотрит, правит 2–4 прохода. Модель Opus (визуальная).
- «Поправить» от версии: пины 3D + «в целом» → vN+1 от прошлого кода (`prefab.js`, `model.py`, `model.glb` копируются).
- «🧊 Сделать в 3D» у утверждённого 2D-пропса: `dim → 3d`, 2D-черновик идёт референсом.

## 7. Библиотека и сцена

- Публикация 3D-пропса: в `library/props/<slug>/vN/` — `prefab.js`, `model.glb`, `model.py`, `preview.png` (лист), `license.json`; в `prop.json` — `dim: '3d'`, `h`.
- В сцене редактора объект ссылается на пропс: `src.prefab = 'lib:props/<slug>@N'` (библиотека) или `'el:<element>@vN'` (черновик этого видео).
  Стенд и редактор грузят такие `prefab.js` до сборки (`/rlib/<plan>/props/<slug>/vN/prefab.js`, `/rscene/<plan>/<el>/vN/prefab.js`) и кладут в `S.lib`.
- «↔ Заменить на…» в свойствах объекта: выбрать пропс из библиотеки или препродакшена — операция `set objects[id].src.prefab`, положение и ключи сохраняются.
  Высота: 3D-пропс строится в реальных метрах, масштаб объекта не трогается.
- Сборка ролика со ссылками `lib:` / `el:` — S6 (проект получит копии `prefab.js` / `model.glb` в `src/props/`).

## 8. Порядок работ

1. `props3d.js` + стенд `?prop=` + ЭЛТ-монитор руками в двух стилях → автор выбирает `style3d`.
2. Данные (`dim`, `how`), карточка элемента (переключатель 2D / 3D, способ, лист ракурсов, «🧊 Покрутить», пины 3D), Blender (`blender_run.py`, поиск).
3. `element_spec` для 3D-пропса, правка по пинам, «🧊 Сделать в 3D».
4. Библиотека 3D-пропсов, `lib:` / `el:` в движке сцены, «↔ Заменить на…» в редакторе.
5. Приёмка на «Комнате»: ЭЛТ и системник через Claude (один — фигурами, другой — Blender), пин «добавь кнопки на корпус», в библиотеку, замена в сцене, клип.
