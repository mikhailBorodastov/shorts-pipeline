# S3. Препродакшен 2D / 3D: 3D-пропсы — ТЗ реализации

Цель ([roadmap](roadmap.md#s3-препродакшен-2d--3d)): у пропса выбор 2D / 3D; 3D-пропс Claude делает фигурами кодом, из бесплатной модели 📦 или через Blender;
автор крутит его в карточке, ставит **пины прямо на модель**, утверждает; утверждённый — в библиотеку и в сцену редактора вместо карточки.
**Готово, когда:** в «Комнате» (видео «Ностальгия») ЭЛТ-монитор и системный блок — 3D-пропсы, поправлены пином «добавь кнопки на корпус», стоят в сцене вместо карточек.

Персонажи в S3 остаются 2D-карточками: объём и скелет персонажа — S4.

## 1. Модель данных

- Элемент `prop` (и `char` — поле есть, но 3D включится в S4): `dim: '2d' | '3d'`. Нет поля — `2d` (все старые элементы).
  Новый пропс получает `dim` из канала: `channel.json → defaults.dim` (у «Доедать будешь» — `3d`, т. к. `engine: 3d`).
- `how: 'auto' | 'shapes' | 'model' | 'blender'` — способ для 3D (по умолчанию `auto`: Claude выбирает сам по сложности). `blender` доступен, если Blender найден (§5).
- Версия 3D-черновика `renders[]`: `{ id, v, dir, img, extra, three3: true, how, summary, note, feedback, fx }`; `img` — лист 2×2 из четырёх ракурсов, `extra` — ракурсы крупно,
  `how` — способ, который Claude выбрал (shapes / model / blender). У пропса 2D и 3D-версии лежат рядом: карточка и библиотека берут те, что выбраны переключателем `dim`.
- Пины в 3D: `fx.main.pins3d = [{ id, p: [x, y, z], n: [nx, ny, nz], text }]` — точка на поверхности модели в координатах пропса (метры, 0 — центр низа), `n` — нормаль грани.
  «В целом» — как у 2D (`fx.main.notes[]`). Отправленные пины снимаются, текст — в `renders[].feedback`.
- Стиль 3D канала: `channel.json → style3d: 'paper' | 'toy'` — выбирает автор на примере ЭЛТ-монитора (первый шаг S3). Влияет на материалы `props3d.js`.

## 2. Формат 3D-пропса — `prefab.js`

Файл версии `<видео>/preprod/<el>/vN/prefab.js` (в документе `render/<id>/<el>/vN`), рядом `model.glb` (если есть), `model.py` (если Blender), кадры.
```js
prop3d({
  name: 'ЭЛТ-монитор', h: 0.45,                         // реальная высота, м; 0 — центр низа, перед — к +z
  models: { m1: 'model.glb' },                          // glb рядом с файлом (Blender) или из 📦 ассетов ('/files/<plan>/assets/<id>/model.glb')
  params: { screen: 'xp', glow: '#7cc4ff' },            // то, что автор сможет менять в сцене (P_(o, 'screen', 'xp'))
  build(w, o) { const G = new THREE.Group(); … return G; },   // или kind: 'model' + model: 'm1' + detail(w, o, G)
  tick(T, o, holder) { … },                              // анимация (экран мерцает, лампочка горит) — чистая функция времени
});
```
`prop3d()` регистрирует префаб в `PROPS3D[<url файла>]` (относительные `models` становятся абсолютными). Это тот же префаб, что в `prefabs.js` сцены (`kind: 'group'` / `'model'`),
поэтому редактор ставит его в сцену без переделки.

## 3. Движок — `engine/props3d.js`

- Материалы по стилю канала: `P3.mat(color, o)` — `paper`: матовый, светлое зерно бумаги (карта и рельеф), линии сгибов `P3.edges`, мало сегментов у круглого;
  `toy`: гладкий, мягкий блик (clearcoat), скруглённые края. `PROP_STYLE` задаётся каналом (стенд — `&style=`, редактор — из `/api/scene → style3d`).
- Фигуры (низ на y = 0): `P3.box(w, h, d, color, {r})` (скруглённый ящик), `P3.cyl`, `P3.lathe([[r, y]…])`, `P3.extrude([[x, y]…], глубина)`, `P3.part(геометрия, цвет)`;
  `P3.sticker(w, h, draw, {glow, dynamic, edge})` — наклейка из 2D-рисунка тулкита (кнопки, логотипы, надписи; `glow` — светящийся экран); `P3.p(o, 'имя', по умолчанию)` — параметр объекта сцены.
- Нормали «по углу» (как Auto Smooth в Blender, `P3.prep`): грань круче 40° — ребро, мягче — сглаживание; UV по метрам — зерно одного размера на любой детали. glb из Blender — `P3.papery`.
- `prop3d()` сам регистрирует динамические наклейки в `w.dyn` мира, где бы пропс ни собирали. Образец — `stands/samples/crt3d/prefab.js`.
- Подключается в стенд и в редактор (`/tpl/props3d.js`), в шаблон ролика — в S6 рядом со `stage3d.js`.

## 4. Стенд и осмотр

- `stand3d.html?prop=<url prefab.js>` — поворотный стол: светлый бумажный фон, мягкий свет с тенью, ёжик-карточка для масштаба (`&hog=1`, только просмотр).
  Время = угол: за `len = 8` с полный оборот; пропс вписан в центральный квадрат кадра.
- `node stands/render_prop.js <url prefab.js> <папка> [--pins pins.json]` — четыре ракурса (T = 1, 3, 5, 7: ¾ спереди, другой бок, ¾ сзади, другой бок) через `render_shot.js`
  и лист 2×2 `element.png` (`stands/prop_sheet.py`); с `--pins` — `pins.png` и `pins_1/3/5/7.png`. Путь можно без «/» (Git Bash портит «/rscene/…»).
- «🧊 Покрутить · 📍 пины» в карточке (или клик по листу) — окно с `…&view=1&pin=1`: центральный квадрат кадра, крутить мышью, колесо — ближе, пробел — вращение стола;
  клик по модели (без протяжки) — raycast, окно шлёт странице `prop-pin` {p, n}, страница сразу пишет пин в `fx.main.pins3d` и отдаёт список обратно (`prop-pins`) — номера рисуются на модели.
  Текст пина — в списке справа (и в карточке под листом).
- `&pins=<json>` — нарисовать пины номерами в кадре (закрытые моделью — пунктиром). Для правки сервер снимает прошлую версию с пинами (`pins.png` + крупно)
  — Claude смотрит их через Read и получает координаты и нормали текстом.

## 5. Blender

- Портативный Blender 5.2 LTS — `_studio/tools/blender/` (в git не идёт). Путь ищется (`paths.blender()`): `.studio/state.json → blender`, `_studio/tools/blender/*/blender.exe`, PATH, Program Files.
  Страница знает, есть ли Blender (`/api/state → blender`): без него способа «через Blender» в списке нет.
- `stands/blender_run.py model.py` — запускает Blender в фоне (`-b --factory-startup`, обёртка чистит сцену, выполняет скрипт, экспортирует glb с +Y вверх),
  пишет `model.glb` рядом, лог — `model.log`, в ответ — размеры модели или трассировку Python. Claude вызывает только его (≈7 с).
- `model.py` — скрипт `bpy`: меши, модификаторы (фаска, булевы, сглаживание), материалы-цвета; экспорт делает обёртка. Детали-наклейки (кнопки, логотип) — кодом в `prefab.js` поверх модели.

## 6. Кнопки ✨ (Claude)

- «🎨 Нарисовать черновик» у 3D-пропса — задача `element` с контрактом §2: Claude читает `props3d.js`, референсы (и 2D-черновик, если пропс был 2D), пишет `prefab.js`
  (и `model.py` → `blender_run.py`), снимает четыре ракурса, смотрит, правит 2–4 прохода. Модель Opus (визуальная).
- «Поправить» от версии: пины 3D + «в целом» → vN+1 от прошлого кода (`prefab.js`, `model.py`, `model.glb` копируются).
- «✨ Сделать в 3D» у пропса с 2D-черновиком: переключатель на 3D, кнопка — 2D-черновик (картинка и код рисунков для наклеек) идёт референсом.
- Разрешённые команды задачи: `node render_prop.js …` и (если есть Blender) `python blender_run.py …`; время — до 40 минут. Результат — `fn` = способ.

## 7. Библиотека и сцена

- Публикация 3D-пропса: в `library/props/<slug>/vN/` — `prefab.js`, `model.glb`, `model.py`, `preview.png` (лист), `license.json`; в `prop.json` — `dim: '3d'`, `h`.
- В сцене редактора объект ссылается на пропс: `src.prefab = 'lib:props/<slug>@N'` (библиотека) или `'el:<element>@vN'` (черновик этого видео).
  Стенд и редактор грузят такие `prefab.js` до сборки (`engine/scene.js`: `scenePropRefs`, `scenePropUrl`, `loadSceneProps`) — `/api/lib/file/video:<plan>/props/<slug>/vN/prefab.js`
  (канал — тот, где лежит видео) и `/rscene/<plan>/<el>/vN/prefab.js` — и кладут в `S.lib`; `scnBuildPrefab` ищет префаб в `prefabs.js` сцены, потом в `S.lib`.
- «↔ Заменить на 3D-пропс…» в свойствах объекта редактора: список — `/api/scene → props3d` (3D-пропсы видео и библиотеки с превью); выбор догружает пропс и делает
  операцию `set objects[id].src.prefab` — положение, поворот, ключи и параметры сохраняются, Ctrl+Z возвращает. Параметры пропса (`params`) видны в свойствах, как у префабов сцены.
  Высота: 3D-пропс строится в реальных метрах, масштаб объекта не трогается; поворот лицом в комнату — как у предмета, который заменили (перед пропса — +z).
- Сборка ролика со ссылками `lib:` / `el:` — S6 (проект получит копии `prefab.js` / `model.glb` в `src/props/`).

## 8. Порядок работ

1. `props3d.js` + стенд `?prop=` + ЭЛТ-монитор руками в двух стилях → автор выбирает `style3d`.
2. Данные (`dim`, `how`), карточка элемента (переключатель 2D / 3D, способ, лист ракурсов, «🧊 Покрутить», пины 3D), Blender (`blender_run.py`, поиск).
3. `element_spec` для 3D-пропса, правка по пинам, «🧊 Сделать в 3D».
4. Библиотека 3D-пропсов, `lib:` / `el:` в движке сцены, «↔ Заменить на…» в редакторе.
5. Приёмка на «Комнате»: ЭЛТ и системник через Claude (один — фигурами, другой — Blender), пин «добавь кнопки на корпус», в библиотеку, замена в сцене, клип.
