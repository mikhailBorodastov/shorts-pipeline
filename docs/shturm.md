# «Штурм идей» — документация сервиса

Состояние на 30.09.2026. Код — `_studio/server/`, данные — `_ideas/` рядом с проектами (вне git).
Главный этап — препродакшен, у него отдельный документ: [preproduction.md](preproduction.md).

---

## 1. Что это

Локальная страница `http://localhost:8790/` (запуск — `Claude Studio.bat` в рабочей папке или `_studio/server.bat`), где автор
вместе с Claude готовит ролик **до** сценария: идея → вопросы → биты → название → препродакшен → обложка → проект.
На выходе — папка проекта из шаблона, в которой уже лежит всё, что нужно сценаристу и аниматору (`refs/штурм.md`, `refs/препродакшен/`, `assets/`).
После публикации сюда же возвращаются цифры и выводы.

Методика — по купленной тетради «Мастер-планер» (`_ideas/master-planer.pdf`, в репозиторий не кладётся, текст не цитируется).
Кнопки ✨ — это Claude Code на подписке автора (`claude -p`), без API-ключей.
Для автора сервис — «локальный скрипт, как review.bat», а не «сервер».

## 2. Пути и вкладки

Оба пути в двух режимах: ⚡ шортс и 🎬 длинное видео на 8–15 минут (`mode: short | long`).

### «Есть идея» (`flow: idea`, по умолчанию: «Новый шортс» / «Новое длинное»)

| вкладка | что там | кнопки Claude |
|---|---|---|
| 💡 Идея | идея, контекст, референсы: видео по ссылке или пути (разбор `refvideo.py`: контактные листы 6×5 + субтитры или расшифровка faster-whisper), картинки | — (разбор локальный) |
| ❓ Вопросы и биты | 15–20 вопросов по группам (сюжет, герои, мир, тон, факты, упаковка), ответы автора — его решения; уточняющие раунды; биты «вопрос → ответ»; челлендж | `questions`, `beats`, `challenge` |
| 🎯 Смыслы и название | смыслы «без этого никак», названия по 4 углам атаки, сильные слова (без 7 вопросов) | `meanings`, `titles`, `strengthen` |
| 🎬 Препродакшен | сцены, персонажи, пропсы, звуки — [preproduction.md](preproduction.md) | `elements`, `element`, `sound`, `assets` |
| 🏆 Обложка | одна связка «хук + первый кадр + обложка», эскизы, отрисовка нашим движком, правки пинами | `thumbs`, `critique`, `render` |
| 🚀 В работу | проверки готовности, «Создать проект» | — (`produce` локальный) |
| 📈 Итоги | работа над ошибками, реакция аудитории, просмотры, выводы | `conclusions` |

### «💡 Штурм идей» (старый путь, поля `flow` нет)
Идеи (10 → ★3 → ●1) → биты → название (7 вопросов, смыслы, 4 угла, сильные слова) → образы (3 на смысл) → превью → структура (схемы А/Б/В
или три акта / инструкция) → в работу → итоги. Кнопки: `ideas`, `beats`, `q7`, `meanings`, `titles`, `strengthen`, `images`, `thumbs`, `critique`,
`structure`, `render`, `conclusions`. Штурм с выбранной идеей переводится на основной путь кнопкой «🎬 → препродакшен».

### Общие страницы
- **Банк идей** (`bank`) — трекер идей с оценками; «📰» — автообновление из новостей сайтов автора (`bank.auto`, раз в `hours` часов, пока открыто окно).
- **Лист проекта** (`brand`) — кто мы, чем отличаемся, чего никогда не делаем.
- **Просмотры** (`stats`) — трекер роликов; «▶ YouTube» — синхронизация через OAuth (только чтение, `youtube.py`), живой счётчик первых 30 часов.
- **Справочник** — карта превью, правила из тетради (своими словами).

## 3. Архитектура

```
браузер: web/index.html + core.js (h(), Store, Claude, Mention, Drafts) + plan.js (вкладки) + idea.js (путь «Есть идея») + pages.js + main.js
   │  GET /api/revs раз в 2 с (ревизии документов + задачи)       POST /api/op (операции), /api/claude (задача), /api/… (локальные задачи)
   ▼
ideas_server.py — ядро: порт 8790, запуск, CLI, тикер (раз в минуту auto_tick). Почти не меняется.
ideas_api.py    — логика: документы и операции, экспорт в md, задачи, HTTP-маршруты. Перезагружается на лету при изменении файла.
   ├─ ideas_claude.py — промпты и JSON-схемы всех кнопок ✨ (build → spec, apply → операции)
   ├─ preprod.py      — модель препродакшена, @-ссылки, состав сцен, микс, экспорт в проект
   ├─ assets.py       — поиск и скачивание бесплатных 3D / 2D / текстур
   ├─ sounds.py       — поиск и скачивание звуков (библиотека, Freesound, Commons, любые ссылки, yt-dlp)
   ├─ refvideo.py     — разбор видео-референса
   └─ youtube.py      — статистика канала
stands/page.html   — 2D-стенд (обложка, первый кадр, элементы), paper.js — бумажный тулкит
stands/stand3d.html — 3D-стенд (/tpl/stand3d.html): рендер черновиков, живой просмотр, редактор расстановки, просмотр моделей
render_shot.js         — puppeteer: снимает PNG со стенда (вызывает Claude и задача layout3d)
web/ref.json           — единый справочник: вкладки путей, типы элементов, группы вопросов, углы атаки, схемы… (страница, экспорт и промпты)
```
Вспомогательные модули перезагружаются через `ideas_api._fresh()` (`sapi`, `aapi`, `vapi`, `pr`, `yapi`, `capi`).
Если меняется то, от чего зависит страница, поднимай `API_VERSION` в `ideas_api.py` и `API` в `web/core.js` (сейчас 3): страница со старым
скриптом покажет плашку «перезапусти».

### Документы и операции
- Ключи: `plan:<id>` → `_ideas/plans/<id>.json` (+ читаемый `<id>.md`), `bank`, `brand`, `stats`. У каждого счётчик `rev`.
- Правки — только операциями (`apply_op`): `set {path, value}`, `add {path, item, at?}` (в список), `del {path, id}`, `move {path, id, to}`.
  Путь по спискам идёт через `id` элемента, а не индекс. Операции применяются к свежему файлу под блокировкой — страница, Claude на странице
  и Claude в сессии (CLI) не затирают правки друг друга.
- Страница держит документ открытым и сливает изменения по `rev`; незаписанный текст в полях без привязки хранят `Drafts`.
- `<канал>/index.md` — обзор всех штурмов для Claude, пересобирается при каждом сохранении.

### Задачи
`start_job(kind, key, scope, params)` → поток → `Job` (`status`, `summary`, `result`, `elapsed`). Лог — `_ideas/.jobs/log.txt` (стоимость и ходы Claude).
- **Claude** (`run_action` → `run_claude`): `claude.exe -p --safe-mode --no-session-persistence --output-format json --json-schema … --system-prompt-file …`,
  `--tools` / `--allowedTools` только из spec (например, единственная команда `node render_shot.js` или `python assets.py search`),
  `--permission-prompts none`, `--add-dir` для папок, которые можно читать. Ответ — `structured_output` по схеме.
  `claude.exe` вызывается напрямую (обёртка `.cmd` ломает кириллицу). Одновременно — не больше `MAX_JOBS` задач Claude.
- **Модели:** текстовые кнопки — Sonnet 5.5 (`TEXT_MODEL = "sonnet"`), визуальные `element` и `render` — Opus 5.5 (`VISUAL_MODEL`);
  усилие medium у `elements`, `sound`, `assets` (`TEXT_EFFORT`). 🌐 у штурма включает WebSearch/WebFetch (1–3 минуты).
- **Локальные** (`LOCAL_KINDS`, без Claude): `produce`, `sndfetch`, `refparse`, `assetfetch`, `layout3d`, `ytlogin`, `ytsync`, `ytfresh`.
- Кнопка ✨ пока идёт задача превращается в «Claude думает… 12 с ✕» (клик — отмена); по окончании — тост, точка «непрочитано» на штурме и вкладке,
  уведомление браузера, если вкладка не на виду.

### HTTP
Полный список — в шапке `ideas_api.py`. POST принимается только со страницы сервиса (заголовок `X-Ideas: 1` и Origin localhost), `/api/*` —
только с Host localhost. Статика: `/files/…` (картинки и файлы штурмов, с Range), `/fonts/…`, `/tpl/…` (src шаблона ролика), `/rscene/…`
(код черновиков), `/sfxlib/…` (библиотека звуков), `/planner.pdf`.

## 4. CLI (для Claude в сессии)

Писать в штурм из сессии — только так, JSON руками не править:
```
python _studio/server/studio.py list | show ID | bank | port
python _studio/server/studio.py new short|long "Имя" [--topic …] [--idea …] [--storm]
python _studio/server/studio.py add-ideas ID "…" … | add-beats ID "вопрос | ответ" … | add-questions ID "вопрос" …
python _studio/server/studio.py add-elements ID scene|char|prop|sound "название | описание" …
python _studio/server/studio.py add-bank "Идея" [--desc … --cool 1-3 --speed 1-3 --mode short|long|any --fresh … --src …]
python _studio/server/studio.py set KEY путь.через.точки значение  |  op KEY '<JSON-операции>'
python _studio/server/studio.py produce ID "Проект" [--attach]  |  yt-sync
python _studio/server/assets.py search "q1" "q2" --kind 3d|2d|tex  |  fetch <src> <id> <папка>
python _studio/server/sounds.py search "q" | fetch <ссылка|lib:id> <папка> [--start … --end …]
```


## 6. Связь с пайплайном роликов

- **«🚀 Создать проект»** = `new_project.py` + `refs/штурм.md` + `refs/штурм.json` + эскизы и листы кадров в `refs/штурм/` + экспорт препродакшена
  (`refs/препродакшен/`, `assets/models|img|sfx/`). Штурм помечается `status: prod`, в нём запоминается `project`.
- **Сценарий:** `_studio/CLAUDE.md`, вход 3 («пришёл со штурмом»): штурм — часть ТЗ, этапы сценариста короче, сцены строятся из локаций препродакшена.
- **Анимация:** шаг A.2 — README элементов, `manifest.json`, черновики как стартовый код, «для финала» — обязательные требования.
- **Обложка:** концепт и `scene.js` из «🎨 Отрисовать» — первый вариант `THUMBNAILS`.
- **Итоги:** после публикации цифры и комментарии возвращаются во вкладку «Итоги» и в «Просмотры»; выводы по 1, 3, 5, 10 роликам — кандидаты в `style-guide.md`.

## 7. Правила, которые важны автору

- Упаковка — одна связка «хук + название + обложка» по умолчанию, правки пинами (обложка и первый кадр отдельно).
- Ассеты качаем без лишних вопросов, но одним подтверждением; права всегда перечисляем.
- Доступность: всё с клавиатуры (Tab выбирает из списков и подсказок, Enter/Tab вставляет @, стек правок по Enter).
- Черновики — не финал: «Для финала» — отдельный слой требований.
- Архитектура должна быть понятна Claude-реализатору: README на элемент, manifest, указатель.
